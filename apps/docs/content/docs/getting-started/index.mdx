## Install

```sh
npx shadcn@latest add @sudokw/primitives-button
```

```json
{
  "compilerOptions": {
    "jsx": "react-jsx",
    "jsxImportSource": "@gpuix/react"
  }
}
```

React 19. `@gpuix/native` ships prebuilt for Apple Silicon, Linux x64 and
Windows. Any other host builds the binding once, as
[`apps/playground/README.md`](https://github.com/Cyberistic/GPUIXUI/blob/master/apps/playground/README.md#the-binding-on-this-host)
describes.

## First component

```tsx
import { render } from "@gpuix/react";
import { Button } from "@gpuixui/primitives";
import { darkTheme } from "@gpuixui/tokens";
import { ThemeProvider } from "@gpuixui/tokens/react";

render(
  <ThemeProvider theme={darkTheme}>
    <Button variant="primary" onActivate={save}>
      Save changes
    </Button>
  </ThemeProvider>,
);
```

`render` takes **one** element: a fragment at the root paints only its last
child.

## Theme

```tsx
import { getTheme, platformTheme } from "@gpuixui/tokens";
import { ThemeProvider } from "@gpuixui/tokens/react";

const theme = platformTheme(getTheme("dark"), "win32");

<ThemeProvider theme={theme}>{app}</ThemeProvider>;
```

Modes: `light`, `dark`. Contrast: `default`, `high`. Platforms: `darwin`,
`win32`, `linux`, `default`.
