---
title: Terminal
description: Run the same view inside kitty or Ghostty instead of a window.
---

`render` takes `terminal: true`, and the runtime paints the app into the terminal it was started from:

```tsx
import { render } from "@gpuix/react";

render(<App />, { terminal: true });
```

`GPUIX_TERMINAL=1` sets the same option, so an unchanged entrypoint runs either way:

```sh
GPUIX_TERMINAL=1 nub src/main.tsx
```

The playground in this repository:

```sh
nub run --filter playground build
GPUIX_TERMINAL=1 nub apps/playground/dist/main.js
```
