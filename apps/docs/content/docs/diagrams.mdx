---
title: Diagrams
description: A mermaid fence, rendered at build time by Pele.
---

A fence tagged `mermaid` is the whole API. [Pele](https://pele.run) renders it
during the build, so the drawing is in the prerendered HTML and the fence stays
the source a reader can copy.

```mermaid
flowchart LR
  subgraph author[Author]
    component[Component] --> recipe[Recipe]
  end
  subgraph render[Render]
    recipe --> themed[Themed surface]
    themed --> frame[Frame]
  end
  author --> render
  render --> reader([Reader])
```

| Pele role | The page's role |
| --- | --- |
| `--pele-bg` | `--card` |
| `--pele-fg` | `--foreground` |
| `--pele-muted` | `--muted-foreground` |
| `--pele-line` | `--border-strong` |
| `--pele-surface` | `--muted` |
| `--pele-accent` | `--ring` |
| `--pele-border` | `--border` |

Every value is a `var()`, so the diagram is rendered once and the surface it sits
on decides its colours.

A source Pele cannot read prints the parser's sentence with the source under it:

```mermaid
this is not a diagram
```
