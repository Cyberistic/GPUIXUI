---
title: Patterns
description: Realistic compositions, not isolated controls.
---

Patterns are where components meet real tasks: a settings page with validation,
a confirmation flow, a searchable command menu, a data table with filters. A
pattern page shows the composition, explains the state it owns, and says which
parts are verified in the native runtime.

<Callout>
Patterns appear once the components they compose are implemented and proven. A
pattern is never assembled from browser imitations and presented as working
native behaviour.
</Callout>
