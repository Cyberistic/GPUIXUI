---
title: Accessibility
description: What a screen reader hears from a GPUix surface, and which states have no attribute.
---

A node exists in the tree only if it has a role. A `div` with only an `aria-label` paints nothing readable; `role="none"` removes the node.

| Attribute | Type | Reaches the tree as |
| --------- | ---- | ------------------- |
| `aria-label` | string | `label` |
| `aria-description` | string | `description` |
| `aria-id` | string | `author_id` |
| `aria-expanded` | boolean | `expanded` |
| `aria-selected` | boolean | `selected` |
| `aria-valuetext` | string | `value` |
| `aria-level` | number | `level` |

An `onClick` with a `tabIndex` surfaces as the `Click` and `Focus` actions; a `text` element is a `Label` node.

Roles are reported by their platform name: `button` is `Button`, `option` is `ListBoxOption`, `heading` is `Heading`, `progressbar` is `ProgressIndicator`.

## What does not exist

There is no `aria-checked`, `aria-valuenow`, `aria-valuemin`, `aria-valuemax`, `aria-labelledby`, `aria-describedby`, `aria-orientation`, `aria-controls`, `aria-disabled`, `aria-pressed`, `aria-haspopup`, `aria-current`, `aria-activedescendant`, `aria-live` or `aria-atomic`.

| Intent | Instead |
| ------ | ------- |
| a visible label names the control | the control carries its own `label`; a visible `Label` is text beside it |
| visible help describes the control | the control carries its own `description` |
| checked or pressed is announced | the component paints the state; nothing announces it |
| a numeric value is announced | `aria-valuetext` on a role with a value, written as the readable value |
| disabled, current, expanded, orientation | visual state plus a guarded handler |
| a change is announced | move focus to the new content, or name the changed control |

A `role="status"` is a marker, not an announcement: a new toast, countdown or message is not spoken.

## Naming a control

There is no `aria-labelledby`, so `labelledBy` builds the props from one string:

```tsx
import { Input, Label, labelledBy } from "@gpuixui/primitives";

const name = "Contact email";
const help = "Where notifications are delivered.";

<Label description={help}>{name}</Label>
<Input
  {...labelledBy(name)}
  description={help}
  value={value}
  onValueChange={setValue}
  placeholder="you@example.com"
/>;
```

A visible `Label` beside a control is not associated with it.
