## Set up

```sh
git clone https://github.com/Cyberistic/GPUIXUI.git
cd GPUIXUI
nub install
nub run check
```

Node 24.18.0 and [`nub`](https://nub.dev) are pinned.

## Work in one tree

One writer per tree. Commits go through `scripts/swarm-commit.sh "<message>" <paths…>`; an agent that needs isolation uses a `git worktree` under `workspaces/<workstream>/` on branch `agent/<workstream>` and merges its own branch.

## Checks

```sh
nub run check
nub run test
nub run --filter @gpuixui/components test:behaviour
nub run --filter @gpuixui/primitives test:runtime
nub run --filter @gpuixui/docs test
nub run --filter playground smoke
```

The live suite opens real windows and is a release gate:

```sh
nub run --filter playground build && nub apps/playground/dist/live/run.js --only <id>
```

## What a component ships with

- One responsibility, a typed public API and sensible defaults.
- A behaviour test in the real GPUix renderer.
- At least one working example.
- A page in `packages/<package>/docs/<component>.mdx`.
- An inventory row in `COMPONENTS.md`.
