## What composes a window

| Part of the shell | Compose it from | Page |
| ----------------- | --------------- | ---- |
| The frame | `Box` + `Stack` + `Separator` + `ScrollArea` | [Layouts](/docs/layouts) |
| Resizable split panes | `SplitPane` | [Split pane](/docs/dock/split-pane) |
| Panel groups | `PanelGroup` | [Panel groups](/docs/dock/panel-group) |
| A docked arrangement | `DockLayout` | [Docking layouts](/docs/dock/dock-layout) |
| Tabbed panels | `Tabs` | [Tabs](/docs/components/tabs) |
| Command palette | `CommandMenu` | [Command menu](/docs/components/command-menu) |
| Application menus | `AppMenu` | [Application menu](/docs/shell/app-menu) |
| Breadcrumb navigation | `Breadcrumb` | [Breadcrumb](/docs/components/breadcrumb) |
| Toolbars | `Toolbar` | [Toolbar](/docs/shell/toolbar) |
| Status bars | `StatusBar` | [Status bar](/docs/shell/status-bar) |
| Notifications | `Toast` provider and viewport | [Toast](/docs/components/toast) |
| A whole window | The [Dashboard](/docs/blocks/dashboard) block | [Blocks](/docs/blocks) |

The frames themselves are on [Layouts](/docs/layouts), and each part's page is under [Components](/docs/components).

## State and persistence

A workspace keeps its own layout state: decode a stored `DockNode` or `PanelLayout` with the package's JSON schema and open the default when the decode fails.

```ts
import { DockNodeJson } from "@gpuixui/dock";
import * as Schema from "effect/Schema";

const saved = Schema.encodeUnknownSync(DockNodeJson)(layout);
const restored = Schema.decodeUnknownSync(DockNodeJson)(saved);
```
