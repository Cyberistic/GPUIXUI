## What composes a window

| Part of the shell | Compose it from | Page |
| ----------------- | --------------- | ---- |
| The frame | `Box` + `Stack` + `Separator` + `ScrollArea` | [Stack](/primitives/stack) |
| Resizable split panes | `SplitPane` | [Split pane](/dock/split-pane) |
| Panel groups | `PanelGroup` | [Panel groups](/dock/panel-group) |
| A docked arrangement | `DockLayout` | [Docking layouts](/dock/dock-layout) |
| Tabbed panels | `Tabs` | [Tabs](/components/tabs) |
| Command palette | `CommandMenu` | [Command menu](/components/command-menu) |
| Application menus | `AppMenu` | [Application menu](/shell/app-menu) |
| Breadcrumb navigation | `Breadcrumb` | [Breadcrumb](/components/breadcrumb) |
| Toolbars | `Toolbar` | [Toolbar](/shell/toolbar) |
| Status bars | `StatusBar` | [Status bar](/shell/status-bar) |
| Notifications | `Toast` provider and viewport | [Toast](/components/toast) |
| A whole window | The [Dashboard](/blocks/dashboard) block | [Blocks](/blocks) |

The frames themselves are on [Primitives](/primitives/stack); the [dock](/dock/split-pane) and [shell](/shell/app-menu) pages stay in Workspace, and the rest are under [Components](/components).

## Persistence

Decode a stored `DockNode` or `PanelLayout` with its JSON schema; open the
default when the decode fails:

```ts
import { DockNodeJson } from "@gpuixui/dock";
import * as Schema from "effect/Schema";

const saved = Schema.encodeUnknownSync(DockNodeJson)(layout);
const restored = Schema.decodeUnknownSync(DockNodeJson)(saved);
```

## Moving a tab

A tab strip is `Tabs` plus the app's own drag state; `Cmd+Shift+Left`/`Right`
step it without wrapping.

- A dragged tab leaves its strip and lands at the dropped slot; the source selects the tab that took its place.
- A moved panel's draft survives the remount; restore the focus it drops.
- A release outside both strips misses.
- **A detached tab is not available.** The window holds one process; move a tab to another pane or layer with `createPortal`.
