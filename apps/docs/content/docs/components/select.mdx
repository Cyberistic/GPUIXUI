## Usage

```tsx
import { useState } from "react";
import { Label, Select } from "@gpuixui/primitives";

const regions = [
  {
    label: "Europe",
    options: [
      { value: "eu-west", label: "Europe — West (Ireland)" },
      { value: "eu-central", label: "Europe — Central (Frankfurt)" },
    ],
  },
  {
    label: "Americas",
    options: [
      { value: "us-east", label: "United States — East" },
      { value: "us-west", label: "United States — West" },
    ],
  },
];

export const DeployTarget = () => {
  const [region, setRegion] = useState("eu-west");

  return (
    <>
      <Label>Region</Label>
      <Select
        label="Region"
        onValueChange={setRegion}
        options={regions}
        value={region}
      />
    </>
  );
};
```

## Composition

```text
Select
├── trigger (built in)
├── content
│   └── item
└── group / label / separator
```

## API reference

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `options` | `ReadonlyArray<SelectOption \| SelectOptionGroup>` | required | the rows, or named groups of them, in render order |
| `value` | `string` | none | controlled selection |
| `defaultValue` | `string` | none | initial selection when uncontrolled |
| `selectedValue` | `string` | `value ?? defaultValue` | the choice a closed trigger announces — a parent's mirror of an uncontrolled select's value |
| `open` | `boolean` | none | controlled open state |
| `defaultOpen` | `boolean` | `false` | the list's initial state while `open` is omitted |
| `onOpenChange` | `(open: boolean) => void` | none | the open state the runtime reported |
| `onValueChange` | `(value: string) => void` | none | the committed value |
| `onChange` | `(value: string) => void` | none | deprecated alias; `onValueChange` wins when both are passed |
| `placeholder` | `string` | none | the trigger's text before a choice |
| `disabled` | `boolean` | `false` | refuses to open |
| `invalid` | `boolean` | `false` | `destructive` edge on the trigger |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | height and padding from density |
| `fullWidth` | `boolean` | `false` | trigger and list fill the parent |
| `side` | `FloatingSide` | the runtime's choice | which side the list opens on |
| `label` | `string` | none | the accessible name — put a visible `Label` beside it |
| `description` | `string` | none | announced help after the name; a blank one publishes nothing |
| `ref` / `aria-id` / `onLayout` | host props | none | the trigger is the addressed element — the one a form focuses, an automation host names and a layout measures |
| `style` | `StyleDesc` | none | merged last on the wrapper, which paints only its width |
| `triggerStyle` | `StateStyle<SelectTriggerState>` | none | resolved against the trigger's live state, merged last |
| `itemStyle` | `StateStyle<SelectItemState>` | none | resolved per row against that row's state, merged last |
| `testId` | `string` | none | locator for the wrapper — it is **not** the trigger |
| `triggerTestId` | `string` | none | locator for the element that opens the list |
| `itemTestId` | `(value: string) => string` | none | locator for an option row, derived from its value |

## Limitations

- Role and name come from the runtime's trigger; `label` adds the accessible name.
- The **trigger is the control**: it carries the open state, the chosen words and `description`.
- `SelectGroup` is a plain `div`; the wrapper carries `role="group"` and the caption's name.
