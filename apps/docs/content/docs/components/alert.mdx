## Usage

```tsx
import {
  Alert,
  AlertContent,
  AlertDescription,
  AlertTitle,
} from "@gpuixui/components/alert";

<Alert tone="warning">
  <AlertContent>
    <AlertTitle>3 tokens are missing</AlertTitle>
    <AlertDescription>
      The platform themes fall back to the default palette.
    </AlertDescription>
  </AlertContent>
</Alert>;
```

## Composition

```text
Alert
├── AlertIcon
├── AlertContent
│   ├── AlertTitle
│   ├── AlertDescription
│   └── AlertLink
└── AlertDismiss
```

## API reference

| Part | Prop | Type | Default | Consequence |
| ---- | ---- | ---- | ------- | ----------- |
| `Alert` | `tone` | `"info" \| "success" \| "warning" \| "danger"` | `"info"` — a stored name the union does not carry | the surface, edge and readable colour every part inherits |
| `Alert` | `children` | parts | — | the composition; a part outside the root throws |
| any part | `className` | `string` | — | joined after that part's recipe; `style` still merges last |
| `AlertLink` | `onSelect` | `() => void` | — | the text action's handler, on click, `Enter` or `Space` |
| `AlertDismiss` | `onDismiss` | `() => void` (required) | — | runs on click, `Enter` or `Space`; there is no optional dismiss |
| `AlertDismiss` | `label` | `string` | `"Dismiss"` | the control's accessible name |

## Limitations

- The root carries `role="alert"`; `AlertIcon` has no role of its own.
- Every alert needs an `AlertTitle`; colour is never the only signal.
- The dismiss control's name comes from `label`, not from the glyph.
