## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@gpuixui/components/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger variant="secondary" size="sm">
    Actions
  </DropdownMenuTrigger>
  <DropdownMenuContent label="File actions" align="end">
    <DropdownMenuItem onSelect={() => rename(file)}>Rename</DropdownMenuItem>
    <DropdownMenuItem disabled>Duplicate</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem tone="destructive" onSelect={() => remove(file)}>
      Delete
    </DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>;
```

## API reference

### DropdownMenu

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` | uncontrolled |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | none |

### DropdownMenuTrigger

### DropdownMenuContent

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` (required) | the menu's accessible name |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `sideOffset` | `number` | `4` |
| `collisionPadding` | `number` | `8` |
| `alignOffset` | `number` | `0` — added to the measured centre correction |

### DropdownMenuItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `onSelect` | `() => void` | none — runs, then closes |
| `disabled` | `boolean` | `false` |
| `tone` | `"default" \| "destructive"` | `"default"` |
| `leading` | `ReactNode` | none — a slot before the label |
| `trailing` | `ReactNode` | none — a slot after it, for a shortcut |
| `textValue` | `string` | the plain text children |
| `closeOnSelect` | `boolean` | `true` |
| `style` | `StyleDesc \| (state: MenuItemState) => StyleDesc` | none |

### DropdownMenuCheckboxItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `checked` | `boolean` (required) | none |
| `onCheckedChange` | `(checked: boolean) => void` (required) | none |
| `closeOnSelect` | `boolean` | `false` — the row stays open |

### DropdownMenuRadioGroup / DropdownMenuRadioItem

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` (required, group) | none — the choice the group marks |
| `onValueChange` | `(value: string) => void` (required, group) | none — reports the chosen row's value |
| `label` | `string` | none — the choice's accessible name |
| `className` | `string` | none — compiled through `@gpuixui/tw` |
| `value` | `string` (required, row) | none — this row's value in the group |

## Limitations

- `role="menu"` names the surface; rows are `menuitem` or `menuitemcheckbox`, and the trigger carries `aria-expanded`.
- **No `aria-haspopup`, `aria-controls`, `aria-checked` or `aria-activedescendant`** in `@gpuix/native@0.11.0` — `HostProps` publishes only `aria-label`, `aria-description`, `aria-expanded`, `aria-selected`, `aria-valuetext` and `aria-level`.
- One level of submenus is tested.
