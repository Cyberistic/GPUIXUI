## Usage

```tsx
import { Button } from "@gpuixui/primitives";

<Button variant="primary" onActivate={save}>
  Save changes
</Button>;
```

## API reference

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `variant` | `"primary" \| "secondary" \| "outline" \| "ghost" \| "destructive" \| "link"` | `"primary"` | paint from the variant table |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | height and padding from density |
| `square` | `boolean` | `false` | icon-only geometry |
| `fullWidth` | `boolean` | `false` | `width: 100%` |
| `disabled` | `boolean` | `false` | blocks activation, leaves the tab order |
| `loading` | `boolean` | `false` | spinner, `Loading` description, blocks activation |
| `loadingLabel` | `string` | the provider's `loading.busy` (`Loading`) | the spinner's accessible name |
| `reducedMotion` | `boolean` | the provider's preference (`false` when none) | lands the busy spinner at rest instead of animating it; the prop wins |
| `leading` / `trailing` | `ReactNode` | none | icon or element beside the label |
| `label` | `string` | none | accessible name; required for an icon-only button |
| `onActivate` | `() => void` | none | click or activating key; not called while busy |
| `onClick` | `(event) => void` | none | raw click, called before `onActivate` |
| `style` | `StyleDesc` | none | merged last |
| `testId` | `string` | none | stable locator |
| `children` | `ReactNode` | none | visible label |

## Limitations

- Role `button`; the name comes from `label` or the visible text.
- `loading` sets `aria-description="Loading"` — the runtime declares no `aria-busy`.
- There is no `aria-disabled`: a disabled button leaves the tab order and drops its handlers instead.
