## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@gpuixui/components/navigation-menu";

<NavigationMenu label="Product" onValueChange={setSection} value={section}>
  <NavigationMenuList>
    <NavigationMenuItem value="platform">
      <NavigationMenuTrigger>Platform</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink onSelect={() => open("overview")}>
          Overview
        </NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>;
```

## Composition

## API reference

| Part | Renders | Props |
| ---- | ------- | ----- |
| `NavigationMenu` | `role="navigation"`, named by `label` | `label` (required), `value`, `defaultValue`, `onValueChange`, `openDelay`, `closeDelay`, `className`, `children` |
| `NavigationMenuList` | `role="list"` row | `className`, `children` |
| `NavigationMenuItem` | `role="listitem"` | `value` (required), `className`, `children` |
| `NavigationMenuTrigger` | button carrying `aria-expanded` and a fixed-slot chevron | every `Button` prop, plus `disabled`; `trailing` renders before the chevron; `onActivate` is the action's handler and `onClick` its deprecated alias |
| `NavigationMenuContent` | anchored `role="group"` panel | `className`, `children` |
| `NavigationMenuLink` | full-width ghost button row | `onSelect`; `onActivate` with `onClick` as the deprecated alias; every `Button` prop |

## Limitations

- The panel's accessible name is the item's **`value`**, not its visible label; no `aria-haspopup`.
- A dismissed panel paints for its **200 ms** exit and its links leave the window's tab order until the runtime inherits `inert`.
- The trigger paints `chevron-down`/`chevron-up` in a fixed slot; `aria-expanded` carries the state.
