## Usage

```tsx
import { InlineEdit } from "@gpuixui/components";
import { useState } from "react";

export const RenameProject = () => {
  const [name, setName] = useState("Docs site");

  return (
    <InlineEdit
      label="Project name"
      onCommit={(next) => {
        // The component reported a changed value; the app decides what to save.
        setName(next);
      }}
      value={name}
    />
  );
};
```

## API reference

### `InlineEdit`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `string` | — | the committed text; required, and the caller owns it |
| `onCommit` | `(value: string) => void` | — | called on a **changed** `Enter` or blur commit, never twice per edit, and never when the caller disables the control mid-edit |
| `label` | `string` | — | the accessible name of both the display and the input |
| `placeholder` | `string` | `"—"` | painted in `mutedForeground` while the value is empty |
| `disabled` | `boolean` | `false` | leaves the tab order, ignores activation and fades to 0.5 |
| `editing` | `boolean` | — | the controlled edit state; `undefined` leaves it to the control |
| `defaultEditing` | `boolean` | `false` | the uncontrolled starting state |
| `onEditingChange` | `(editing: boolean) => void` | — | reports the edit state the control took |
| `style` | `StateStyle<InlineEditState>` | — | resolved against `{ editing, disabled }`, merged last |
| `className` | `string` | — | joined after the recipe, so it wins conflicts |
| `testId` | `string` | — | stable locator |

## Limitations

- The display is a `role="button"`; the input is a real `<input>` — both take `label`.
- **No `aria-invalid` or `aria-describedby`** in 0.11.0, so a refused commit is not announced.
- A caller that **disables the control mid-edit** refuses both the edit and the commit.
