## Usage

```tsx
import {
  Table,
  TableBody,
  TableCell,
  TableHeader,
  TableHeaderCell,
  TableRow,
  TableViewport,
  useColumns,
  useTable,
} from "@gpuixui/data";

const columns = useColumns({
  columns: [
    { id: "service", label: "Service", width: 260 },
    { id: "environment", label: "Environment", width: 140 },
  ],
});

const table = useTable({
  rows,
  keyOf: (row) => row.id,
  // One column list is what the header paints, what the core sorts by and
  // what the filter searches.
  columns: [
    { id: "service", valueOf: (row) => row.service },
    { id: "environment", valueOf: (row) => row.environment },
  ],
  // A column the menu hides leaves the query; it keeps its sort.
  hiddenColumns: columns.hidden,
});

<Table aria-label="Deploy queue" height={320}>
  <TableViewport>
    <TableHeader>
      <TableRow>
        <TableHeaderCell width={260}>Service</TableHeaderCell>
        <TableHeaderCell width={140}>Environment</TableHeaderCell>
      </TableRow>
    </TableHeader>
    <TableBody>
      {table.rows.map((row) => (
        <TableRow
          key={row.id}
          onClick={(event) => table.press(row.id, event.modifiers)}
          selected={table.isSelected(row.id)}
        >
          <TableCell width={260}>{row.service}</TableCell>
          <TableCell width={140}>{row.environment}</TableCell>
        </TableRow>
      ))}
    </TableBody>
  </TableViewport>
</Table>;
```

## API reference

### Table

| Prop | Type | Default |
| ---- | ---- | ------- |
| `height` | `number` — a definite height; the header stays painted and the body scrolls | — |
| `className` | `string` — joined after the recipe, so it wins conflicts | — |

### TableViewport, TableHeader, TableBody

| Prop | Type | Default |
| ---- | ---- | ------- |
| `rows` | `number` — the skeleton's row count when the body has no children | `3` |
| `height` | `number` — the body height `Table` measures and hands down | measured |
| `className` | `string` | — |

### TableRow

| Prop | Type | Default |
| ---- | ---- | ------- |
| `selected` | `boolean` — the chosen record's wash and label role | `false` |
| `disabled` | `boolean` — no press, no pointer cursor | `false` |
| `instanceRef` | `Ref<PublicInstance>` — the painted element, for `renderer.focusElement` | — |
| `className` | `string` | — |

### TableHeaderCell, TableCell

| Prop | Type | Default |
| ---- | ---- | ------- |
| `width` | `number` — a fixed track; omitted, the cell shares the leftover width | — |
| `align` | `"left" \| "center" \| "right"` | `"left"` |
| `className` | `string` | — |

### TableSkeleton

| Prop | Type | Default |
| ---- | ---- | ------- |
| `rows` | `number` — bars, one row each | `3` |
| `columns` | `number` — bars per row | `3` |

### TableSortHeader

| Prop | Type | Default |
| ---- | ---- | ------- |
| `field` | `string` — the field a press reports | — |
| `label` | `string` — the visible label and the base of the accessible name | — |
| `sort` | `Option<SortState>` — the primary sort, for a single-sort consumer | — |
| `order` | `SortOrder` — the whole order, primary first | `sort` alone |
| `initialDirection` | `"asc" \| "desc"` — the direction a first press starts at | `"asc"` |
| `onSort` | `(next: SortState) => void` — the single-column contract | — |
| `onSortPress` | `(field, initialDirection, modifiers) => void` — the raw press, so the controller can compose an order | — |
| `width` | `number` — a fixed track | — |
| `align` | `"left" \| "center" \| "right"` | `"left"` |
| `resize` | `TableColumnResizeProps` — the divider; needs a fixed `width` | — |
| `testId` | `string` | — |

### The sort surface `useTable` exposes

| Member | Type | Consequence |
| ------ | ---- | ----------- |
| `sort` | `Option<SortState>` | the primary entry, for a single-sort readout or header |
| `sortOrder` | `SortOrder` | every sorted field, primary first — what the rows and the header read |
| `setSort` | `(sort: Option<SortState>) => void` | replace the order with one entry, or none |
| `toggleSort` | `(field: string, additive?: boolean) => void` | the press cycle; `additive` keeps the order and adds a tie-break |
| `pressSort` | `(field, initialDirection, modifiers?) => void` | the raw press; `modifiers.shift` is what sets `additive` |
| `rows` | `ReadonlyArray<Row>` | filtered by the query, then ordered by every entry in turn |

## Limitations

- **No table element**: rows report `role` and `aria-selected`, not `aria-colindex` or `aria-rowindex`.
- **No `aria-sort`**: `TableSortHeader` carries the state in its name.
- **No `position: "sticky"`**: a header inside the row scroller scrolls away.
