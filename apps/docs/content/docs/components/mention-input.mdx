`MentionInput` opens a ranked suggestion list when the text contains an open
`@` token and inserts the chosen name. The token rules are pure; the field owns
the text and the highlight, and the consumer declares the candidate items.

## Usage

```tsx
import {
  MentionInput,
  MentionInputItem,
  MentionInputList,
} from "@gpuixui/components";

<MentionInput
  label="Comment"
  value={comment}
  onValueChange={setComment}
  onMention={(name) => notify(name)}
>
  <MentionInputList>
    {people.map((person) => (
      <MentionInputItem key={person} value={person} />
    ))}
  </MentionInputList>
</MentionInput>;
```

## Variants

None. `maxVisible` caps the ranked list (default 6); `disabled` makes the field
read-only and inert.

## Sizes

None. The field uses the theme's `md` control height and the list sizes itself
to its rows.

## States

| Text / action | Result |
| ------------- | ------ |
| `"@"` or `"hi @"` | opens with an empty query |
| `"hi @an"` | query `"an"` |
| `"email@example"` | no mention (no whitespace before `@`) |
| `"@a @b"` | the last token |
| no matches | the list closes |

Ranking is case-insensitive: prefix matches first, then substring matches, each
in declaration order.

## State and ownership

`MentionInput` owns the text when uncontrolled, the suggestion list's open
flag, the ranked query and the highlight. The consumer owns the candidate list
and what an inserted `@name ` means: `onValueChange` reports the new text and
`onSelect` the chosen candidate. The query is the last `@` token in the text,
not the caret (0.10.0 exposes no caret API), and Escape closes only the list.

## Keyboard and focus

| Key | Result |
| --- | ------ |
| `ArrowDown` / `ArrowUp` | moves the highlight, wrapping |
| `Enter` | inserts the highlighted name (the input's submit event) |
| `Escape` | closes the list, text unchanged |
| pressing a row | inserts that name |

`Tab` is not claimed: the platform moves focus out of the field. Rows are
focusable, so `Tab` then `Enter` can pick one.

## Theming

The field uses `background`, `border`, `radius.md`, the control height and the
focus ring; the list uses `popover`, `border` and `radius.md`; the highlighted
row uses `accent` / `accentForeground`.

## Accessibility and limitations

- The field is a real input named by `label`; typing and focus are native.
- Rows are buttons with `aria-selected` on the highlighted one; the surface is a
  named group.
- 0.10.0 drops `role="listbox"`/`option` from its accessibility dump and has no
  `aria-activedescendant`, so the list is not announced as a listbox.
- The query comes from the text's last `@` token, not the caret: 0.10.0 exposes
  no caret position, so mid-string editing is not supported and an `@` inside a
  word is ignored.
- A space typed while the list is open is consumed by the runtime before the
  field sees it.
- No async or remote candidates, and the surface label is fixed to "Mentions".
