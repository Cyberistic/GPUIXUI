## Usage

```tsx
import {
  DatePicker,
  DatePickerCalendar,
  DatePickerContent,
  DatePickerTrigger,
} from "@gpuixui/components/date-picker";
import { useState } from "react";

export const DeploymentWindow = () => {
  const [due, setDue] = useState<string | null>("2026-10-30");

  return (
    <DatePicker
      clearable
      max="2026-12-18"
      min="2026-10-26"
      onValueChange={setDue}
      today="2026-10-22"
      value={due}
    >
      <DatePickerTrigger label="Deployment date" />
      <DatePickerContent>
        <DatePickerCalendar />
      </DatePickerContent>
    </DatePicker>
  );
};
```

A span is `mode="range"`: the value is `{ from, to }` of ISO days, the surface
opens on two months, and it closes when the second day completes the span.

```tsx
<DatePicker
  mode="range"
  clearable
  onValueChange={setWindow}
  today="2026-10-22"
  value={window}
>
  <DatePickerTrigger label="Booking window" />
  <DatePickerContent>
    <DatePickerCalendar label="Booking calendar" />
  </DatePickerContent>
</DatePicker>
```

## API reference

### `DatePicker`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `mode` | `"single" \| "range"` | `"single"` | selects the value shape `value` and `onValueChange` speak |
| `value` | `string \| null` · `{ from, to } \| null` | none | the controlled value; `undefined` makes the picker uncontrolled |
| `defaultValue` | `string \| null` · `{ from, to } \| null` | `null` | the opening value when uncontrolled |
| `onValueChange` | `(value \| range \| null) => void` | none | the chosen day, the span, or `null` from Clear |
| `weekStartsOn` | `0 \| 1` | `1` | the grid's first column |
| `min` | `string` | unbounded | the first selectable ISO day, inclusive |
| `max` | `string` | unbounded | the last selectable ISO day, inclusive |
| `clearable` | `boolean` | `false` | adds the Clear row while a value is set |
| `disabled` | `boolean` | `false` | leaves the tab order and does not open the surface |
| `today` | `string` | the runtime clock | the ISO day the grid marks as today |
| `numberOfMonths` | `1 \| 2` | `1`, or `2` in range mode | months painted side by side |
| `showOutsideDays` | `boolean` | `true` | paints the neighbouring months' days |
| `captionLayout` | `"label" \| "dropdown"` | `"label"` | a caption, or month and year jump controls |
| `fromYear` / `toYear` | `number` | today ± 10 | the years a dropdown may reach |
| `children` | `ReactNode` | none | the trigger and the content, directly inside |

### `DatePickerTrigger`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `placeholder` | `string` | `"Pick a date"` | the text painted while no value is set |
| `label` | `string` | — | the trigger's accessible name (the caret is decorative) |
| `variant` | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"secondary"` | the trigger's fill and label role |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | the control height the trigger takes from the theme's density |
| `disabled` | `boolean` | `false` | adds to the root's disabled rule; never removes it |
| `className` | `string` | — | joined after the recipe, so it wins conflicts |
| `testId` | `string` | `"date-picker-trigger"` | the trigger's test identity |
| `onActivate` | `(event) => void` | — | the action's one handler: it opens the surface from a press or an activating key |
| `onClick` | `(event) => void` | — | the deprecated alias; only runs when `onActivate` is absent |

### `DatePickerContent`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` | where the surface anchors relative to the trigger |
| `align` | `"start" \| "center" \| "end"` | `"start"` | the surface's alignment on that side |
| `sideOffset` | `number` | `6` | the gap between trigger and surface, in pixels |
| `className` | `string` | — | joined after the recipe |
| `children` | `ReactNode` | none | the calendar, directly inside |

### `DatePickerCalendar`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | `"Calendar"` | the grid's accessible name |

## Migration

`DatePickerTrigger`, `DatePickerContent` and `DatePickerCalendar` keep their
names and props; `DatePickerCalendar` is now a thin wrapper over `Calendar`, so
the old composition keeps working and the grid gains the new keyboard, the
dropdown caption and the span modes.

Two things changed on purpose:

- the trigger prints shadcn's labels — `"Oct 17, 2026"` instead of
  `"17 October 2026"`, and `"Jan 20 – Feb 4, 2026"` for a span;
- the surface paints the neighbouring months' days by default. Pass
  `showOutsideDays={false}` for the old blank-cell grid.

## Limitations

- No `aria-current`: today is a border, not an attribute.
- No `aria-disabled`: an unavailable day leaves the tab order and is named
  "unavailable".
- Fixed English labels; time of day is the separate Time picker.
