## Usage

```tsx
import {
  Carousel,
  CarouselControl,
  CarouselIndicators,
  CarouselSlide,
  CarouselTrack,
} from "@gpuixui/components";
import { useState } from "react";

export const WorkspacePreviews = () => {
  const [index, setIndex] = useState(0);

  return (
    <Carousel label="Workspace previews" onValueChange={setIndex} value={index}>
      <CarouselTrack>
        <CarouselSlide>Overview</CarouselSlide>
        <CarouselSlide>Activity</CarouselSlide>
        <CarouselSlide>Members</CarouselSlide>
      </CarouselTrack>
      <CarouselControl direction="previous" />
      <CarouselControl direction="next" />
      <CarouselIndicators />
    </Carousel>
  );
};
```

## API reference

### `Carousel`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | — | the region's accessible name; required |
| `value` | `number` | — | controlled slide index; omit to let the carousel keep its own |
| `defaultValue` | `number` | `0` | the opening slide when uncontrolled |
| `onValueChange` | `(value: number) => void` | none | the next index, only when it changed |
| `loop` | `boolean` | `false` | wraps past both ends and keeps both controls live |
| `className` | `string` | — | joined after the recipe, so it wins conflicts |
| `children` | `ReactNode` | none | the track and the controls, directly inside |

### `CarouselTrack`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | none | the slides, as direct children |
| `className` | `string` | — | joined after the recipe |

### `CarouselSlide`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | none | the slide's content |
| `style` | `StateStyle<CarouselSlideState>` | — | `{ active, index }`, merged last |
| `className` | `string` | — | joined after the recipe |

### `CarouselControl`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `direction` | `"previous" \| "next"` | — | which way it steps; required |
| `label` | `string` | `"Previous slide"` / `"Next slide"` | the accessible name |
| `disabled` | `boolean` | `false` | adds to the edge rule; never removes it |

### `CarouselIndicators`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | `"Choose a slide"` | the dot group's accessible name |
| `style` | `StateStyle<CarouselIndicatorsState>` | — | `{ active, count }`, merged last |
| `className` | `string` | — | joined after the recipe |

## Limitations

- The root is a named `group`; 0.11.0 has no `aria-roledescription="carousel"`.
- Dots use `aria-selected`; 0.11.0 has no `aria-current`.
- Only the active slide is mounted.
