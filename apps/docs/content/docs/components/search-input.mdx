## Usage

```tsx
import { SearchInput } from "@gpuixui/components/search-input";
import { Text } from "@gpuixui/primitives";
import { useState } from "react";

export const FileFilter = () => {
  const [query, setQuery] = useState("");
  const [last, setLast] = useState("none");

  return (
    <>
      <SearchInput
        aria-label="Filter files"
        placeholder="Filter files…"
        value={query}
        onValueChange={setQuery}
        onSubmit={setLast}
        onClear={() => setQuery("")}
      />
      <Text role="caption">Last submitted: {last}</Text>
    </>
  );
};
```

## API reference

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `string` | none | the controlled text; omit it to let the field keep its own |
| `defaultValue` | `string` | `""` | the initial text in uncontrolled mode |
| `onValueChange` | `(value: string) => void` | none | every edit, including the clear and `Escape` paths |
| `onChange` | host change event | none | the raw host payload, called before the value is applied |
| `onSubmit` | `(value: string) => void` | none | `Enter`, with the current text |
| `onClear` | `() => void` | none | the clear control or `Escape`, only when the field held text |
| `placeholder` | `string` | `"Search…"` | the hint the field paints — and announces — while the value is empty |
| `disabled` | `boolean` | `false` | `readOnly` plus the half-opacity paint; no ring, no tab stop, and an inert clear target |
| `className` | `string` | none | joined after the recipe, so it wins conflicts |
| `style` | `StateStyle<SearchInputState>` | none | resolved against `{ disabled, focused }` and merged last on the field surface |
| `testId` | `string` | `"search-input"` | the input's locator; the painted hint is `${testId}-hint` |
| `ref` | `Ref<PublicInstance>` | none | the inner `<input>`, composed with the field's own focus ref |
| `onKeyDown` / `onFocus` / `onBlur` | host handlers | none | composed with the field's own; yours runs first |

## Limitations

- The field has **no name of its own**: pass `aria-label` or wrap it in a `Field`.
- The clear control is a labelled 24px target around a 14px glyph.
- **No debounce**: a query fires on every keystroke.
