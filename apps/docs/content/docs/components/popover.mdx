`Popover` floats a surface next to its trigger without making the rest of the
window modal. GPUix's `anchored` layer snaps inside the window but does not flip,
so the component opens on the opposite side when snapping would cover the
trigger and measures `align="center"` from real bounds. It owns the open state,
the dismissal rules and the trigger's re-open guard.

## Usage

```tsx
import {
  Popover, PopoverContent, PopoverTrigger,
} from "@gpuixui/components/popover";

<Popover>
  <PopoverTrigger>Columns</PopoverTrigger>
  <PopoverContent side="bottom" align="end">
    <ColumnToggles />
  </PopoverContent>
</Popover>;
```

## Variants

`PopoverContent` takes `side` (`top`/`right`/`bottom`/`left`, default `bottom`),
`align` (`start`/`center`/`end`, default `start`), `sideOffset` (6) and
`collisionPadding` (8). There is no arrow and no custom anchor element.

## Sizes

The surface has a 200px minimum width; its height follows the content. Spacing,
radius and elevation come from the theme.

## States

Controlled (`open`/`onOpenChange`) or uncontrolled (`defaultOpen`). Escape closes
and returns focus to the trigger; Tab closes and moves on; a press outside closes
without moving focus; a press inside does nothing; clicking the trigger while
open closes it. It shares the dismiss stack with `Dialog`, so the topmost layer
closes first.

## State and ownership

`Popover` owns the open flag when uncontrolled, the dismiss layer and focus
return on Escape; a controlled `open` is available. The consumer owns the
trigger, the content and the open decision. Escape closes it and returns focus
to the trigger; an outside press closes it without moving focus. The trigger's
press guard stops the same gesture from immediately re-opening it.

## Keyboard and focus

Focus moves into the surface on open. The surface is a tab stop but not a trap:
Tab leaves and closes it. The trigger is an ordinary button; Enter/Space toggle
it.

## Theming

The surface paints `colors.popover`/`popoverForeground`, `radius.lg`, a thin
`colors.border`, the `md` elevation and `spacing.lg` padding.

## Accessibility and limitations

- `aria-expanded` is set on the trigger.
- **No `aria-haspopup`, `aria-controls` or `aria-labelledby`** in 0.10.0: the
  link between trigger and surface is positional, not semantic.
- No arrow, custom anchor or backdrop. Keep the content short; a blocking form
  belongs in `Dialog`.
- A press outside hands focus to whatever was pressed, so focus is not restored to
  the trigger on that path. Escape is the keyboard path that restores it.
