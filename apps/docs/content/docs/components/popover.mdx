## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@gpuixui/components/popover";

<Popover>
  <PopoverTrigger variant="secondary">Columns</PopoverTrigger>
  <PopoverContent side="bottom" align="start">
    <ColumnToggles />
  </PopoverContent>
</Popover>;
```

## Composition

```text
Popover
├── PopoverTrigger
└── PopoverContent
```

## API reference

### Popover

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` | uncontrolled |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | none |
| `children` | parts — `PopoverTrigger`, `PopoverContent` | — |

### PopoverContent

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `align` | `"start" \| "center" \| "end"` | `"start"` |
| `sideOffset` | `number` | `6` |
| `collisionPadding` | `number` | `8` |
| `alignOffset` | `number` | `0` |
| `className` | `string` — joined after the surface recipe | — |
| `children` | `ReactNode` — the surface's content | — |

### PopoverTrigger

| Prop | Type | Default |
| ---- | ---- | ------- |
| `onActivate` | `(event) => void` | — |
| `onClick` | `(event) => void` | — |

## Limitations

- `aria-expanded` is on the trigger.
- **No `aria-haspopup`, `aria-controls` or `aria-labelledby`** in `@gpuix/native@0.11.0`; the link between trigger and surface is positional, not semantic.
- Positioning is the runtime's anchored layer: no arrow, no custom anchor element, no backdrop.
