## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@gpuixui/components/popover";

<Popover>
  <PopoverTrigger variant="secondary">Columns</PopoverTrigger>
  <PopoverContent side="bottom" align="start">
    <ColumnToggles />
  </PopoverContent>
</Popover>;
```

## Composition

```text

├── PopoverTrigger
└── PopoverContent
```

## API reference

### Popover

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` | uncontrolled |
| `defaultOpen` | `boolean` | `false` |
| `onOpenChange` | `(open: boolean) => void` | none |
| `children` | parts — `PopoverTrigger`, `PopoverContent` | — |

### PopoverContent

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` — a stored name the union does not carry |
| `align` | `"start" \| "center" \| "end"` | `"center"` — a stored name the union does not carry |
| `sideOffset` | `number` | `6` |
| `collisionPadding` | `number` | `8` |
| `alignOffset` | `number` | `0` |
| `className` | `string` — joined after the surface recipe | — |
| `children` | `ReactNode` — the surface's content | — |

### PopoverTrigger

| Prop | Type | Default |
| ---- | ---- | ------- |
| `onActivate` | `(event) => void` | — |
| `onClick` | `(event) => void` | — |

## Theming

The surface paints the theme's `elevation.lg` beside its 1px `foreground` ring. Its corner is the recipe's fixed **24px** (`rounded-3xl`); the preview follows the platform radius and is the approximation.
