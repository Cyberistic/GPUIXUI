## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@gpuixui/components/drawer";

<Drawer>
  <DrawerTrigger>Filters</DrawerTrigger>
  <DrawerContent label="Filters" side="right" size="md">
    <DrawerHeader>
      <DrawerTitle>Filters</DrawerTitle>
      <DrawerDescription>Narrow the result set.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose variant="ghost">Cancel</DrawerClose>
      <DrawerClose variant="primary">Apply filters</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>;
```

## Composition

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerFooter
    │   └── DrawerClose
    └── (close control)
```

The close control is painted in the box around the panel's own scroller, not
inside it, so a long body scrolls under the control instead of carrying the one
visible way out of the surface. The Tab trap, Escape and an outside press read
that same box
(`packages/components/src/behaviour/drawer.test.tsx` holds the scroll case).

## API reference

### `Drawer`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `open` | `boolean` | uncontrolled | controlled state; omit to let the drawer keep its own |
| `defaultOpen` | `boolean` | `false` | the initial state when uncontrolled |
| `onOpenChange` | `(open: boolean) => void` | none | reports the next state; a controlled drawer does not move until the caller re-renders |
| `dismissible` | `boolean` | `true` | whether Escape and an outside press close the surface; the close control is unaffected |
| `children` | parts | none | `DrawerTrigger`, `DrawerClose` and `DrawerContent` |

### `DrawerContent`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` (required) | none | the dialog's accessible name |
| `side` | `"left" \| "right" \| "bottom"` | `"right"` | the edge the surface is anchored to |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | the requested width or height, clamped by the window |
| `showClose` | `boolean` | `true` | renders the close control, a `@gpuixui/icons` `x` named "Close drawer" |
| `initialFocus` | `() => number \| null` | none | the native id to focus after the surface receives focus |
| `className` | `string` | none | compiled through `@gpuixui/tw` and joined after the recipe |
| `children` | parts | none | the header, title, description, body and footer |

## Limitations

- The runtime role is **`dialog`**, named by the required `label`; focus enters
  the surface on open and returns to the opener on close (unless the opener has
  been destroyed), and `dismissible={false}` consumes Escape and an outside
  press.
- **A dismissed drawer is a ghost, not a target.** It stays painted for its
  **320 ms** exit and the seam's shield takes the presses, while its own close
  control leaves the window's Tab order for that window: the runtime decides the
  order element by element, so a control the library paints has to drop its own
  stop. A control you compose inside the body keeps its stop until the runtime
  publishes an inherited `inert`.
- **No `aria-modal` and no `aria-labelledby`** in `@gpuix/native@0.11.0`, and no
  swipe-to-dismiss: the runtime publishes no drag host. A `size` restored from
  storage that the union does not name paints the house `md` box instead of an
  `undefined` side.
