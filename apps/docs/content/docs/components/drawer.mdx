The drawing opens on the surface: the frame is the window, the `md` panel is
flush to its right edge, and `Filters` opens it again for the slide.

## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@gpuixui/components/drawer";

<Drawer>
  <DrawerTrigger>Filters</DrawerTrigger>
  <DrawerContent label="Filters" side="right" size="md">
    <DrawerHeader>
      <DrawerTitle>Filters</DrawerTitle>
      <DrawerDescription>Narrow the result set.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose variant="ghost">Cancel</DrawerClose>
      <DrawerClose variant="primary">Apply filters</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>;
```

## Composition

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerFooter
    │   └── DrawerClose
    └── (close control)
```

The close control is painted in the box around the panel's own scroller, not
inside it, so a long body scrolls under the control instead of carrying the one
visible way out of the surface. The Tab trap, Escape and an outside press read
that same box
(`packages/components/src/behaviour/drawer.test.tsx` holds the scroll case).

## Surface and motion

The shipped surface is vaul's drawer, not a docked column: the corners **inside**
the window are rounded (`radius.xl`) while the edge it opens from stays flush,
the recipe's `lg` lift is the theme's own, and a `top` or `bottom` sheet wears the
**grabber** — the 40×4 handle at its inner edge, painted by default and removed
with `grabber={false}`. The grabber is decoration: the runtime has no drag host,
so nothing follows the pointer and there are no snap points.

The panel **slides its own span** in from the edge it names — a right `md` drawer
starts 400px outside the window — and the veil clips it while it travels. The
runtime has no `transform`, so the movement is a numeric `left`/`top` offset on
the surface's box; the content keeps its layout because the box moves, not the
flow. It runs on the `slow` level (320 ms), and the grabber and close control
ride the same box. `MotionProvider preference="reduced"` paints the settled
frame at once.

The veil is the page's own background at **55%** — a wash, so the page stays
legible under the surface. The 6px blur shadcn's veil carries is **drawing-only**:
`StyleDesc` has no `filter`/`backdrop-filter`, so the native veil cannot blur
what is behind it.

## API reference

### `Drawer`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `open` | `boolean` | uncontrolled | controlled state; omit to let the drawer keep its own |
| `defaultOpen` | `boolean` | `false` | the initial state when uncontrolled |
| `onOpenChange` | `(open: boolean) => void` | none | reports the next state; a controlled drawer does not move until the caller re-renders |
| `dismissible` | `boolean` | `true` | whether Escape and an outside press close the surface; the close control is unaffected |
| `children` | parts | none | `DrawerTrigger`, `DrawerClose` and `DrawerContent` |

### `DrawerContent`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` (required) | none | the dialog's accessible name |
| `side` | `"left" \| "right" \| "top" \| "bottom"` | `"right"` | the edge the surface is anchored to; a stored name the union does not carry opens on the default `"right"` edge |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | the requested width or height, clamped by the window; a stored name the union does not carry paints the house `"md"` box |
| `showClose` | `boolean` | `true` | renders the close control, a `@gpuixui/icons` `x` named "Close drawer" |
| `grabber` | `boolean` | `true` | paints the vaul handle on a `top` or `bottom` sheet; a column never shows one |
| `initialFocus` | `() => number \| null` | none | the native id to focus after the surface receives focus |
| `className` | `string` | none | compiled through `@gpuixui/tw` and joined after the recipe |
| `children` | parts | none | the header, title, description, body and footer |

## Limitations

- The runtime role is **`dialog`**, named by the required `label`; focus enters
  the surface on open and returns to the opener on close (unless the opener has
  been destroyed), and `dismissible={false}` consumes Escape and an outside
  press.
- **A dismissed drawer is a ghost, not a target.** It stays painted for its
  **320 ms** exit and the seam's shield takes the presses, while its own close
  control leaves the window's Tab order for that window: the runtime decides the
  order element by element, so a control the library paints has to drop its own
  stop. A control you compose inside the body keeps its stop until the runtime
  publishes an inherited `inert`.
- **No `aria-modal` and no `aria-labelledby`** in `@gpuix/native@0.11.0`, and no
  swipe-to-dismiss or snap points: the runtime publishes no drag host, so the
  grabber cannot be dragged. The slide is a numeric `left`/`top` offset rather
  than a `transform`, and the veil cannot blur the page (no `filter`). A `side`
  restored from storage that the union does not name opens on the house `right`
  edge, and a `size` it does not name paints the house `md` box.
