## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@gpuixui/components/tabs";

<Tabs defaultValue="profile">
  <TabsList label="Account settings">
    <TabsTrigger value="profile">Profile</TabsTrigger>
    <TabsTrigger value="notifications">Notifications</TabsTrigger>
  </TabsList>
  <TabsContent value="profile">…</TabsContent>
  <TabsContent value="notifications">…</TabsContent>
</Tabs>;
```

## Composition

```text
Tabs
├── TabsList
│   └── TabsTrigger
└── TabsContent
```

## API reference

### Tabs

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | uncontrolled |
| `defaultValue` | `string` | `""` — no tab selected |
| `onValueChange` | `(value: string) => void` | none |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` — a stored name the union does not carry |
| `activation` | `"automatic" \| "manual"` | `"automatic"` — a stored name the union does not carry |
| `className` | `string` | — |
| `children` | parts — `TabsList`, `TabsContent` | — |

### TabsList

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` | none |
| `className` | `string` | — |
| `children` | parts — `TabsTrigger` | — |

### TabsTrigger

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` (required) | none |
| `disabled` | `boolean` | `false` |
| `style` | `StyleDesc \| (state) => StyleDesc` | none |
| `className` | `string` | — |

## Notes
- `role="tablist"`, `role="tab"`, `role="tabpanel"` and `aria-selected` are exposed.
- **No `aria-orientation`, `aria-controls` or `aria-labelledby`**.
- The list owns the keys; a key event on a focused trigger bubbles to it.
