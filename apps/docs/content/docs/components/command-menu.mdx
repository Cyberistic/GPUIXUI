## Usage

```tsx
import {
  CommandMenu,
  CommandMenuEmpty,
  CommandMenuInput,
  CommandMenuList,
} from "@gpuixui/components/command-menu";

const actions = [
  {
    id: "new-file",
    label: "New file",
    group: "File",
    shortcut: "⌘N",
    perform: newFile,
  },
  {
    id: "toggle-sidebar",
    label: "Toggle sidebar",
    group: "View",
    shortcut: "⌘B",
    perform: toggleSidebar,
  },
];

<CommandMenu open={open} onOpenChange={setOpen} actions={actions}>
  <CommandMenuInput placeholder="Type a command…" />
  <CommandMenuList />
  <CommandMenuEmpty>No matching commands</CommandMenuEmpty>
</CommandMenu>;
```

## Composition

```text
CommandMenu
├── CommandMenuInput
├── CommandMenuList
│   └── CommandMenuItem
└── CommandMenuEmpty
```

## API reference

| Part | Renders | Props |
| ---- | ------- | ----- |
| `CommandMenu` | the composed `Dialog` surface | `open` (required), `onOpenChange` (required), `actions` (required; a stored value that is not a list paints the empty state), `recents` (a stored value that is not a list carries no recents), `filter`, `children` |
| `CommandMenuInput` | host `<input>` | `placeholder` (default `"Type a command…"`; an empty field announces it as `aria-description`), `label` (default `"Search commands"`), `className` |
| `CommandMenuList` | scrolling match column | `className`; the root's ranked matches are its content |
| `CommandMenuItem` | one runnable row | `action` (required), `className` |
| `CommandMenuEmpty` | the no-match message | `children` (default `No matching commands`), `className` |

## Notes
- The field keeps the focus; `↓`/`Ctrl+N`, `↑`/`Ctrl+P`, `Home` and `End` move the highlight, `Enter` runs the active row, `Escape` dismisses.
- A dismissed palette paints for its **320 ms** exit and its field leaves the window's tab order until the runtime inherits `inert`.
- **No `aria-activedescendant` or `aria-controls`**: the active row is visual only.
