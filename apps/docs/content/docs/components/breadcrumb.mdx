## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@gpuixui/components/breadcrumb";

<Breadcrumb maxItems={4}>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink onSelect={() => go("Projects")}>Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbLink onSelect={() => go("GPUIXUI")}>GPUIXUI</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>breadcrumb.tsx</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

## Composition

```text
Breadcrumb
└── BreadcrumbList
    └── BreadcrumbItem
        ├── BreadcrumbLink
        ├── BreadcrumbPage
        └── BreadcrumbSeparator
```

## API reference

| Part | Prop | Type | Default | Consequence |
| ---- | ---- | ---- | ------- | ----------- |
| `Breadcrumb` | `maxItems` | `number` | — | rendered entries to keep; below `3` is clamped to `3`, absent means no collapse |
| `Breadcrumb` | `separator` | `ReactNode` | `/` | the glyph between entries; a node, so a chevron works |
| `Breadcrumb` | `children` | parts | — | `BreadcrumbList` |
| `BreadcrumbList` | `children` | parts | — | the items and any authored separators |
| `BreadcrumbItem` | `children` | parts | — | `BreadcrumbLink` or `BreadcrumbPage` |
| `BreadcrumbLink` | `onSelect` | `() => void` | — | runs on click, `Enter` or `Space` |
| `BreadcrumbLink` | `current` | `boolean` | `false` | renders the current page instead of a link |
| `BreadcrumbPage` | `children` | text | — | the current page; not focusable |
| `BreadcrumbSeparator` | `children` | text | `/` | the default glyph when none is authored |
| all parts | `className` | `string` | — | an extra recipe class, joined last |

## Limitations

- `role="navigation"` with `aria-label="Breadcrumb"`, `role="list"`, and `role="listitem"` on every entry.
- **No `aria-current`** in `@gpuix/native@0.11.0`.
- The collapse ellipsis is a mark named "More", not a button: it does not expand the trail and is not in the tab order.
