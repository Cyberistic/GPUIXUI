The Tier 2 components are composed from the [primitives](/docs/primitives); the data lane ships <code>@gpuixui/data</code> and its own [Data display](/docs/data-display) map.

The filter matches a page's name, purpose, lane, parts, props, limitations and inventory verdict. It travels in the URL (<code>?q=partial</code>), so `DialogFooter`, `onCheckedChange`, `StateStyle`, `aria-orientation` and `preview` are linkable queries.

<ComponentIndex />

A component or primitive page mounts its own browser preview, a browser approximation, labelled as one.

Pages come from `apps/docs/content/docs/components` (curated, with previews) or `packages/components/docs` (the package's own page).

To run a real component, open the companion playground with <code>{playgroundCommand}</code>.
