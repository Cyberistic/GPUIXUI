The index below is generated from the component registry — the same records
that drive the sidebar, the status badges on each page, and the API tables.
Nothing here is hand-maintained, so it cannot disagree with the pages. The
filter searches titles, summaries, the documented props types and the
limitations each record carries; it runs in the browser because these records
are rendered, not part of Fumadocs' full-text index.

Status is honest: `planned` means no implementation exists yet. The support
badge keeps the inventory's own word — `ours` means GPUix provides no such
primitive and this library implements it, `reuse` means it wraps one GPUix does
provide. A component with `partial` support records the limitation and the
strongest honest alternative. The conventions every page assumes — parts,
controlled state, state-aware styles and the keyboard contract — are on
[Component API](/docs/component-api).

The targets that do not have a page yet — the data grid, the workspace and the
specialised editors — are listed with their inventory status on the
[Roadmap](/docs/roadmap).
