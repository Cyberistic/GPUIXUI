## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@gpuixui/components/accordion";

<Accordion type="single" collapsible defaultValue="surface">
  <AccordionItem value="surface">
    <AccordionTrigger>What is a GPUix surface?</AccordionTrigger>
    <AccordionContent>
      A tree of hosted elements the renderer lays out and paints.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="motion">
    <AccordionTrigger>Why does the panel animate?</AccordionTrigger>
    <AccordionContent>Its measured height is the tween target.</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## Composition

```text
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
```

## API reference

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Accordion` | `type` | `"single" \| "multiple"` | required |
| `Accordion` | `collapsible` | `boolean` — single mode only | `false` |
| `Accordion` | `value` | `string \| null` (single) · `ReadonlyArray<string>` (multiple) | — ; a stored open set that is not a list means uncontrolled |
| `Accordion` | `defaultValue` | the same union, for the uncontrolled form | `null` · `[]` — a stored default that is not a list opens no sections |
| `Accordion` | `onValueChange` | `(value: string \| null) => void` · `(values: ReadonlyArray<string>) => void` | — |
| `AccordionItem` | `value` | `string` | required |
| `AccordionItem` | `disabled` | `boolean` | `false` |
| `AccordionTrigger` | `style` | `StateStyle<{ open, disabled, focused }>` | the recipe |
| `AccordionContent` | `children` | `ReactNode` | — |
| any part | `className` | `string` | — |

## Limitations

- Each trigger publishes `aria-expanded` and names its own section.
- **No `aria-controls`**: a panel cannot be referenced from its header.
- The indicator's `aria-label` names the action, not a glyph.
