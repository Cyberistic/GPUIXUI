`Accordion` is a list of collapsible sections that agree on which ones are open.
The two modes have genuinely different state: a single optional value, or an
ordered set. That is a tagged union in `accordion/logic.ts`, not a list plus a
boolean.

## Usage

```tsx
import {
  Accordion, AccordionContent, AccordionItem, AccordionTrigger,
} from "@gpuixui/components/accordion";

<Accordion type="single" collapsible={false} defaultValue="what">
  <AccordionItem value="what">
    <AccordionTrigger>What is GPUix?</AccordionTrigger>
    <AccordionContent>A native rendering runtime…</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## Variants

| Mode | Rules |
| ---- | ----- |
| `type="single"` | opening another section closes the first; toggling the open one is a no-op unless `collapsible` |
| `type="single" collapsible` | toggling the open section closes it, leaving nothing open |
| `type="multiple"` | toggling adds or removes; open order is preserved and duplicates are impossible |

## Sizes

Triggers use the `label` type role at `controlHeight(theme, "lg")`; spacing and
dividers come from the theme.

## States

Controlled or uncontrolled. Single mode reports `string | null` (`null` is the
controlled closed state); multiple mode reports an array. Disabled items are
skipped by clicks and keys and leave the tab order.

## Keyboard and focus

The trigger is a button: Tab reaches it, Enter and Space toggle it. `↓`/`↑`
move focus between enabled headers with wrapping, and `Home`/`End` jump to the
first or last one; moving focus never toggles a section. A disabled header is
skipped by every arrow.

## Theming

Triggers use `colors.foreground` and `colors.primary` on hover; a thin
`colors.border` divides sections, with none after the last. The indicator is a
text glyph (`⌄` / `⌃`) because 0.10.0's style has no `transform` for rotation.

## Accessibility and limitations

- `aria-expanded` on each trigger; the trigger names its section.
- **No `aria-controls`** in 0.10.0; the relationship is positional.
- The indicator carries `aria-label="Expand"` / `"Collapse"`.
- No height animation; the content mounts and unmounts.
- No live scene ships for this component yet; the example and source are real.
