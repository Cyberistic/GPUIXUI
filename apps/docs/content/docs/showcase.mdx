One screen, built only from the public packages: an identity header, a project
card, its form controls and a progress state. It runs on **GPUix's published
WebAssembly renderer** — the real component code, tokens and layout — with the
honest label the rest of the site uses. It is not the native desktop binary;
the playground runs that, and each component page keeps its native evidence.

## The screen

<LiveSurface scene="showcase" title="Showcase" />

The composition is a `ShowcaseScene` in the live-preview project, mounted with
the same two providers as every other scene. The platform toggle and light/dark
mode reach it, so switching Windows or choosing dark repaints it with the active
theme. The scene is deliberately one realistic screen rather than a sampler:
the card, fields and actions are what an application builds.
