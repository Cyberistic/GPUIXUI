---
title: Getting started
description: Build a settings card from the library's parts and run it in a native window.
---

```tsx
import { render } from "@gpuix/react";
import { useState } from "react";
import { Button, Input, Stack, Switch, Text } from "@gpuixui/primitives";
import { themes } from "@gpuixui/tokens";
import { ThemeProvider } from "@gpuixui/tokens/react";
import {
  Card,
  CardContent,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@gpuixui/components/card";

const ProjectSettings = () => {
  const [name, setName] = useState("Atlas");
  const [autoSave, setAutoSave] = useState(true);
  const [saved, setSaved] = useState(false);

  return (
    <Card>
      <CardHeader>
        <CardTitle>Project settings</CardTitle>
      </CardHeader>
      <CardContent>
        <Stack direction="column" gap="md">
          <Input label="Project name" value={name} onValueChange={setName} />
          <Stack align="center" direction="row" gap="sm">
            <Switch
              checked={autoSave}
              label="Save automatically"
              onCheckedChange={setAutoSave}
            />
            <Text role="body">Save automatically</Text>
          </Stack>
          {saved ? (
            <Text role="caption" tone="muted">
              Saved {name}.
            </Text>
          ) : null}
        </Stack>
      </CardContent>
      <CardFooter>
        <Button variant="primary" onActivate={() => setSaved(true)}>
          Save changes
        </Button>
      </CardFooter>
    </Card>
  );
};

render(
  <ThemeProvider theme={themes.dark}>
    <ProjectSettings />
  </ThemeProvider>,
);
```

Only `CardHeader`, `CardContent` and `CardFooter` nest directly in `Card`.

`render` takes **one** element — a fragment at the root paints only its last
child and reports nothing — so keep an app shell's toolbar, body and status bar
as siblings inside one wrapper.

## Run it natively

```sh
nub run dev:playground
```

The same window needs a native binding: a host with no prebuilt one — an Intel
Mac — builds it first, as [Platform support](/installation#platform-support)
describes.

The same module runs in a terminal:

```tsx
render(<App />, { terminal: true });
```
