title: Testing
description: The two test lanes, the check model a native scenario uses, and the report it leaves.
---

| Lane | Question | Where it lives |
| ---- | -------- | -------------- |
| The package's own suite | Does this module compute the right value, and does this component respond to input? | `packages/<package>/src/**/*.test.ts(x)`, run with `vitest` or `@effect/vitest` |
| The native smoke suite | Does the runtime paint, focus, scroll and dismiss as the component assumes? | a scenario in `apps/playground`, against a real renderer or window |

`nub run check:tests` rejects a test that asserts nothing, compares a value with itself, or asserts back what it stubbed.

## `@gpuixui/testing`

The platform-free half of the native suite: it never imports `@gpuix/react` or `@gpuix/native`.

| Namespace | Responsibility |
| --------- | -------------- |
| `Runtime` | `detectRuntime`, `bindingHint` and the `RuntimeStatus` union |
| `Smoke` | `SmokeScenario`, `SmokeHost`, `runScenarios`, `SmokeReport`, `CAPABILITIES` and the assertion types |
| `Native` | `createTestHost` over the synchronous offscreen renderer |
| `Pixels` | `decodePng`, `encodePng`, `pixelAt`, `countColour`, `boundsOfColour`, `crop` |
| `State` | `runCommands` — fold a runtime's commands and query the final state |
| `Report` | `formatReport`, `reportJson`, `passed`, `exitCode` |

```ts
import { Native, Report, Smoke } from "@gpuixui/testing";
import { Effect } from "effect";

const host = Native.createTestHost(renderer);
const report = await Effect.runPromise(
  Smoke.runScenarios(host, scenarios, {
    host: "test-renderer",
    startedAt: Date.now(),
  }),
);
process.stdout.write(`${Report.formatReport(report)}\n`);
process.exitCode = Report.exitCode(report);
```

## Running a suite

```sh
nub run --filter playground smoke
nub run --filter playground build && nub apps/playground/dist/live/run.js --only <id>
```

## Limitations

- **Workspace-internal**: only `apps/playground` depends on it.
- **The two hosts are not interchangeable**: `paintedStyle` and `a11yTree` are offscreen facts; `hover`, `keyDown` and `pixels` are window facts.
- **`verified` means the declared probes ran and passed on this host**, not that the capability should work.
