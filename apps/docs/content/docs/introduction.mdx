**Native components, open source, built on GPUix.**

Every component renders through GPUix host elements: no DOM, CSS or browser runtime.

```tsx
import { Badge } from "@gpuixui/components/badge";
import { lightTheme } from "@gpuixui/tokens";
import { ThemeProvider } from "@gpuixui/tokens/react";

<ThemeProvider theme={lightTheme}>
  <Badge variant="success">Connected</Badge>
</ThemeProvider>;
```

Compound parts validate their placement: a `DialogTitle` inside `Dialog` but
outside `DialogContent` throws, and the message names the parent and what to do
instead.

```tsx
<Dialog>
  <DialogTrigger>Rename project</DialogTrigger>
  <DialogContent label="Rename project">
    <DialogHeader>
      <DialogTitle>Rename project</DialogTitle>
      <DialogDescription>Used everywhere the project is named.</DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose variant="ghost">Cancel</DialogClose>
      <DialogClose variant="primary">Save</DialogClose>
    </DialogFooter>
  </DialogContent>
</Dialog>;
```

Theme roles are data: components read `colors.primary`, `spacing.md` and `radius.md`, never a literal.
