---
title: Registry
description: Install a component's source with the shadcn CLI.
---

A flat shadcn registry: an index at [`/registry.json`](/registry.json) and one
document per item beside it, `/<package>-<component>.json`.

```sh
npx shadcn@latest add https://gpuixui.sudokw.com/primitives-button.json
```

The copied files render through GPUix, not the DOM, so each item declares
`@gpuix/react` and the per-platform `@gpuix/native` binding. The `@gpuixui/*`
packages are private to the repository, so a consuming project installs them
from a checkout with `nub add`.

Names are `<package>-<component>` because the registry is flat and eight page
names belong to two components (`primitives-progress` and `components-progress`).
