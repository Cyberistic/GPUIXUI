## Reading the audit

`mutedForeground on muted — 3.90:1 (needs 4.5:1)`. A ratio that **cannot be
computed** prints **unmeasurable** — a wash, not a pass; the prefix names the
report it came from.

Switch box:

`switch height — 22 cannot hold a knob that needs 32`

`switch width — 0 cannot be laid out (needs a size greater than zero)`

Edits are stored per mode over the platform style; a browser that refuses site
storage keeps the editor. **Reset** clears them; **Copy theme** prints it.

## Bring a shadcn theme

```tsx
import { shadcnTheme } from "@gpuixui/tokens";

const theme = shadcnTheme(css, "dark");
```

A shadcn `styles.css` holds `:root` and `.dark`. **Default** is shadcn's neutral
theme, audited as warnings.
