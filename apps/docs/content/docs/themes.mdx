## Reading the audit

One line per finding: `mutedForeground on muted — 3.90:1 (needs 4.5:1)`.
**Unmeasurable** means the contrast cannot be computed — a translucent colour or
a composited wash — not that it passed; the prefix names the report it came from.

A switch is measured on its box too:
`switch height — 22 cannot hold a knob that needs 32`, and
`switch width — 0 cannot be laid out (needs a size greater than zero)`.

Edits are stored per mode over the selected platform style, so switching
platform re-bases the audit and your edits stay. **Reset** clears them;
**Copy theme** prints the resolved module. A browser that refuses site storage
keeps the editor and the URL.

## The looks

<LookPicker />

A platform style is one of four identity variants; an authored look applies a
style over one. The picker remembers the look in the app, not the URL.

## Bring a shadcn theme

```tsx
import { shadcnTheme } from "@gpuixui/tokens";

const theme = shadcnTheme(css, "dark");
```

`css` is a shadcn `styles.css`: `:root` is light, `.dark` is dark. The roles it
names are taken, `--chart-1…5` become the data scale, and the rest keep the
shipped theme. `shadcnCss(theme)` writes one back out in the same variables.

The **Default** platform is shadcn's neutral black-and-white theme exactly
(`shadcnNeutralTheme`). Its contrast misses are listed as warnings, not errors.
