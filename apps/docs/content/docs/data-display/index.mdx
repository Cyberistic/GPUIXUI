## What ships today

| Surface | Page | What it gives a data view |
| ------- | ---- | ------------------------- |
| Table | [Table](/docs/components/table) | The frame, fixed header, measured body, sort, selection, filter, column menu and virtual body |
| Query builder | [Advanced filtering](/docs/data-display/advanced-filter) | A typed predicate tree a saved query and a filter share |
| Toolbar | [Data toolbar](/docs/data-display/data-toolbar) | A row of controls above the set |
| Frozen columns | [Frozen columns](/docs/data-display/frozen-columns) | `FrozenTable`: a pinned column in its own scroller |
| Tree view | [Tree views](/docs/data-display/tree-view) | One tab stop, arrows, type-ahead and a hierarchy |
| Virtual tree | [Virtual trees](/docs/data-display/virtual-tree) | The same keyboard over a windowed list |
| Expandable rows | [Expandable rows](/docs/data-display/expandable-rows) | A detail panel under its row |
| Key-value | [Key-value](/docs/data-display/key-value) | One object as label/value rows |
| Property panel | [Property panel](/docs/data-display/property-panel) | Editable and read-only rows over an object |
| Metric | [Stat card](/docs/data-display/stat-card) | A derived reading, its unit and trend |
| Virtualization | [Virtualization](/docs/data-display/virtualization) | `VirtualList`, `VirtualTable` and `useVirtualRows` |
| Charts | [Charts](/docs/data-display/charts) | One `<svg>` mask per series |
