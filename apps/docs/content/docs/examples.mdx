Each package keeps a worked example beside its components, generated here from `packages/*/examples/*.example.tsx`. They are GPUix modules, not browser components: the page shows the source, not a rendering.

<ExamplesIndex />

## Running one

```bash
nub run --filter @gpuixui/primitives test:runtime
```

```bash
nub run --filter playground build
nub apps/playground/dist/smoke/run.js --only examples-mount
```

The scenario's checks are in `apps/playground/README.md`.

## Adding one

Create `packages/<package>/examples/<id>.example.tsx` exporting one component with a `<Name> example: …` header, and add it to that package's `examples/index.ts`.
