Run it natively:

```sh
nub run --filter @gpuixui/blocks dev -- macos
```

## Composition

`MacosDesktop({ children, width, height })` in `@gpuixui/blocks/macos`:

- **wallpaper**: two-stop gradients and translucent discs; the runtime paints no
  blur and no filters, so depth is layered fills rather than glass;
- **menu bar**: the Gon mark, the app's name, File · Edit · View · Go · Window ·
  Help, then the battery and the clock. A press opens that menu over the bar; the
  same press, another title, or a press on the desktop closes it. The items are
  labels — nothing pretends to run a command;
- **dock**: a centred plate of app tiles; the running apps wear a dot and a press
  names the app in the bar;
- **`children`**: the floating window layer, so a caller can put a real
  `Window` (and any block inside it) on the desktop.

The menus' state is pure (`nextMenu`, `focusedApp` in `src/macos/logic.ts`), held
by `src/macos/logic.test.ts`, and the two directions of a menu press run on the
real renderer in `src/blocks.test.tsx`.
