Click a conversation to swap the thread, type to filter, press Enter to send.

## The four dresses

`ConversationWindow` takes `platform`; the control set is identical in all four.

- **macOS** — white window, 12px radius, traffic lights left, grey list, blue selected row, green bubbles.
- **Windows 11** — light Fluent window, 8px radius, `− □ ×` right, icon rail, blue bubbles.
- **Linux (Breeze dark)** — dark window, 8px radius, `− □ ×` right, teal rail and selected row, blue bubbles.
- **Omarchy** — the Linux rail in Tokyo Night roles, near-square corners.
