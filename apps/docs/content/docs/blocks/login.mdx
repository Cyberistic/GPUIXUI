A sign-in recipe: a `Card` with email and password fields, a link to reset the
password, a primary action, a divider, two OAuth buttons and a footer that opens
sign-up. Copy the recipe; it is composed from the library, not a new component.

<BlockPreview name="login-01" />

The preview is interactive: submit empty fields for the error state, or a
well-formed address and password to watch the button go busy and the form
resolve. The status row is reserved, so the card never moves between states.

## Composition

The block composes:

- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent` and
  `CardFooter` from `@gpuixui/components/card`
- `Button`, `Input`, `Label`, `Separator`, `Stack` and `Text` from
  `@gpuixui/primitives`

Both are workspace packages already on the component page; the recipe adds no
new dependency. `Button`'s `loading` prop is the busy state, and `fullWidth`
keeps the primary action on the card's edge. Wire `signIn`, `signInWithGitHub`,
`signInWithGoogle`, `forgotPassword` and `openSignUp` to your own handlers.
