Every sidebar block shadcn ships, on one page. Each drawing keeps the shipped
family's geometry — the 256px panel, the 48px icon rail, the 300px list column
and the 36px row — and its controls are live: press a header trigger or a rail
to collapse the panel, a section header to fold it, the page actions or the
account to open their menu, and Escape to close an overlay. Every example is
capped at the block stage's width, never the component panel.
