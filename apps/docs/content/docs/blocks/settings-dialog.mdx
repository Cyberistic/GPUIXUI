A modal settings window: a dimmed stage, a 260px nav pane of settings sections
and a theme pane with three controls. The left nav, the switch, the slider and
the layout cards all change the state a reader can watch.

## Composition

The block composes:

- `Dialog`, `DialogContent` and `DialogTitle` from
  `@gpuixui/components/dialog`, `Avatar` from `@gpuixui/components/avatar`,
  `SearchInput` from `@gpuixui/components/search-input`
- `Button`, `Slider`, `Stack`, `Switch`, `Text` and `useTheme` from
  `@gpuixui/primitives`
- `Icon` from `@gpuixui/icons`

## State

The switch flips `aria-checked` and translates its knob; the slider is a range
input whose value is the `px` label; the layout cards are a radio group, and the
selected one carries an accent ring and a check. Every one of those changes
paint, a ring or a transform — never a border width, padding or size — so the
panel stays still. The check is always in the markup and hidden with
`visibility`, which is why selecting a card cannot move its label.

The preview above is a browser reproduction of the recipe's geometry and
palette; the code tab is the `@gpuixui/*` source. The dimmed stage is the
theme's `overlay` role and the panes read `background`, `card`, `accent`,
`primary`, `secondary`, `border`, `ring` and `shadow`, so the platform and look
switch repaint the window.
