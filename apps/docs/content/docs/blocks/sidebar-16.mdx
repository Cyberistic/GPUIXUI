The workspace with the header above the columns instead of inside the page:
the toggle, the breadcrumb trail and the search field span both the panel and
the content.

<BlockPreview name="sidebar-16" />

## Composition

- `SidebarProvider` wrapping a column `Stack` for the header and a row `Stack`
  for the panel and inset
- `SidebarTrigger`, `Breadcrumb` and `SidebarInput` in the site header
- `Sidebar`, `SidebarHeader`, `SidebarContent`, `SidebarFooter` for the workspace
- `Collapsible` sections, `SidebarMenuSub` pages and `SidebarMenuAction` rows
- `SidebarUserMenu` in the footer
- `Separator`, `Stack` and `Text` from `@gpuixui/primitives`

## Notes

The header belongs to the window, not the page, so it is the first child of the
provider and the two columns sit beneath it. The search field in the header is a
`SidebarInput`, which is the same field the panel's own search uses — one
control, two placements.

The screen above is a browser reproduction of the recipe's geometry and
palette; the disclosure under it holds the `@gpuixui/*` source to copy.
