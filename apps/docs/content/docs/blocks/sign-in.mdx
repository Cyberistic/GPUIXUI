The preview is interactive. Submit empty fields for the validation error,
submit the credentials named in the status row for the success state, and press
**Show** to reveal the password. A submission walks idle → loading → error or
success in a reserved row, so no state moves the card.

## Composition

The page composes:

- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent` and
  `CardFooter` from `@gpuixui/components/card`
- `Button`, `Checkbox`, `Input`, `Label`, `Separator`, `Stack` and `Text` from
  `@gpuixui/primitives`

The page adds no new dependency. The navbar is a `Stack` pair; the form is the
same `Card` the [auth examples](/components/auth) use; the panel is a
`Stack` whose background the application paints. Wire `signIn`,
`signInWithGitHub`, `signInWithGoogle`, `forgotPassword` and `openSignUp` to
your own handlers.
