## Composition

`DesktopBlock({ look })` in `@gpuixui/blocks/desktop`, with `look` `"luna"` or `"aero"`:

- window contents are `Tabs`, `Checkbox`, `Slider`, `Button`, `Text` and `Icon` under `retroTheme`
- the chrome — title bars, caption buttons, the taskbar, the Start button and menu — is drawn in each era's own values, over a shaped wallpaper
- Start opens the menu, a taskbar press raises its window, a desktop press closes the menu
