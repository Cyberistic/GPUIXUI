Run it natively:

```sh
nub run --filter @gpuixui/blocks dev -- notes
```

## Composition

`Notes` in `@gpuixui/blocks/notes`, inside the shell's native window where it has one:
the folders' source list, the note list and a `TextArea` editor whose typing rewrites the row's excerpt. Its rules are pure and tested in `examples/blocks/src/mac-blocks.logic.test.ts`,
and its primary interaction runs on the real renderer in `src/mac-blocks.test.tsx`.
