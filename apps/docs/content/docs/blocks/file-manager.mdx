A file-browser recipe: a folder rail with a storage meter, a folder of image
tiles with breadcrumbs, and an information rail for the selected file. Copy the
recipe; it is composed from the library, not a new component.

<BlockPreview name="file-manager-01" />

The preview is interactive: click a tile to repaint the information rail, switch
the four view buttons (`eye`, `list`, `grid`, `columns`) to change the layout,
or pick another folder in the tree to move the breadcrumb. `My files` is the
root: from there the centre pane asks for a folder, and the parent link is
disabled rather than hidden, so nothing moves. The selected tile keeps a 2px
ring in a border that is always present — transparent at rest — so a selection
never nudges the grid.

## Composition

The block composes:

- `Breadcrumb` and its parts from `@gpuixui/components/breadcrumb`,
  `SearchInput` from `@gpuixui/components/search-input`
- `Button`, `Progress`, `ScrollArea`, `Stack` and `Text` from
  `@gpuixui/primitives`
- `Icon` from `@gpuixui/icons`

The tiles are placeholder gradients drawn from the theme's five categorical
[data series](https://github.com/Cyberistic/GPUIXUI/blob/master/docs/tokens.md#data-series), so the platform and look switch
repaints them with the rest of the preview. A real app replaces the gradient
with a thumbnail and passes the scan's own type, size, date, contrast and
`ExifFDPointer` into the facts list. The rails narrow with the block: the
information rail drops out below 720px of the block's own width, and the
viewport's 1100px breakpoint drops it too, leaving the grid the width it frees.
