The opening sidebar: the docs' version switcher over a search field, then four
labelled sections, and the current page beside them under a breadcrumb header.

<BlockPreview name="sidebar-01" />

## Composition

- `SidebarProvider`, `Sidebar`, `SidebarInset` and `SidebarRail` from
  `@gpuixui/components`
- `SidebarHeader`, `SidebarContent`, `SidebarGroup`, `SidebarGroupLabel`,
  `SidebarGroupContent`, `SidebarMenu`, `SidebarMenuItem` and
  `SidebarMenuButton` for the panel
- `SidebarInput` for the search field, `SidebarTrigger` for the header toggle
- `Breadcrumb`, `BreadcrumbList`, `BreadcrumbItem`, `BreadcrumbLink`,
  `BreadcrumbPage` and `BreadcrumbSeparator` for the trail
- `Stack`, `Text` and `Separator` from `@gpuixui/primitives`

## Notes

Every section is plain rows with no collapse: `SidebarMenuButton` carries the
tooltip that icon mode shows, and `isActive` marks **Data Fetching** on the
same row the breadcrumb names. The rail toggles the panel; the header toggle
does too, so the block reads the same on a narrow window where the panel is the
sheet.

The screen above is a browser reproduction of the recipe's geometry and
palette; the disclosure under it holds the `@gpuixui/*` source to copy.
