Run it natively:

```sh
nub run --filter @gpuixui/blocks dev -- license
```

## Composition

`License` in `@gpuixui/blocks/license`, in the shell's native window: the
registry's `SourceList` (everyone, the star hunters, each specialty), the
chosen hunter's licence card — drawn from the theme's roles and the Gon mark —
and its privileges as an `InsetGroup` of `Switch`es. The directory's order (most
stars first) and the rank titles are pure rules in
`examples/blocks/src/license/logic.ts`.
