---
title: Blocks
description: Page-level recipes composed from the library — copy, adapt and ship.
---

Blocks are **recipes, not components**: a page composed from the primitives and
components already in the library. Copy the source, wire your handlers and
theme, and ship. As in shadcn/ui, each block is a browser rendering of the
native parts plus the real `@gpuixui/*` source to copy.
