## Composition

- `Sidebar` from `@gpuixui/components/sidebar` for the rail's panel, group and footer
- `FileTree` from `@gpuixui/files` for the vault's branches, fold and current note
- `Breadcrumb` from `@gpuixui/components/breadcrumb` for the trail
- `Button` from `@gpuixui/primitives` for the view pills and the stage filter
- `Badge` from `@gpuixui/components/badge` for the chips

The note is the drawing's own: a properties list, list rows for the pipeline, a
bullet for each dossier and a callout for what blocks one. The window chrome and
the chart have no shipped part, so they are painted here.
