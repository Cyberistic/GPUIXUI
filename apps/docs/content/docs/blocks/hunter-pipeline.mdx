The dashboard a guild reads before it deploys anyone: how much renown the
fortnight brought, which stage each dossier sits in, what is staged, what a
missing fact holds, and the shape of the last eight nights.

<BlockPreview name="hunter-pipeline-01" />

## Composition

The block composes:

- `Button` from `@gpuixui/primitives` for the four view pills and the stage
  filter
- `Card` from `@gpuixui/components/card` for the five readings, the seven
  stage cells and the dossier rows
- `Badge` from `@gpuixui/components/badge` for the bank, rank and length chips
- `Text` from `@gpuixui/primitives` for the `caption` labels and the `h3`
  numbers

The chart is drawn, not shipped: the runtime has no chart host, so the block
paints two polylines over the same night list the readout reads.

## What a reader can change

- **The stage filter** narrows the strip to the open stages or to the verified
  one; `all` keeps every stage.
- **A day on the chart** picks the night the readout prints.
