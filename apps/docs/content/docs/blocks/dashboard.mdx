## Composition

The block composes:

- `Sidebar`, `SidebarProvider`, `SidebarInset` and the menu parts from
  `@gpuixui/components/sidebar` — the workspace switcher, Quick Create, both
  nav groups and the account row
- `Card` from `@gpuixui/components/card` for the four KPI tiles and the two
  panels
- `LineChart` from `@gpuixui/data` — the area wash is the chart's own
- `Tabs` from `@gpuixui/components/tabs`, over `Table`, `TableHeader`,
  `TableRow` and the cells from `@gpuixui/data`
- `Badge` for the status pills, `ToggleGroup` for the range, `Checkbox` for the
  rows, `Text`/`Stack`/`Button`/`Icon` for the rest

## What moves

The range control swaps the chart's labels, values and total; the tab strip
swaps the table's rows; the header checkbox selects every row the open tab holds
and the footer counts what is chosen. All three are the block's own state, so
the live preview can be driven rather than read.

The runtime paints an `<svg source>` as **one tint**, so a multi-series chart is
one stacked element per colour. `LineChart` draws its line and its wash that
way, in the theme's first categorical swatch.

## Run it natively

```sh
nub run --filter @gpuixui/blocks dev -- dashboard
```
