A password-reset recipe: a `Card` with one email field, a primary action, an
inline note once the link is sent, and a footer back to sign-in. Copy the
recipe; it is composed from the library, not a new component.

<BlockPreview name="forgot-password-01" />

The preview is interactive: submit an empty or malformed address for the error
state, or a valid one to watch the button go busy and the link resolve. The
success note names the address it was sent to. The status row is reserved, so
the card never moves between states.

## Composition

The block composes:

- `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardContent` and
  `CardFooter` from `@gpuixui/components/card`
- `Button`, `Input`, `Label`, `Stack` and `Text` from `@gpuixui/primitives`

Both are workspace packages already on the component page; the recipe adds no
new dependency. The note is a `Text` with `role="caption"`, so it sits on the
theme's type scale instead of a hand-set size. Wire `sendResetLink` and
`openSignIn`; keep the flow on one page so a mistyped address does not lose the
form.
