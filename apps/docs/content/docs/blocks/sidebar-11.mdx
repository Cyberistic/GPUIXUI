The file sidebar: the working tree's three changes with their state, then the
repository as a collapsible tree with the UI folder open on the active file.

<BlockPreview name="sidebar-11" />

## Composition

- `SidebarProvider`, `Sidebar`, `SidebarInset` and `SidebarRail` from
  `@gpuixui/components`
- `SidebarGroup`, `SidebarGroupLabel`, `SidebarMenu`, `SidebarMenuItem` and
  `SidebarMenuButton` for both lists
- `SidebarMenuBadge` for the M/U state beside each change
- `Collapsible`, `CollapsibleContent` and `SidebarMenuSub` per folder
- `Breadcrumb` and its parts for `components / ui / button.tsx`
- `Stack`, `Text` and `Separator` from `@gpuixui/primitives`

## Notes

The tree is data: one recursive `Tree` component renders a folder as a
`SidebarMenuButton` plus a `SidebarMenuSub`, and a file as one button. A folder
that is closed keeps its row; `components` and `ui` start open because they
lead to the active file. The changes list is deliberately short — the block is
about the tree, not the diff.

The screen above is a browser reproduction of the recipe's geometry and
palette; the disclosure under it holds the `@gpuixui/*` source to copy.
