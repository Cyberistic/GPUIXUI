Text in GPUIXUI is a named role, not a font size at the call site. A role
carries size, weight and line height together, so a heading cannot drift from the
typographic scale. The scale is shared by both themes and is not changed by
density.

rendered at the role it documents.

## Families

## Custom fonts on the pinned runtime

The repository pins `@gpuix/react` and `@gpuix/native` to **0.10.0**. That
published release exposes no `registerFont` API, so an application cannot
register its own typeface with it: the library can only use the system UI font and
the platform monospace families above.

`registerFont` exists on GPUix's `main` branch but is not in the published
release. Shipping a bundled UI or brand face is tracked as plan
[`052-register-font.md`](https://github.com/Cyberistic/GPUIXUI/blob/master/.agents/slop/plans/052-register-font.md)
and its native proof is blocked by the binding-install blocker (B1). Until both
land, treat custom faces as unsupported rather than documented-but-missing.
