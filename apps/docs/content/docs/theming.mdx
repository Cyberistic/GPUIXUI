## Theme shape

| Field | What it decides |
| ----- | --------------- |
| `colors` | semantic roles: surfaces, text, actions, status, borders, focus |
| `typography` | display, headings, body, label, caption, code and families |
| `spacing` | the spacing scale for gaps and padding |
| `radius` | `sm` through `xl` and `full` |
| `density` | control heights and horizontal padding for `sm`, `md`, `lg` |
| `elevation` | the shadow steps (`sm`, `md`, `lg`) |
| `borderWidth` | thin and strong boundaries |
| `iconSize` | icon sizes paired with each type role |

## Colour roles

| Role | Use |
| ---- | --- |
| `background` | window and application canvas |
| `foreground` | default text |
| `card` | raised content surface |
| `popover` | menus, popovers and dialogs |
| `primary` / `primaryForeground` | primary action and its text |
| `secondary` | secondary action |
| `mutedForeground` | secondary text |
| `accent` | tinted emphasis surface |
| `hover` / `active` / `selected` | pointer, press and chosen-row washes |
| `destructive` | destructive action |
| `border` / `borderStrong` | decorative and essential boundaries |
| `ring` | focus ring |

The full catalogue is [`docs/tokens.md`](https://github.com/Cyberistic/GPUIXUI/blob/master/docs/tokens.md).

## Code colours

A code host paints from the theme's `syntax` table — {syntaxRoles.length} token types from `comment` to `invalid`. `syntaxColors(theme)` answers one colour per role, and `syntaxFailures(theme)` holds each to its floor on the two fills a host paints (<TokenList names={syntaxSurfaces} />): a comment answers {contrastFloors.secondary}:1, a code role {contrastFloors.body}:1.

This site's blocks use the same palette: `apps/docs/src/lib/code-theme.ts` builds both schemes from `syntaxColors(themes[mode])`.

## Override a theme

`createTheme` starts from a built-in mode; `extendTheme` merges into a base without mutating it.

```tsx
import { createTheme } from "@gpuixui/tokens";

export const acmeDark = createTheme({
  mode: "dark",
  name: "Acme",
  colors: {
    primary: "#B49CFF",
    primaryForeground: "#1C1547",
    ring: "#9B8CFF",
  },
  radius: { md: 8 },
  density: "compact",
});
```

Only what changes is written; every other role is inherited.

## Density

`compact` for toolbars and data-dense surfaces; `comfortable` is the default. Density changes control geometry, never type.

## Focus rings

| Focus arrives by | Helper | What paints |
| ---------------- | ------ | ----------- |
| `Tab`, or a field taking focus | `keyboardFocusRing(theme)` | the `focusVisible` outline, offset from the control's fill |
| a press, or code opening a surface | `focusRing(theme)` | a zero-blur box shadow |

## Platform styles

```tsx
import { platformTheme, themes } from "@gpuixui/tokens";

const windows = platformTheme(themes.dark, "win32");
```

A high-contrast base keeps its own colours and takes only geometry and families.

A browser that refuses site storage keeps the URL's choice and the identity, and does not remember the choice.

### The look parameter

`?look=` selects an authored style (Luna, Aero, Omarchy); the sidebar offers platforms only.

## Read the theme

```tsx
import { useTheme } from "@gpuixui/tokens/react";

const theme = useTheme();
const muted = theme.colors.mutedForeground;
```
