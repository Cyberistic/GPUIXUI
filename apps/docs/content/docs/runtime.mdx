| Capability | Status | Workaround |
| ---------- | ------ | ---------- |
| Terminal rendering | Supported | `render(<App />, { terminal: true })`, or `GPUIX_TERMINAL=1` |
| Headless `Dialog` | Supported | `@gpuix/react/dialog` owns Escape and the Tab trap |
| Tab / Shift+Tab focus | Supported | default; `preventDefault()` keeps one Tab |
| `transform` | Not supported | animate motion with `@gpuixui/motion`; static rotate/scale is unavailable |
| Grid span | Not supported | size the track with `gridTemplateColumns`/`gridTemplateRows` |
| Canvas drawing | Not supported | render `svg` or compose `div`/`svg` primitives |
| IME composition | Not supported | compose at the application layer from `onInput`/`onKeyDown` |
| Global shortcut | Not supported | window-level `onKeyDown` |
| Tray / menu bar | Not supported | ship an in-window menu |
| Native view / webview | Not supported | use `markdown`/`code`/`diff` surfaces |

## A window measured

The matrix above is built from the typings. Some rules a reader needs are not in
a type, so a probe in a window measured them; `docs/gpuix-capabilities.md`
carries the detail.

| Rule | What a window measured | Use instead |
| ---- | ---------------------- | ----------- |
| In-window application chrome | the shipped `AppMenu`/`Toolbar`/`StatusBar` paint in a window: a dropdown lands below its trigger, `Escape` returns the focus to it, the toolbar's roving moves the **window's** focus and skips a disabled action, and a status tone paints its own ink (`app-chrome-lifecycle`, 47 checks) | the app paints its own top and bottom rows; toggle the toolbar overflow with `Enter`, and open a menu with a press rather than relying on the hover |
| A modal contains the wheel | the shipped `DialogContent` paints one `<anchored occlude>` veil over the page, and it is a wall: a wheel on the veil moves neither the page nor the modal body, a wheel inside the body scrolls it by its delta and clamps against its own content, and `Escape` leaves the page where the reader left it (`modal-scroll-lifecycle`, 35 checks) | mount the shipped `Dialog`; no scroll lock is needed. Read the body's own `onScrollChange`, and keep a close control outside the scrolling body |
| An interrupted animation continues | a box driven from **120** to **400** and cut to **240** a quarter of the way in painted **191.5** at the cut and **192** in the cut's frame, then settled on **240**; the reverse run read **329.5** and **329.5** and settled on **400** — the next run starts from the visible width, not from the old start or target, and keeps its own full duration (`motion-interruption`, 18 checks) | retarget state mid-flight; budget the new run's whole duration, and chain on the state a completion sets rather than a retarget plus its report |

## The browser build

The pinned release ships a 19.2 MiB wasm renderer beside the `.node` binding; [/live](/live) paints through it. A second `init()` fails with `GPUIX web is already running`. The previews on this site are a browser approximation.

| Constraint | What it means for a page |
| ---------- | ------------------------ |
| One canvas, one window per document | a second `init()` fails; leaving the surface means reloading |
| Cross-origin isolation | needs `Cross-Origin-Opener-Policy: same-origin` and `Cross-Origin-Embedder-Policy: require-corp`; without them `SharedArrayBuffer` is absent and it never starts |
| WebGPU or WebGL2, or nothing | a browser with neither gets no surface; provide a plain-text fallback |

## `isTerminal()`

`isTerminal()` is `false` until `init()` runs, so read it while rendering:

```tsx
import { isTerminal } from "@gpuixui/runtime";

if (isTerminal()) {
  // render without the macOS traffic-light space
}
```

## Refusals are typed

A gap is an error value, not a thrown string. `unsupportedFeatures` names every key the matrix refuses, and `unsupportedFeature(key)` returns the `UnsupportedRuntimeFeature` a caller can catch — it carries the same reason and workaround the table prints.

```ts
import { Effect } from "effect";
import {
  UnsupportedRuntimeFeature,
  unsupportedFeature,
  unsupportedFeatures,
} from "@gpuixui/runtime";

const attempt = Effect.fail(unsupportedFeature("nativeView"));

export const recover = Effect.catchTag(
  attempt,
  "UnsupportedRuntimeFeature",
  (error: UnsupportedRuntimeFeature) =>
    Effect.succeed(`${error.feature}: ${error.workaround}`),
);

unsupportedFeatures; // the refused keys, in matrix order
```

## Read the matrix from code

```ts
import { capabilities, unsupportedFeature } from "@gpuixui/runtime";

capabilities.transform.supported; // false
const refusal = unsupportedFeature("gridSpan");
```
