Five primitives are documented in depth in the [Components](/components)
section, where their previews and copyable source live, so their rows below link
there: [Button](/components/button),
[Checkbox](/components/checkbox), [Select](/components/select),
[Switch](/components/switch) and [Tooltip](/components/tooltip). The
package pages for those five — and the old `/primitives/<name>` addresses —
open the same page.

## Layout

| Primitive | What it is |
| --------- | ---------- |
| [Box](/primitives/box) | The one container — a semantic surface and flex facts |
| [Stack](/primitives/stack) | Children along one axis, spaced by the theme scale |
| [Grid](/primitives/grid) | Equal tracks in two dimensions |
| [Separator](/primitives/separator) | One theme-coloured rule, with an optional caption |
| [Spacer](/primitives/spacer) | A fixed step, or a flexible filler |
| [ScrollArea](/primitives/scroll-area) | A bounded container that scrolls |

## Type and icons

| Primitive | What it is |
| --------- | ---------- |
| [Text](/primitives/text) | One run of type, named by a theme role and a tone |
| [Label](/primitives/label) | A control's name, required marker and description |
| [Icons](/icons/icon) | 81 monochrome icons and their size scale |

## Actions

| Primitive | What it is |
| --------- | ---------- |
| [Button](/components/button) | The primary action, with busy and disabled states |
| [Icon button](/primitives/icon-button) | A square, icon-only action with a required name |
| [Button group](/primitives/button-group) | A row of related actions |
| [Toggle](/primitives/toggle) | A button with a persistent on/off state |
| [Toggle group](/primitives/toggle-group) | Related modes in one toolbar |

## Text and numeric inputs

| Primitive | What it is |
| --------- | ---------- |
| [Input](/primitives/input) | A single-line text field |
| [Text area](/primitives/textarea) | A multi-line text field sized in rows |
| [Number field](/primitives/number-field) | A number field with steps and optional bounds |
| [OTP field](/primitives/otp-field) | A one-time code in length cells |

## Choice

| Primitive | What it is |
| --------- | ---------- |
| [Select](/components/select) | One choice from a list |
| [Checkbox](/components/checkbox) | An independent yes/no, optionally indeterminate |
| [Checkbox group](/primitives/checkbox-group) | Several choices sharing one tab stop |
| [Radio group](/primitives/radio-group) | One choice from a small set |
| [Switch](/components/switch) | An immediate on/off |
| [Slider](/primitives/slider) | A value on a track |
| [Range slider](/primitives/range-slider) | The two ends of one interval |
| [Rating](/primitives/rating) | A whole number of stars, or none |

## Value and progress

| Primitive | What it is |
| --------- | ---------- |
| [Progress](/primitives/progress) | A determinate or indeterminate progress bar |
| [Meter](/primitives/meter) | A measurement inside a range |

## Feedback

| Primitive | What it is |
| --------- | ---------- |
| [Skeleton](/primitives/skeleton) | A pulsing placeholder |
| [Spinner](/primitives/spinner) | Three dots, because the runtime cannot rotate |
| [Tooltip](/components/tooltip) | A short label on hover or keyboard focus |
| [Theme provider](/primitives/theme-provider) | Supplies the theme every primitive draws with |
