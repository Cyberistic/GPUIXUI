Five primitives are documented in depth in the [Components](/docs/components)
section, where their previews and copyable source live, so their rows below link
there: [Button](/docs/components/button),
[Checkbox](/docs/components/checkbox), [Select](/docs/components/select),
[Switch](/docs/components/switch) and [Tooltip](/docs/components/tooltip). The
package pages for those five — and the old `/docs/primitives/<name>` addresses —
open the same page.

## Layout

| Primitive | What it is |
| --------- | ---------- |
| [Box](/docs/primitives/box) | The one container — a semantic surface and flex facts |
| [Stack](/docs/primitives/stack) | Children along one axis, spaced by the theme scale |
| [Grid](/docs/primitives/grid) | Equal tracks in two dimensions |
| [Separator](/docs/primitives/separator) | One theme-coloured rule, with an optional caption |
| [Spacer](/docs/primitives/spacer) | A fixed step, or a flexible filler |
| [ScrollArea](/docs/primitives/scroll-area) | A bounded container that scrolls |

## Type and icons

| Primitive | What it is |
| --------- | ---------- |
| [Text](/docs/primitives/text) | One run of type, named by a theme role and a tone |
| [Label](/docs/primitives/label) | A control's name, required marker and description |
| [Icons](/docs/icons/icon) | 80 monochrome icons and their size scale |

## Actions

| Primitive | What it is |
| --------- | ---------- |
| [Button](/docs/components/button) | The primary action, with busy and disabled states |
| [Icon button](/docs/primitives/icon-button) | A square, icon-only action with a required name |
| [Button group](/docs/primitives/button-group) | A row of related actions |
| [Toggle](/docs/primitives/toggle) | A button with a persistent on/off state |
| [Toggle group](/docs/primitives/toggle-group) | Related modes in one toolbar |

## Text and numeric inputs

| Primitive | What it is |
| --------- | ---------- |
| [Input](/docs/primitives/input) | A single-line text field |
| [Text area](/docs/primitives/textarea) | A multi-line text field sized in rows |
| [Number field](/docs/primitives/number-field) | A number field with steps and optional bounds |
| [OTP field](/docs/primitives/otp-field) | A one-time code in length cells |

## Choice

| Primitive | What it is |
| --------- | ---------- |
| [Select](/docs/components/select) | One choice from a list |
| [Checkbox](/docs/components/checkbox) | An independent yes/no, optionally indeterminate |
| [Checkbox group](/docs/primitives/checkbox-group) | Several choices sharing one tab stop |
| [Radio group](/docs/primitives/radio-group) | One choice from a small set |
| [Switch](/docs/components/switch) | An immediate on/off |
| [Slider](/docs/primitives/slider) | A value on a track |
| [Range slider](/docs/primitives/range-slider) | The two ends of one interval |
| [Rating](/docs/primitives/rating) | A whole number of stars, or none |

## Value and progress

| Primitive | What it is |
| --------- | ---------- |
| [Progress](/docs/primitives/progress) | A determinate or indeterminate progress bar |
| [Meter](/docs/primitives/meter) | A measurement inside a range |

## Feedback

| Primitive | What it is |
| --------- | ---------- |
| [Skeleton](/docs/primitives/skeleton) | A pulsing placeholder |
| [Spinner](/docs/primitives/spinner) | Three dots, because the runtime cannot rotate |
| [Tooltip](/docs/components/tooltip) | A short label on hover or keyboard focus |
| [Theme provider](/docs/primitives/theme-provider) | Supplies the theme every primitive draws with |
