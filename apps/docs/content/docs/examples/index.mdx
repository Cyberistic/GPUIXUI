title: Examples
description: Runnable native example applications.
---

Examples are runnable applications, not screenshots. They live under
`examples/` and run through the native playground:

```sh
nub run dev:playground
```

Each example shows a real composition — a settings window, a workspace layout,
a data-heavy table — and each component it uses links back to its own page.

<Callout>
Examples are added as the components they use are implemented and verified.
This page will list the runnable apps and their commands; it will not describe
an app that does not run.
</Callout>
