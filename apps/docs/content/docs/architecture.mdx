## The direction

```
tokens ──▶ tw ──▶ primitives ──▶ components ──▶ data
   └──────▶ icons ──▶ primitives
motion ──▶ primitives
primitives ──▶ editor
data, primitives ──▶ files
primitives, keyboard ──▶ shell
keyboard, runtime, testing   stand alone
```

Each arrow means "may import at build time"; the graph is acyclic. Tokens import nothing in the library, a styling layer never imports a component, and no package imports the docs site.

## Rendering

```
Button variant + size ──▶ className recipe ──▶ classesToStyle(theme) ──▶ StyleDesc
```

A caller's `className` and `style` merge last. See [Styling and recipes](/docs/styling).

A component belongs in `packages/<tier>`, a token or scale in `@gpuixui/tokens`, and a page-level frame in your app or a block.
