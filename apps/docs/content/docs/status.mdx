## How to read a row

- **`done`** — the component ships, with a docs page, an example and a suite.
  **`done (composed)`** is the same promise over parts that already ship: a
  notification centre is toasts plus the app's history, and a media player is a
  transport over frames the caller supplies.
- **`wip` / `todo`** — not shipped. A lane page records what is blocking it.
- **`blocked`** — the component works, but one capability it wants is missing
  from the pinned runtime. **`unsupported`** — no host element exists on
  `@gpuix/native@0.11.0`; the row names the alternative.
- **GPUix** — `yes`/`partial` is the runtime verdict per row, `(measured)`
  means a window probe proved the behaviour, and `unmeasured` (`?`) means the
  runtime was never exercised for that row. The limits behind every `partial`
  are on [Runtime](/runtime).
- **A link** — the row's component has a page. A plain name means the surface
  is taught by a lane page or the runtime matrix instead of a page of its own.

The last section is the **animated primitives catalogue** (plan 600). It is a
catalogue below Tier 5, not a sixth tier: its rows are components with their own
pages, and they are held to the same demo, docs and behaviour-test contract as
every other row.
