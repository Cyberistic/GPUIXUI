GPUIXUI is a reusable component library for desktop applications, rendered by
[GPUix](https://github.com/remorses/gpuix) through its React integration. GPUix
paints through GPUI — Metal, DirectX or Vulkan — so there is no web view and no
Electron.

## What this site is

This site is a **browser application**. It documents and showcases the library.
Where a page has a live scene, it runs the real component code on GPUix's
published WebAssembly renderer — a real GPUix surface, labelled as the browser
renderer and not the desktop binary. Every page also carries its native
evidence (a run, a capture or the suite that drives it), and a static rest state
may carry a labelled browser approximation. No page presents an imitation as
native. See [Architecture](/docs/architecture) for how every preview is
labelled, and `docs/preview-strategy.md` in the repository for the full decision.

## Status

The library is being built in public. The component index records each
component's real status, its GPUix support, and any limitation. A row that says
`planned` has no implementation yet — this site does not present a placeholder
as a finished component.
