GPUIXUI is a reusable component library for desktop applications, rendered by
[GPUix](https://github.com/remorses/gpuix) through its React integration. GPUix
paints through GPUI — Metal, DirectX or Vulkan — so there is no web view and no
Electron.

## What this site is

This site is a **browser application**. It documents and showcases the library;
it does not render it. Where a component cannot be shown running in a browser,
the page says so and names the native suite that drives it rather than
imitating native behaviour. See [Architecture](/docs/architecture) for how every
preview is labelled, and `docs/preview-strategy.md` in the repository for the full decision.

## Where to start

## Status

The library is being built in public. The component index records each
component's real status, its GPUix support, and any limitation. A row that says
`planned` has no implementation yet — this site does not present a placeholder
as a finished component.
