`Window` is the frame every native block wears. The sidebar runs from the top
edge under the traffic lights and paints the theme's `sidebar` material; the
unified toolbar sits over the content column; the content and the inspector are
opaque. On macOS the window is vibrant, so the desktop shows through the
sidebar and toolbar (`/theming#materials`).

```tsx
<Window
  sidebar={<SourceList label="Mailboxes" sections={sections} value={place} onValueChange={setPlace} />}
  toolbar={<WindowToolbar title="Inbox" actions={<SearchInput />} />}
  inspector={<Details />}
>
  <MessageList />
</Window>
```

Open it with `nativeWindowOptions`: a transparent titlebar, the theme's window
background and the lights centred on the toolbar's line. Windows and Linux get
no options and keep the system bar.

```tsx
render(<App />, { title: "Mail", ...nativeWindowOptions(theme, currentPlatform) });
```

| Prop | Type | Default | Consequence |
| --- | --- | --- | --- |
| `sidebar` | `ReactNode` | none | runs under the lights; without one the toolbar reserves their 78-point box |
| `sidebarWidth` | `number` | `220` | fixed; compose a `SplitPane` (`/dock/split-pane`) for a resizable one |
| `toolbar` | `ReactNode` | none | usually a `WindowToolbar` |
| `toolbarStyle` | `"unified" \| "compact"` | `"unified"` | 52 or 38 points tall |
| `inspector` | `ReactNode` | none | a trailing opaque pane, `inspectorWidth` wide (260) |
| `platform` | `PlatformName` | the host's | where the lights float; none in a terminal |

## Source list

`SourceList` is the sidebar's list: 28-point rows with an icon, a label and a
count, titled sections, and one tab stop. ↑/↓/Home/End move the choice and stop
at either end. As on macOS, a row paints **no hover wash**, and the chosen row is
emphasized (the accent fill) only while the list holds focus.

## Following the Mac

The runtime reports neither the accent colour, the Light/Dark choice nor Reduce
Transparency, so `@gpuixui/shell` reads them from `defaults` at the app's
boundary. `watchAppearance` emits the settings now and on each change (polled
every two seconds), and `appearanceOverrides` turns them into a theme edit: the
accent repaints `primary`, `ring` and the selection with a readable ink, and
Reduce Transparency paints every material opaque.

```tsx
const app = watchAppearance.pipe(
  Stream.runForEach((appearance) =>
    Effect.sync(() =>
      setTheme(extendTheme(getTheme(appearance.mode), appearanceOverrides(appearance, base))),
    ),
  ),
  Effect.provide(NodeServices.layer),
);
```

A sandboxed `.app` may be refused the global domain; the read then fails with
`AppearanceReadError` instead of guessing a blue.

## Limits

The runtime reserves no titlebar and reports none, so whether the OS bar is
hidden and where the lights sit are confirmed by eye on macOS
(`docs/gpuix-capabilities.md` §Window chrome). An app's own capture shows
neither the lights nor the blur.
