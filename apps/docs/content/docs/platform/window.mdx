---
title: Window actions
description: Minimise, zoom, fullscreen, rename, and the system's path picker.
---

<ComponentPreview name="platform-file-panel" />

`useWindowActions` binds the window's verbs for the tree it is called in; a host
without them fails at setup, naming them.

```tsx
const window = useWindowActions();

window.minimize();
window.zoom();
window.toggleFullscreen();
window.setTitle("Files");
```

`pickPaths` opens the system panel and answers `Picked` or `Cancelled`, and fails
with `FilePanelError` if the platform refuses.

```tsx
const chosen = await Effect.runPromise(
  window.pickPaths({ directories: true, prompt: "Choose a folder" }),
);

if (chosen._tag === "Picked") copy(chosen.paths);
```

| Action | What it does | Platform |
| --- | --- | --- |
| `activate` | brings the window forward | all |
| `minimize` | sends it to the Dock | all |
| `zoom` | the platform's zoom or maximise | all |
| `toggleFullscreen` | enters or leaves fullscreen | all |
| `setTitle` | renames the window | all |
| `pickPaths` | opens the system path panel | all |
