`TitleBar` is the app's own bar under the window's lights. It reserves their
78-point box, centres the title, and hosts the actions a titlebar carries.

```tsx
<TitleBar title="Files" actions={<WindowButtons />} />
```

| Prop | Type | Default | Consequence |
| --- | --- | --- | --- |
| `title` | `string` | none | the centred window title; omitted leaves the strip to `leading` / `actions` |
| `controls` | `"native" \| "none"` | `"native"` | reserves the lights' box, or 12 points when the window keeps the system bar |
| `density` | `"compact" \| "comfortable"` | `"comfortable"` | 32 or 38 points tall |
| `leading` | `ReactNode` | none | content after the lights: a back chevron, a sidebar toggle |
| `actions` | `ReactNode` | none | trailing window actions |

It only works with a transparent-chrome window: pass `titlebarTransparent` to
`render()` and place the lights with `trafficLightX` / `trafficLightY`. Verified
in a window by the `window-chrome` probe, which measured that the runtime
reserves no titlebar of its own.
