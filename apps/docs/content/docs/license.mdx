GPUIXUI reimplements behaviour from other projects and may reuse source where
the licence permits it. Every reference and every adapted implementation is
recorded before release; the licence inventory is written while the code is
written, not after.

## The library's own licence

No licence has been declared for the library itself. The repository has no
`LICENSE` file at its root and no workspace package manifest carries a `license`
field, so the terms a consumer can rely on are not published: it is not yet
accurate to call this library open source, free to use, or licensed for
commercial use.

The records below are the **references'** licences and the evidence rule for
them, not a grant for this code. Until the owner declares the library's licence
and the published packages carry it, do not redistribute or ship it. This page
states the status; it does not choose the licence.

## How a licence is verified

Read the licence file in the reference clone at the recorded commit. A README
badge is not evidence, and a project's website is not evidence. `LICENSES/README.md`
states the rule and what each file must answer.

## Still owed before release

The inventory and the notices are a release requirement, and they are not
written yet:

- `LICENSE` — the library's own licence, and a `license` field in every
  published package manifest.
- `LICENSES/inventory.md` — one row per dependency and reference: name,
  version or commit, licence, use and obligations.
- `LICENSES/provenance.md` — one row per adapted implementation: source,
  commit, what changed and the licence.
- `LICENSES/NOTICE` — the notices the published package must redistribute.

Until those land, this page names only what a record actually states. It does
not repeat a licence from a project's website.

## Identity

The library's own package name, logo and wordmark are original. No third-party
logos or trademarks are copied into them, and no icon set is vendored under a
name that misrepresents its licence.
