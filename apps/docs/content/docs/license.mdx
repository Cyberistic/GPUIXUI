title: License and attribution
description: Licences and provenance for the library and its references.
---

GPUIXUI reimplements behaviour from other projects and may reuse source where
the licence permits it. Every reference and every adapted implementation is
verified and recorded before release; the licence inventory is written while the
code is written, not after.

Three files must exist before release; none is written yet (the inventory starts
in Phase A, because a licence inventory written after the code is a rewrite):

- `LICENSES/inventory.md` — one row per dependency and reference.
- `LICENSES/provenance.md` — one row per adapted implementation.
- `LICENSES/NOTICE` — the notices the package must redistribute.

`LICENSES/README.md` records what each file must answer and the evidence rule
(a licence is verified by reading it in the reference clone, never a README
badge).

The library's own identity — package name, logo and wordmark — is original. No
third-party logos or trademarks are copied into it.
