GPUIxUI reimplements behaviour from several projects and ports some motion
physics. Each of them has a record in
[`LICENSES/`](https://github.com/Cyberistic/GPUIXUI/tree/master/LICENSES), and
this page is those records — not a summary of them. A reference that gains a
record appears here with no docs change, and a reference whose terms were never
verified cannot hide behind prose.

## How a record is written

- The licence is read from the licence file in the clone, at the commit the
  record names — never from a README badge.
- **Inspiration** and **copied or ported source** carry different obligations, so
  every record says both what we take and what we do not take.
- A notice we must redistribute is carried in `LICENSES/NOTICE`.
- No project's logo or trademark is used. The identity, the name and the docs
  design are original.

The records above are the part of the release inventory that is written. The
footer under the table names the artefacts still outstanding, read from the
directory itself: the licence inventory, the provenance table and the
redistributed notices. A release is blocked until none are named.

## Using a reference in your own work

The library's source is not a copy of any of these projects — the records say
what was translated and what was left out. If you reimplement behaviour from
them in turn, read their licence and preserve their notice; that is the same
obligation this page records for us.
