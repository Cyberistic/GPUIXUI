## Usage

```tsx
import { AppMenu, type AppMenuEntry } from "@gpuixui/shell";

const menus: ReadonlyArray<AppMenuEntry> = [
  {
    id: "file",
    label: "File",
    items: [
      { id: "new", label: "New file", accelerator: "mod+n" },
      { id: "save", label: "Save", accelerator: "mod+s" },
    ],
  },
  { id: "edit", label: "Edit", items: [{ id: "undo", label: "Undo", accelerator: "mod+z" }] },
];

<AppMenu label="Editor" menus={menus} onSelect={(menuId, itemId) => run(menuId, itemId)} />;
```

## Pointer

A closed bar opens nothing on hover: a menu opens on press. Once one menu is
open, moving the pointer onto a sibling title switches to that menu at once and
closes the previous one, the macOS menu-bar rule; pressing the open title again
closes it. Moving off a title into its dropdown keeps the dropdown open.

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `AppMenu` | `div` with `role="menubar"` | `label?`, `menus` (required), `platform?`, `onSelect?`, `className?` |
| `AppMenuItem` | a dropdown row | `id`, `label`, `accelerator?`, `disabled?` |
| `AppMenuEntry` | a top-level menu | `id`, `label`, `disabled?`, `items` |

## Limitations

- **No native menu bar**: this is an in-window `div` and dropdowns; the runtime's menu is fixed and unaddressable.
- **Highlight, not focus.** Rows are highlighted with `aria-selected`; a screen reader gets no `aria-activedescendant` (0.11.0 publishes none).
- Accelerator labels are display-only; no chord is registered.
