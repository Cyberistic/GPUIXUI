---
title: Toolbar
description: A horizontal action strip with an overflow menu
---

## Usage

```tsx
import { Toolbar, type ToolbarAction } from "@gpuixui/shell";

const actions: ReadonlyArray<ToolbarAction> = [
  { id: "open", label: "Open", icon: "file", group: "file" },
  { id: "save", label: "Save", icon: "download", group: "file" },
  { id: "copy", label: "Copy", icon: "copy", group: "edit" },
  { id: "link", label: "Link", icon: "link", group: "edit" },
];

<Toolbar label="Document" max={5} actions={actions} onAction={(id) => run(id)} />;
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Toolbar` | `div` with `role="toolbar"` | `label?`, `actions` (required), `max?`, `onAction?`, `modes?`, `mode?`, `onModeChange?`, `modesLabel?`, `className?` |
| `ToolbarAction` | one `Button` in the leading group | `id`, `label`, `icon?`, `group?`, `disabled?` |
| `ToolbarMode` | one option in the trailing `ToggleGroup` | `id`, `label`, `disabled?` |

The strip is a leading group of actions, a flexible spacer, then the trailing
group — the mode group and the overflow trigger.

## Limitations

- `max` is a **count** of visible slots, not a measured width.
- The overflow menu's rows are click- and Escape-operated; they do not re-run the strip's arrow-key roving.
