## Usage

```tsx
import { PanelGroup, PanelLayout, Panel } from "@gpuixui/dock";
import { useState } from "react";

const initial = new PanelLayout({
  orientation: "horizontal",
  panels: [
    new Panel({ id: "sidebar", label: "Sidebar", size: 0.2, collapsible: true }),
    new Panel({ id: "editor", label: "Editor", size: 0.8 }),
  ],
});

const [layout, setLayout] = useState(initial);

<PanelGroup
  layout={layout}
  onLayoutChange={setLayout}
  renderPanel={(id) => <Pane id={id} />}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `layout` | `PanelLayout` | — | the persisted shape; controlled |
| `onLayoutChange` | `(layout: PanelLayout) => void` | — | the next shape after a resize or a collapse |
| `renderPanel` | `(id: string) => ReactNode` | — | one pane's content |
| `className` | `string` | — | joined after the recipe |

## Limitations

- The layout is **controlled**: resize and collapse report through `onLayoutChange`.
- Fractions need not sum to one; `normalizePanels` rescales them.
- A collapsed pane's content leaves the tree and the remaining panes fill the gap.
- The preview is a fixed 620px drawing: a divider's 16px step is converted against that frame, while the shipped group measures its own pane space in `onLayout`.
