## Usage

```tsx
import { CodeEditor } from "@gpuixui/editor";

<CodeEditor
  value={value}
  onValueChange={setValue}
  language="tsx"
  lineNumbers
/>;
```

## API

| Prop | Type | Default | Notes |
| ---- | ---- | ------- | ----- |
| `value` | `string` | — | The controlled text. A stored value that is not text reads as an empty document. |
| `defaultValue` | `string` | `""` | The uncontrolled starting text. A stored value that is not text reads as an empty document. |
| `onValueChange` | `(value: string) => void` | — | Every edit, including Tab and Enter. |
| `language` | `string` | — | The tokenizer's language id. An unknown id, or one that is not text, paints plain text. |
| `lineNumbers` | `boolean` | `true` | Number the rows in a gutter. |
| `tabMode` | `"insert" \| "focus"` | `"insert"` | What Tab does. |
| `indent` | `string` | `"  "` | The string Tab inserts. An empty string leaves Tab as the platform traversal, and a value that is not a string reads as the default. |
| `placeholder` | `string` | — | The editor's hint, painted in the theme's `placeholder` role and announced as the field's description; the host is handed none. |
| `readOnly` | `boolean` | `false` | View-only. |
| `disabled` | `boolean` | `false` | Not editable, out of the tab order, painted with the disabled chrome. |
| `minRows` / `maxRows` | `number` | — | The runtime's row controls. |
| `fullWidth` | `boolean` | `false` | Fill the available width. |
| `label` | `string` | `"Code editor"` | The accessible name. A blank name reads as the default. |
| `className` | `string` | — | A Tailwind class string, merged last. |
| `style` | `StateStyle<CodeEditorState>` | — | The surface, or a function of `{ disabled, focused }`. |
| `testId` | `string` | `"code-editor"` | The address an automation host locates the field by; the surface around it is `${testId}-surface`. |

## Limitations

- **A disabled editor paints the disabled chrome**: the surface fades by `disabledOpacity` and the field leaves the tab order, so a reader sees the refusal rather than typing into a field that answers nothing — held by `src/behaviour/code-editor.test.tsx`.
- **A transparent textarea paints no caret** and reports no scroll offset.
- **Tab and Enter insert at the end**, because the runtime exposes no caret position.
- **Tab only swallows the traversal when it inserts something**: an empty `indent` leaves the platform's Tab, so a field is never a keyboard trap, and an indent restored from storage that is not a string reads as the default `"  "`.
- **A stored draft that is not text paints an empty document**: a `value` or `defaultValue` restored from storage as `null` reads through `draftOf`, so the tokenizer and the gutter paint the empty state instead of throwing out of the render.
- **A stored `language` that is not text paints plain text**: the id is read through `languageOf` before the tokenizer sees it, so a preference saved as a number or an object is the same plain fallback an unknown id gets instead of a `.trim()` throw.
- **A blank `label` reads as `"Code editor"`**: the name is read through the same absence rule as every other name, so a stored empty string cannot publish an unnamed field.
- **The gutter is flush with the code column**: a line number shares its row's top edge — held by `src/behaviour/code-editor.test.tsx` in the renderer, so a number cannot drift a spacing step below the line it numbers. The transparent field's own text inset stays unverified: it paints no caret to compare against the highlight layer.
