## Usage

```tsx
import { DiffViewer } from "@gpuixui/editor";

<DiffViewer before={before} after={after} mode="unified" />;
```

## API

| Prop | Type | Default | Notes |
| ---- | ---- | ------- | ----- |
| `before` | `string` | — | The before source. |
| `after` | `string` | — | The after source. |
| `mode` | `"unified" \| "split"` | `"unified"` | One merged column, or two. |
| `lineNumbers` | `boolean` | `true` | Number the rows on both sides. |
| `label` | `string` | `"Diff"` | The accessible name. |
| `className` | `string` | — | A Tailwind class string, merged last. |
| `style` | `StateStyle<DiffViewerState>` | — | The surface, or a function of `{ changed }`. |
| `testId` | `string` | `"diff-viewer"` | The address an automation host locates the diff by; each pair appends `-row-<index>`. |

## Split mode

`mode="split"` puts a changed line and its replacement on **one** row: a run of
removed and added lines is zipped by index, and a side that ran out gets a blank
cell. A one-line edit is therefore one row with the old line on the left and the
new one on the right, not a removal and an addition stacked apart. Context rows
pair with themselves and keep both line numbers.

## Limitations

- **`O(n·m)` time and space.** The LCS table is the size of the two files, so very large files are slow.
- **No word-level diff.** A changed line is a whole line, not the words inside it.
- **The diff text is presentational.** The rows are `role="presentation"` runs, so a reader hears whether anything changed, not the diffed text itself.
