## Usage

```tsx
import { MarkdownEditor } from "@gpuixui/editor";

<MarkdownEditor
  value={value}
  onValueChange={setValue}
  label="Release notes"
  width={640}
  height={300}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | — (uncontrolled) |
| `defaultValue` | `string` | `""` |
| `onValueChange` | `(value: string) => void` | — |
| `mode` | `"split" \| "source" \| "preview"` | — (uncontrolled) |
| `defaultMode` | `"split" \| "source" \| "preview"` | `"split"` |
| `onModeChange` | `(mode) => void` | — |
| `label` | `string` | `"Markdown editor"` |
| `placeholder` | `string` | — |
| `width` | `number` | `640` |
| `height` | `number` | `280` |
| `splitSize` | `number` | — (uncontrolled) |
| `defaultSplitSize` | `number` | half the body |
| `onSplitSizeChange` | `(size: number) => void` | — |
| `readOnly` | `boolean` | `false` |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |
| `testId` | `string` | — |

## Names

`label` names the editor and every part of it: the source field is `"<label> source"`, the preview `"<label> preview"` and the split's divider `"<label> split"`. A label that arrives blank — from an i18n table or a saved record — is an absence, so each part falls back to `Markdown editor` rather than publishing `" source"`.

## Limitations

- **No formatting toolbar.** It needs a selection API the runtime does not have.
- **No caret or selection read-back.** `MarkdownEditor` cannot insert at the reader's cursor.
- **Two panes, horizontal only.** A split divides the editor left/right and the preview takes the rest; there is no stacked split.
