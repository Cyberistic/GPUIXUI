## Usage

The runtime has no chart host and an `<svg>` paints as one tinted mask, so a
chart is one layer per series, each tinted through `style.color`. The
`chart-surface-lifecycle` probe measures the shipped components' paint in a real
window.

```tsx
import {
  BarChart,
  ChartLegend,
  DonutChart,
  LineChart,
  Sparkline,
  StackedBar,
} from "@gpuixui/data";

<BarChart
  aria-label="Revenue against cost by quarter"
  labels={["Q1", "Q2", "Q3", "Q4"]}
  series={[
    { key: "revenue", label: "Revenue", values: [32, 48, 41, 60] },
    { key: "cost", label: "Cost", values: [18, 22, 26, 24] },
  ]}
  width={320}
  height={140}
/>;

<LineChart aria-label="Churn" labels={QUARTERS} series={[churn]} />;
<StackedBar aria-label="Revenue and cost" labels={QUARTERS} series={[revenue, cost]} />;
<DonutChart aria-label="Traffic by source" data={sources} size={160} />;
<Sparkline aria-label="Revenue trend" values={revenue.values} />;
<ChartLegend
  items={[
    { key: "revenue", label: "Revenue", color: series1 },
    { key: "cost", label: "Cost", color: series2 },
  ]}
/>;
```

## API

### `BarChart` · `StackedBar` · `LineChart`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `series` | `ChartSeries[]` | — | `{ key, label, values }` per series |
| `labels` | `string[]` | — | one label per category |
| `width` | `number` | `320` | the plot's width, in pixels |
| `height` | `number` | `160` | the plot's height, in pixels |
| `legend` | `boolean` | `series.length > 1` | paints the legend under the labels |
| `axis` | `boolean` | `true` | paints the y-axis tick column |
| `ticks` | `number` | `4` | how many steps the y axis divides into |
| `className` | `string` | — | joined after the recipe |
| `testId` | `string` | — | the chart's locator; the plot is `-plot`, the axis column `-axis`, a series layer `-layer-<key>` |
| `aria-label` | `string` | — | the group's name |

### `DonutChart`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `data` | `ChartDatum[]` | — | `{ key, label, value }` per slice |
| `size` | `number` | `160` | the ring's box, in pixels |
| `legend` | `boolean` | `true` | paints the legend under the ring |
| `className` | `string` | — | joined after the recipe |
| `testId` | `string` | — | the chart's locator; a slice is `-layer-<key>` |
| `aria-label` | `string` | — | the group's name |

### `Sparkline`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `values` | `number[]` | — | one point each, in paint order |
| `width` | `number` | `120` | the plot's width, in pixels |
| `height` | `number` | `32` | the plot's height, in pixels |
| `color` | `string` | the first categorical swatch | the line's colour |
| `className` | `string` | — | joined after the recipe |
| `testId` | `string` | — | the sparkline's locator |
| `aria-label` | `string` | `Trend` | the single image's name |

### `ChartLegend`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `items` | `ChartLegendItem[]` | — | `{ key, label, color }` per series |
| `testId` | `string` | — | the legend's locator; a swatch is `-swatch-<key>` |
| `aria-label` | `string` | — | the legend's group name |

## Limitations

- One tint per layer: two colours inside one series need two layers.
- No tooltips, hover readouts or zoom.
- No animation between data sets.
