---
title: Charts
description: Bar, stacked, line, donut and sparkline charts drawn as stacked SVG masks.
---

GPUix has no chart host, so `@gpuixui/data` draws one `<svg>` per series, each
tinted through `style.color` and stacked inside one plot.

## Usage

```tsx
import { BarChart, DonutChart, LineChart, Sparkline, StackedBar } from "@gpuixui/data";

<BarChart
  aria-label="Revenue against cost by quarter"
  labels={["Q1", "Q2", "Q3", "Q4"]}
  series={[
    { key: "revenue", label: "Revenue", values: [32, 48, 41, 60] },
    { key: "cost", label: "Cost", values: [18, 22, 26, 24] },
  ]}
  width={320}
  height={140}
/>;

<LineChart aria-label="Churn" labels={QUARTERS} series={[churn]} />;
<StackedBar aria-label="Revenue and cost" labels={QUARTERS} series={[revenue, cost]} />;
<DonutChart aria-label="Traffic by source" data={sources} size={160} />;
<Sparkline aria-label="Revenue trend" values={revenue.values} />;
```

## API

The series charts (`BarChart`, `StackedBar`, `LineChart`) share one contract:

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `series` | `ChartSeries[]` | — | `{ key, label, values }` per series |
| `labels` | `string[]` | — | one label per category |
| `width` | `number` | `320` | the plot's width, in pixels |
| `height` | `number` | `160` | the plot's height, in pixels |
| `legend` | `boolean` | `series.length > 1` | paints the legend under the labels |
| `axis` | `boolean` | `true` | paints the y-axis tick column |
| `ticks` | `number` | `4` | how many steps the y axis divides into |
| `testId` | `string` | — | the chart's locator |
| `aria-label` | `string` | — | the group's name; a sparkline's own image name |

`DonutChart` takes `data: ChartDatum[]`, `size` (`160`) and `legend`. `Sparkline`
takes `values: number[]`, `width` (`120`), `height` (`32`) and `color`.

A `StackedBar`'s axis and its bars both read the category totals, so a tall stack
never prints an axis under it.

The axis column reads from the top down: its ceiling is the topmost label and
its floor sits on the plot's floor — the same edge the bars stand on — so a
bar's top is read against the number beside it.

`labels` names the columns: a series with more values than labels paints only
the labelled slots, and the extra values draw nowhere. An extra value cannot
raise the axis either — the scale is measured over the slots the chart paints, so
a stray `999` beside two labelled values of `3` and `6` scales the axis to `10`
instead of flattening both bars under a `1000` ceiling. A line's points sit at
the centre of their slot, like a bar and the label under it, so a series with
fewer values than labels stays in the columns it names instead of stretching
across the plot.

## Accessibility

A chart is a **group** named by its `aria-label`, holding one **image** per
series named by the series' `label`. The numbers travel in the image's
description, because a picture of numbers is the one thing a role cannot carry:

- a series reads `Q1 32, Q2 48, Q3 41` — the label it stands under and the value
  it paints, in category order;
- a series with a labelled slot keeps its image even when nothing draws: a bar
  chart of zeros paints no bar, and a negative value no geometry can show, yet
  the series still reads `Q1 0, Q2 -4` rather than disappearing from the tree;
- a value past the last label draws nowhere and is not described, and one the
  caller never supplied reads `no value` rather than the `0` the geometry
  substitutes;
- a ring slice reads its own value (`Direct 40`);
- a `Sparkline` is **one image**, not a group of them: the caller's `aria-label`
  names it (`Trend` when absent) and its values are its description.

The axis ticks and the category labels are ordinary `Label`s beside the plot.
0.11.0 has no figure or table role, so the series' description is the strongest
channel the tree has; a reader who needs to compare values across many series
should also be given the same data as a `Table` (or a `KeyValue` list) next to
the picture.

## Limitations

- One tint per layer: two colours inside one series need two layers.
- No tooltips, hover readouts or zoom.
- No animation between data sets.
- Labels are laid out by the chart, not measured; a wide label is clipped.
