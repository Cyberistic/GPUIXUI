---
title: Table selection
description: A checkbox column for a data table.
---

`TableSelectionHeader` and `TableSelectionCell` are the checkbox column of a data
table.

## Usage

```tsx
import {
  Table,
  TableBody,
  TableHeader,
  TableRow,
  TableSelectionCell,
  TableSelectionHeader,
  TableViewport,
  useTable,
} from "@gpuixui/data";

const table = useTable({ rows: files, keyOf: (row) => row.id, columns });

<Table height={320} aria-label="Files">
  <TableViewport>
    <TableHeader>
      <TableRow>
        <TableSelectionHeader
          checked={table.allSelected}
          indeterminate={table.someSelected}
          onCheckedChange={table.setAllSelected}
          disabled={table.rows.length === 0}
        />
        <TableHeaderCell width={260}>Name</TableHeaderCell>
      </TableRow>
    </TableHeader>
    <TableBody>
      {table.rows.map((file) => (
        <TableRow key={file.id} selected={table.isSelected(file.id)}>
          <TableSelectionCell
            checked={table.isSelected(file.id)}
            onCheckedChange={() => table.toggleSelection(file.id)}
            label={`Select ${file.name}`}
          />
          <TableCell width={260}>{file.name}</TableCell>
        </TableRow>
      ))}
    </TableBody>
  </TableViewport>
</Table>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `checked` | `boolean` | — | whether the box paints a check |
| `indeterminate` | `boolean` | `false` | header only: paints a dash for a partial set |
| `onCheckedChange` | `(selected: boolean) => void` | — | the box's next state |
| `label` | `string` | header: `Select every row`; row: required | the box's accessible name |
| `width` | `number` | `40` | the track width |
| `disabled` | `boolean` | `false` | refuses the press |
| `testId` | `string` | — | the box's id |

## Limitations

- A row box toggles one record; the header box toggles the whole visible set.
- No `aria-checked`: state is announced through `aria-valuetext`.
- A filter that hides a chosen record releases it from the painted selection.
