---
title: Expandable rows
description: A table row that opens a detail panel under itself
---

`TableExpandableRow` opens a detail panel under its row.

## Usage

```tsx
import {
  Table,
  TableBody,
  TableExpandableRow,
  TableHeader,
  TableHeaderCell,
  TableRow,
  TableViewport,
} from "@gpuixui/data";
import { useState } from "react";

const [open, setOpen] = useState<string | null>(null);

<Table height={300} aria-label="Files with details">
  <TableViewport>
    <TableHeader>
      <TableRow>
        <TableHeaderCell width={32} />
        <TableHeaderCell width={200}>Name</TableHeaderCell>
      </TableRow>
    </TableHeader>
    <TableBody>
      {files.map((file) => (
        <TableExpandableRow
          key={file.id}
          expanded={open === file.id}
          onToggle={() => setOpen(open === file.id ? null : file.id)}
          cells={<TableCell width={200}>{file.name}</TableCell>}
          detail={<KeyValue entries={detailOf(file)} />}
        />
      ))}
    </TableBody>
  </TableViewport>
</Table>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `expanded` | `boolean` | `false` | the panel under the row paints |
| `onToggle` | `() => void` | — | the row's press, and the activation its Enter/Space makes; the caller flips `expanded` |
| `cells` | `ReactNode` | — | the row's cells, after the expander track |
| `detail` | `ReactNode` | — | the panel painted under the row while it is open |
| `toggleWidth` | `number` | `32` | the expander track's width |
| `detailTestId` | `string` | — | the panel's test id |
| `tabIndex` | `number` | `0` | the row's place in the Tab order; a disabled row takes `-1` |
| `disabled` | `boolean` | `false` | refuses the press and the keys, and paints no pointer state |

## Limitations

- One panel per row; two rows can be open at once.
- No animation of the panel's height.
- A windowed table cannot use it; use the plain table or the list's children mode.
