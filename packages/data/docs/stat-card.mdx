---
title: Statistic / metric cards
description: A card that shows one derived reading.
---

`StatCard` shows **one** reading: what it measures, the number, and optionally the
unit and the way it moved.

## Usage

```tsx
import { StatCard } from "@gpuixui/data";

<StatCard label="Area" value={`${width * height}`} unit="px²" />;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | — | what the reading measures |
| `value` | `ReactNode` | — | the reading, already rendered by the caller |
| `unit` | `string` | — | the unit, beside the reading |
| `hint` | `ReactNode` | — | a line under the reading |
| `trend` | `StatTrend` | — | `{ direction: "up" \| "down" \| "flat", text: string }` |

## Limitations

- The card does not size itself; it fills the box it is given.
- The reading is a node, not a number: the card formats nothing.
