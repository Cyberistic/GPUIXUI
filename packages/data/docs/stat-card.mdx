---
title: Statistic / metric cards
description: A card that shows one derived reading
---

## Usage

```tsx
import { StatCard } from "@gpuixui/data";

<StatCard label="Area" value={`${width * height}`} unit="px²" />;
```

## API

### `StatCard`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | — | what the reading measures |
| `value` | `ReactNode` | — | the reading, already rendered by the caller |
| `unit` | `string` | — | the unit, beside the reading |
| `hint` | `ReactNode` | — | a line under the reading |
| `trend` | `StatTrend` | — | the movement of the reading; a `null` a store wrote for an absent trend paints no trend |
| `className` | `string` | — | joined after the recipe |

### `StatTrend`

| Field | Type | Consequence |
| ----- | ---- | ----------- |
| `direction` | `"up" \| "down" \| "flat"` | which way the reading moved; it chooses the status tone's readable role |
| `text` | `string \| null` | the trend's own words, e.g. `+12%`; a nullish or blank one paints no words |

## Limitations

- The card does not size itself; it fills the box it is given.
- The reading is a node, not a number: the card formats nothing.
- A saved card's `trend` is read as data: `null` means no trend, so the
  reading, label and hint still paint.
- The card's own copy is read before it paints: a blank `label`, `unit`, `hint`
  or `trend.text` — a locale table's missing row, a saved record's empty field —
  paints **no line** rather than an empty or whitespace run the runtime would
  lay out as a full line. The reading is the caller's data and still paints
  (`behaviour/surface-a11y.test.tsx`).
