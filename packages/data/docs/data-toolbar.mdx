---
title: Data toolbars
description: The row of controls a data surface acts from.
---

`DataToolbar` is the row of controls above a data surface: a search field at its
head, and whatever actions the caller puts beside it. The search debounces
through `@tanstack/pacer`.

## Usage

```tsx
import { DataToolbar } from "@gpuixui/data";

<DataToolbar search={{ value: query, onValueChange: setQuery }}>
  <Button onActivate={reset}>Reset</Button>
</DataToolbar>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | — | the controls the row holds |
| `search` | `ToolbarSearch` | — | the field at the head of the row |
| `testId` | `string` | — | the field derives from it: `${testId}-search` |

A `ToolbarSearch` is `{ value, onValueChange, placeholder?, label?, debounceMs? }`;
`debounceMs` defaults to `150`.

## Limitations

- The toolbar does not own the query; it reports a debounced value.
- A pending query is dropped when the toolbar unmounts.
- It lays children out in one row only.
