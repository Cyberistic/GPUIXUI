---
title: Virtualization
description: A long list and table that mount one window of rows
---

## Usage

```tsx
import { VirtualList } from "@gpuixui/data";

<VirtualList height={320} aria-label="Files">
  {rows.map((row) => (
    <div key={row.id} style={{ height: 32 }}>
      <text>{row.label}</text>
    </div>
  ))}
</VirtualList>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `height` | `number` | caller's layout | a definite viewport height |
| `children` | `ReactNode` | — | the rows |
| `itemCount` | `number` | children mode | switches to the windowed mode |
| `estimatedItemHeight` | `number` | — | required with `itemCount`; a height the runtime cannot lay out is read as the shipped row's own (`37`) |
| `windowStart` | `number` | `0` | the first rendered slice's index |
| `onVisibleRange` | `(range: VisibleRange) => void` | — | the built window |
| `overdraw` | `number` | — | rows built beyond the viewport; a count the runtime cannot read is the default (`4`), a negative is `0` |
| `ref` | `Ref<PublicInstance>` | — | the list's instance, for `scrollToItem` |

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `count` | `number` | — | the logical row count; a fraction, a negative or an unreadable count is the whole, non-negative rows the table holds (`0` paints `empty`) |
| `rowHeight` | `number` | — | every row must paint exactly this height; a height the window cannot divide is read as the shipped row's own (`37`) |
| `row` / `renderRow` | `(index: number) => ReactNode` | — | paints one absolute row index |
| `height` | `number` | measured body | a definite table (or body) height |
| `header` | `ReactNode` | — | the header row's cells |
| `empty` | `ReactNode` | `No rows` | painted inside a `TableEmpty` row when `count` is `0`; a string paints as its own text element |
| `caption` | `ReactNode` | — | the line below the frame; a string paints as its own text element |
| `overdraw` | `number` | `4` | rows mounted beyond the viewport on each side; a count the window cannot read is `4`, a negative is `0` |
| `reveal` | `VirtualReveal` | — | `{ index }`; the window moves, then the body scrolls |
| `onVisibleRange` | `(range: VisibleRange) => void` | — | the runtime's lagging report |

## Limitations

- One row height: the windowed mode positions rows from `estimatedItemHeight`.
- `onVisibleRange` is not a window source: it lags the paint by one gesture.
- `itemCount` mode has no row span; an expanding row belongs in children mode.
