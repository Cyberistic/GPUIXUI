---
title: Tree views
description: Expandable rows of a hierarchy, with one tab stop and arrow keys.
---

`TreeView` paints a tree of rows a reader opens, closes and walks; it composes
with `useExpandedRows`.

## Usage

```tsx
import { TreeView, useExpandedRows } from "@gpuixui/data";

const tree = useExpandedRows({
  roots: files,
  keyOf: (node) => node.name,
  childrenOf: (node) => node.children ?? [],
  labelOf: (node) => node.name,
  initialExpanded: ["src"],
});

<TreeView
  aria-label="Workspace files"
  height={260}
  rows={tree.rows}
  cursor={tree.cursor}
  onCursorChange={tree.setCursor}
  labelOf={(node) => node.name}
  onActivate={(row) => open(row.node)}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `rows` | `TreeRow<T>[]` | — | the visible rows, in paint order |
| `labelOf` | `(node: T) => string` | — | the row's accessible name and type-ahead match |
| `cursor` | `TreeCursor` | — | the caller's cursor; omit for an uncontrolled tree |
| `onCursorChange` | `(cursor: TreeCursor) => void` | — | reports every cursor |
| `defaultCursor` | `TreeCursor` | nothing open | the uncontrolled tree's start |
| `onActivate` | `(row: TreeRow<T>) => void` | — | a press or Enter on a row |
| `renderRow` | `(row: TreeRow<T>) => ReactNode` | `labelOf` as text | paints a row's content |
| `height` | `number` | — | a definite height; the rows scroll inside it |
| `testId` | `string` | — | the tree's locator |

## Limitations

- One active row; a multi-select tree is not shipped.
- The tree does not virtualize itself; compose `VirtualList` in children mode.
- A row that changes height while painted re-measures on the next frame.
- The docs site cannot render this component live.
