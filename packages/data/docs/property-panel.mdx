---
title: Property panels
description: A panel of property rows over one object the caller owns.
---

`PropertyPanel` shows the rows that describe one object; every row is the
caller's, and an edit is a callback.

## Usage

```tsx
import { PropertyPanel } from "@gpuixui/data";

<PropertyPanel
  title="Properties"
  rows={[
    { kind: "readonly", key: "tag", label: "Tag", value: tag },
    { kind: "editable", key: "name", label: "Name", value: name, onChange: setName },
  ]}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `title` | `string` | — | the panel's header |
| `rows` | `PropertyRow[]` | — | the rows, in the order they paint |
| `labelWidth` | `number` | `120` | the label column's width, in pixels |

A read-only row is `{ kind: "readonly", key, label, value }`; an editable row is
`{ kind: "editable", key, label, value, onChange }`.

## Limitations

- The panel does not validate; a row reports its own change or message.
- The panel does not scroll.
- One editable row is one text session.
