# Provenance

This package is a conformance layer, not a fork of a browser library.

| Source | Version / commit | Licence | What is reused |
| ------ | ---------------- | ------- | -------------- |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | `d2fba50` | MIT, Copyright (c) 2023 shadcn | Class strings for the recipes in `src/recipes.ts`; no source files copied |
| [cn](https://github.com/shadcn-ui/cn) | `0.5.0` | MIT | Runtime dependency (`cn`) for class joining and conflict resolution |
| [Base UI](https://github.com/mui/base-ui) | `v1.6.0` | MIT | Behavior reference for the next slice; no source copied yet |

The upstream class strings are facts about the shadcn API and are kept verbatim
so a diff against upstream is meaningful. The MIT notices above apply to the
upstream projects; this package remains under the repository's licence.
