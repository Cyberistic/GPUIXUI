## Where these come from

The geometry is [Lucide](https://lucide.dev)'s, on its 24×24 grid with a 2px
stroke, used under the ISC licence and attributed in `LICENSES/`. Lucide ships
React components; this package ships the same shapes as plain markup strings,
because the runtime paints an icon as data: `<svg source>` takes the geometry and
tints it with the element's own `style.color`.

That is the whole contract. An icon carries no colour, no size and no state of its
own — one markup serves every theme and every platform look — and the wrapper
fixes the grid and the two paint values a monochrome tint can use (`fill: none`,
`stroke: #000`, which the runtime replaces with the token you pass). Nothing is
traced or redrawn: a shape that leaves the grid, or one that carries a colour
literal, fails `registry.test.ts` rather than shipping.

Adding an icon is two edits: the name in `names.ts` and its markup in
`registry.ts`. TypeScript refuses the pair if one is missing.

## Usage

```tsx
import { Icon } from "@gpuixui/icons";
import { useTheme } from "@gpuixui/primitives";

const theme = useTheme();

// Decoration: takes itself out of the accessibility tree.
<Icon name="search" color={theme.colors.mutedForeground} />;

// Meaningful on its own: announced as an image.
<Icon name="warning" color={theme.colors.destructive} size="md" label="Overdue" />;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `name` | `IconName` | required | which icon; TypeScript rejects an unknown name, and a **stored** name the set does not carry paints the `help` mark |
| `color` | `string` | required | the tint; pass a theme role |
| `size` | `IconSize \| number` | `"md"` | a named step or raw pixels; a name the scale does not carry resolves to `md` |
| `label` | `string` | none | accessible name; a non-blank label promotes the icon to an image |
| `testId` | `string` | — | stable locator |
| `rotation` | `number` | `0` | clockwise degrees about the 24x24 centre, written into the markup; `NaN` reads as no turn |
| `motion` | `MotionProps` | none | a tween for the icon's own box: `width`/`height` size the path and `left`/`top` keep it centred, because the runtime has no `transform` |
| `style` | `StyleDesc` | none | extra style merged over the icon's own, last |

## Where these come from

The geometry is copied from [Lucide](https://lucide.dev) `lucide-static@1.61.0`
on its 24x24 grid, under ISC and MIT; the notice that redistribution must carry
is [`LICENSES/lucide.md`](https://github.com/Cyberistic/GPUIXUI/blob/master/LICENSES/lucide.md).
`star-filled` and `sort-asc` are the package's own. `LICENSES/` is the ledger for
every reference the library takes from.

## Limitations

- Monochrome only: no two-tone, duotone or brand marks.
- No spin animation: `rotation` is a static turn, because an animated one would need a frame-driven re-render. Use `Spinner` for a moving mark. A `motion` tween moves and resizes the box; it does not rotate the path — write the turn into `rotation` and animate around it.
- No icon font and no ligatures.
