## Usage

```tsx
import { Icon } from "@gpuixui/icons";
import { useTheme } from "@gpuixui/primitives";

const theme = useTheme();

// Decoration: takes itself out of the accessibility tree.
<Icon name="search" color={theme.colors.mutedForeground} />;

// Meaningful on its own: announced as an image.
<Icon name="warning" color={theme.colors.destructive} size="md" label="Overdue" />;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `name` | `IconName` | required | which icon; TypeScript rejects an unknown name |
| `color` | `string` | required | the tint; pass a theme role |
| `size` | `IconSize \| number` | `"md"` | a named step or raw pixels; a name the scale does not carry resolves to `md` |
| `label` | `string` | none | accessible name; a non-blank label promotes the icon to an image |
| `testId` | `string` | — | stable locator |

## Limitations

- Monochrome only: no two-tone, duotone or brand marks.
- No rotation or spin animation; use `Spinner`.
- No icon font and no ligatures.
