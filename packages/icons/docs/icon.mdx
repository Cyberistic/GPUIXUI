`@gpuixui/icons` is the icon set: each icon is a self-contained 24×24 monochrome
SVG markup string that GPUix tints with `style.color`. Icons are data, not
component trees.

## Usage

```tsx
import { Icon } from "@gpuixui/icons";
import { useTheme } from "@gpuixui/primitives";

const theme = useTheme();

// Decoration: takes itself out of the accessibility tree.
<Icon name="search" color={theme.colors.mutedForeground} />;

// Meaningful on its own: announced as an image.
<Icon name="warning" color={theme.colors.destructive} size="md" label="Overdue" />;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `name` | `IconName` | required | which icon; TypeScript rejects an unknown name |
| `color` | `string` | required | the tint; pass a theme role |
| `size` | `IconSize \| number` | `"md"` | a named step or raw pixels |
| `label` | `string` | none | accessible name; a non-blank label promotes the icon to an image |
| `testId` | `string` | — | stable locator |

## Sizes

| Step | Pixels |
| ---- | ------ |
| `xs` | 12 |
| `sm` | 14 |
| `md` (default) | 16 |
| `lg` | 20 |
| `xl` | 24 |

A raw pixel count is for a mark that is not lining up with text. A count the
runtime cannot paint — `NaN`, an infinity, zero or a negative — and a **name the
scale does not carry**, such as a size read back from a stored preference, both
resolve to `md`: a stored value paints the default box rather than a full-width,
zero-height icon. `iconPixels(size)` is the resolver, and it takes the decoded
value as `unknown` for exactly that reason.

## Limitations

- Monochrome only: no two-tone, duotone or brand marks.
- No rotation or spin animation; use `Spinner`.
- No icon font and no ligatures.
- The set is curated; add a name to `registry.ts` and `names.ts` together.

## Provenance

The geometry is taken from [Lucide](https://lucide.dev) `lucide-static@1.61.0`,
on its 24×24 grid at `stroke-width="2"`. Both the ISC and MIT notices travel
with the geometry in [`LICENSES/lucide.md`](../../../LICENSES/lucide.md).
