---
title: File trees
description: A hierarchical file tree with a glyph per kind, single and multi selection, one roving tab stop and type-ahead
---

## Usage

```tsx
import { buildFileTree, FileTree } from "@gpuixui/files";

const roots = buildFileTree([
  "src/index.ts",
  "src/components/button.tsx",
  "readme.md",
]);

<FileTree
  aria-label="Project files"
  height={280}
  roots={roots}
  keyOf={(node) => node.path}
  childrenOf={(node) => node.children ?? []}
  labelOf={(node) => node.name}
  onSelectionChange={(keys) => setChosen(keys)}
  onActivate={(node) => open(node.path)}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `roots` | `T[]` | — | the tree's roots, in paint order |
| `keyOf` | `(node: T) => string` | — | the stable identity a row is addressed by |
| `childrenOf` | `(node: T) => T[]` | — | the children, in paint order |
| `labelOf` | `(node: T) => string` | — | the row's name and what type-ahead matches |
| `kindOf` | `(node: T, hasChildren: boolean) => FileKind` | `fileKindOf` | the glyph a row paints |
| `initialSelected` | `Iterable<string>` | none | the keys selected at first paint |
| `onSelectionChange` | `(keys: string[]) => void` | — | reports the chosen keys after every press |
| `onActivate` | `(node: T) => void` | — | a press or Enter on a row, after the selection is replaced |
| `height` | `number` | — | a definite height; the rows scroll inside it |
| `testId` | `string` | — | the tree; each row is `${testId}-row-${key}` |

## Limitations

- Selection is press-and-checkbox, not a Shift-drag range; the range mode of `pressSelection` is available to a caller driving the reducer directly.
- The tree does not virtualize itself.
- The docs site cannot render this component live — it is a GPUix host tree, not DOM.
