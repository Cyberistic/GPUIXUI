---
title: Property panels
description: A key/value editor for text, number, boolean and select
---

## Usage

```tsx
import { PropertyPanel, type PropertyRow } from "@gpuixui/files";

const rows: ReadonlyArray<PropertyRow> = [
  { type: "text", key: "name", label: "Name", value: name },
  { type: "number", key: "count", label: "Count", value: count },
  { type: "boolean", key: "active", label: "Active", value: active },
  { type: "select", key: "kind", label: "Kind", value: kind, options: KINDS },
];

<PropertyPanel title="Shape" rows={rows} onChange={(record) => apply(record)} />;
```

A number row's label is its scrub handle: drag it horizontally to step the
value (Shift is ten steps) and a click still selects the field for typing. A
row's optional `min`/`max`/`step` bound the drag and the field.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `rows` | `PropertyRow[]` | — | the rows, in paint order |
| `onChange` | `(record: PropertyRecord) => void` | — | receives the whole record after every edit |
| `title` | `string` | — | the panel's header title |
| `labelWidth` | `number` | `120` | the label column's width, in pixels |
| `testId` | `string` | — | the panel; each label is `${testId}-label-${key}` |

## Limitations

- One `type` per row; a property whose type changes is a different row, not a switch the panel animates.
- A select's options are data, so there is no rich option content — the same shape the primitives' `Select` accepts.
- The docs site cannot render this component live — it is a GPUix host tree, not DOM.
