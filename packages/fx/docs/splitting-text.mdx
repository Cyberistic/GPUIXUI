## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SplittingText } from "@gpuixui/fx/splitting-text";

<SplittingText text="Build native interfaces" role="h1" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `split` | `"words" \| "characters"` | `"words"` |
| `stepMs` | `number` | `40` |
| `from` | `"start" \| "end" \| "center"` | `"start"` |
| `offset` | `number` | `8` |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<SplittingTextState>` | — |
