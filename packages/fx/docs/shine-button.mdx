## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { ShineButton } from "@gpuixui/fx/shine-button";

<ShineButton variant="primary" onClick={deploy}>
  Deploy
</ShineButton>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"secondary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `disabled` | `boolean` | `false` |
| `loading`, `loadingLabel`, `reducedMotion`, `leading`, `trailing` | the shared `Button` busy contract | — |
| `level` | `MotionLevel` | `"notice"` |
| `sheenColor` | `string` | the label colour |
| `onMouseEnter` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |
| `style` | `StyleDesc` | — |
