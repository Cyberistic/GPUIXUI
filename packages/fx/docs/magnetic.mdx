<ComponentPreview name="magnetic-demo" />

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Magnetic } from "@gpuixui/fx/magnetic";

<Magnetic onClick={open}>
  <Card>
    <CardTitle>Notes</CardTitle>
  </Card>
</Magnetic>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `strength` | `number` | `0.35` |
| `maxOffset` | `number` | `12` |
| `level` | `MotionLevel` | `"fast"` |
| `className` | `string` | — |
| `style` | `StateStyle<{ pulled, reducedMotion }>` | — |
| `onMouseMove` | `(event) => void` | — |
| `onMouseLeave` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |
