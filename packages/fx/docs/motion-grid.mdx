## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { MotionGrid } from "@gpuixui/fx/motion-grid";

<MotionGrid
  items={tools.map((tool) => ({ id: tool.id, content: <ToolCard tool={tool} /> }))}
  columns={3}
  cellWidth={160}
  rowHeight={120}
  gap={12}
  label="Tool board"
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `ReadonlyArray<MotionGridItem>` (a value that is not a list reads as none; an entry without a text `id` is dropped) | — |
| `columns` | `number` | `3` |
| `cellWidth` | `number` | `160` |
| `rowHeight` | `number` | `120` |
| `gap` | `number` | `12` |
| `level` | `MotionLevel` | `"normal"` |
| `label` | `string` | — |
| `className` | `string` | — |
| `style` | `StateStyle<MotionGridState>` | — |
