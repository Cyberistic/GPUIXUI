## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { TypingText } from "@gpuixui/fx";

<TypingText text="Deploying to production…" speed={35} />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `speed` | `number` | `45` |
| `delay` | `number` | `0` |
| `caret` | `boolean` | `false` |
| `label` | `string` | the whole `text` |
| `onComplete` | `() => void` | — |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<TypingTextState>` | — |
