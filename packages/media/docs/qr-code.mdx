---
title: QrCode
description: A QR symbol painted from the package's own encoder — byte mode, versions 1–10, every error correction level and a scanner-safe quiet zone
---

## Usage

```tsx
import { QrCode } from "@gpuixui/media";

<QrCode
  value="https://gpuixui.dev/docs/components/qr-code"
  label="The component documentation"
  size={160}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | required |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"M"` |
| `size` | `number` | `160` |
| `quietZone` | `number` | `4` |
| `ink` | `string` | `#111111` |
| `paper` | `string` | `#FFFFFF` |
| `label` | `string` | `"QR code"` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |

## Limitations

- **Versions 1–10.** The largest symbol holds 274 bytes at `L`.
- **Byte mode only.** Numeric and alphanumeric payloads would pack more tightly; the encoder always declares byte mode, which every scanner reads.
- **No logo or artwork overlay**: a mask is a path, not a composited image.
