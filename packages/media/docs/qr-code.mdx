title: QrCode
description: A QR symbol painted from the package's own encoder — byte mode, versions 1–10, every error correction level and a scanner-safe quiet zone
---

## Usage

```tsx
import { QrCode } from "@gpuixui/media";

<QrCode
  value="https://gpuixui.dev/docs/components/qr-code"
  label="The component documentation"
  size={160}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `string` | required |
| `level` | `"L" \| "M" \| "Q" \| "H"` | `"M"` |
| `size` | `number` | `160` |
| `quietZone` | `number` | `4` |
| `ink` | `string` | `#111111` |
| `paper` | `string` | `#FFFFFF` |
| `label` | `string` | `"QR code"` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |

## Limitations

- **Versions 1–10.** The largest symbol holds 271 bytes at `L`.
- A `quietZone` that is not finite and non-negative reads as the default `4`; `0` asks for no quiet zone, while a stored `-4` cannot mean one.
- **A value that does not fit is an alert, not an image**: the box announces the capacity sentence, keeps the caller's reserved square and never paints a partial symbol; `label` names the painted symbol only.
- **Byte mode only.** Numeric and alphanumeric payloads would pack more tightly; the encoder always declares byte mode, which every scanner reads.
- **No logo or artwork overlay**: a mask is a path, not a composited image.
