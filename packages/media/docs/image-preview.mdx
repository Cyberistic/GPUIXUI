---
title: ImagePreview
description: An image surface with a loading state, an error state, a caption and a pointer zoom
---

## Usage

```tsx
import { ImagePreview } from "@gpuixui/media";

<ImagePreview
  src={bytesReady ? "data:image/png;base64,…" : ""}
  alt="The dashboard screenshot"
  status={fetchFailed ? "error" : bytesReady ? "loaded" : "loading"}
  caption="Figure 1 — the revenue dashboard"
  onRetry={() => refetch()}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` (required) | — |
| `alt` | `string` (required) | — |
| `status` | `ImagePreviewStatus` | `"error"` for blank `src`, else `"loaded"` |
| `caption` | `string` | — |
| `loadingLabel` | `string` | `"Loading"` |
| `errorLabel` | `string` | `"Could not load image"` |
| `retryLabel` | `string` | `"Retry"` |
| `onRetry` | `() => void` | — |
| `width` / `height` | `number` | `240` / `160` |
| `zoom` | `boolean` | `true` |
| `scale` | `number` | `ImageZoom`'s `1.6` |
| `radius` | `number` | `theme.radius.md` |

## Limitations

- **No load/error signal**: the `<img>` host has no `onLoad`/`onError`, so `status` is caller-driven and the only error the component detects itself is a blank `src`.
- The docs site cannot render this live; the code above is the real source.
- The loading state is a `Spinner`, announced as `loadingLabel`.
