## Usage

```tsx
import { ImagePreview } from "@gpuixui/media";

<ImagePreview
  src={bytesReady ? "data:image/png;base64,…" : ""}
  alt="The dashboard screenshot"
  status={fetchFailed ? "error" : bytesReady ? "loaded" : "loading"}
  caption="Figure 1 — the revenue dashboard"
  onRetry={() => refetch()}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` (required) | — (a blank or non-text value paints the error state) |
| `alt` | `string` (required) | — (a blank or non-text value reads as `"Picture"`) |
| `status` | `ImagePreviewStatus` | `"error"` for blank `src`, else `"loaded"` |
| `caption` | `string` | — |
| `loadingLabel` | `string` | `"Loading"` |
| `errorLabel` | `string` | `"Could not load image"` |
| `retryLabel` | `string` | `"Retry"` |
| `onRetry` | `() => void` | — |
| `width` / `height` | `number` | `240` / `160` |
| `zoom` | `boolean` | `true` |
| `scale` | `number` | `ImageZoom`'s `1.6` |
| `radius` | `number` | `theme.radius.md` |
| `className` | `string` | — |

## Limitations

- **No load/error signal**: the `<img>` host has no `onLoad`/`onError`, so `status` is caller-driven and the only error the component detects itself is a blank `src`.
- **A source that is not text paints the error state**: a `src` restored from storage as `null` is read as text once, so the derived state is paintable instead of throwing out of the render.
- The docs site cannot render this live; the code above is the real source.
- The loading state is a `Spinner`, announced as `loadingLabel`.
- A **blank `loadingLabel`, `errorLabel` or `retryLabel`** reads as its documented default and is trimmed: a label table is copy, so an empty string is an absence, not a name, and the spinner, the error sentence and the retry action are always announced.
- **A blank picture name reads as `"Picture"`**: the runtime publishes an `<img>` as an `Image` node named by its `alt`, so an empty name — an i18n row, or a saved record's `null` — would otherwise be announced with no name at all. A name given is trimmed and kept.
- **A blank caption paints no line**: `caption` is copy from a data table or an i18n file, so an empty or whitespace-only one is an absence — the pinned runtime lays out `""` at 0px and a run of spaces at 16px, so it is read through `visibleCopy` before the paint and a caption given is painted exactly as written.
