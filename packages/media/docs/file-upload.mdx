## Usage

```tsx
import { FileUpload, type UploadFunction } from "@gpuixui/media";

const upload: UploadFunction = async (file, onProgress) => {
  await transfer(file.path, (fraction) => onProgress(fraction));
};

<FileUpload
  upload={upload}
  files={files}
  onRemoveFile={(id) => setFiles(files.filter((file) => file.id !== id))}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `upload` | `UploadFunction` (required) | — |
| `files` | `ReadonlyArray<UploadFile>` (required) | — (a blank or non-text `name` reads as the file's `id`) |
| `onRemoveFile` | `(id: string) => void` | — |
| `label` | `string` | `"Upload files"` |
| `emptyLabel` | `string` | `"No files"` |
| `retryLabel` | `string` | `"Retry"` |
| `removeLabel` | `string` | `"Remove"` |
| `className` | `string` | — |

## Limitations

- The transfer is the caller's; the package owns no network and no platform prompt, so there is nothing here that dials a host.
- The progress bar is `Progress`'s determinate bar (the runtime has no `aria-valuenow`, so the value rides `aria-valuetext`).
- The docs site cannot render this live; the code above is the real source.
- A **blank `label`, `emptyLabel`, `retryLabel` or `removeLabel`** reads as its documented default and is trimmed, so a copy table's empty string cannot publish an unnamed queue, an empty sentence or an unnamed action.
- A **blank or non-text file `name`** reads as the file's `id` in the queue, so a record restored without a name paints a named row and its action says `Remove notes.txt`, never `Remove null`.
