## Usage

```tsx
import * as Option from "effect/Option";
import { MediaPlayer, type MediaFrame } from "@gpuixui/media";

// The caller decodes or generates each frame: a file, a stream or a sequence.
const frameAt = (playhead: number): Option.Option<MediaFrame> =>
  Option.some(frames[Math.floor(playhead / 1000)] ?? firstFrame);

<MediaPlayer
  duration={4000}
  frameAt={frameAt}
  alt="A clip's frame"
  label="Generated clip"
  width={240}
  height={135}
  trackWidth={240}
  peaks={waveformSamples}
  seekStep={500}
  onPlayheadChange={(playhead) => savePosition(playhead)}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `duration` | `number` (milliseconds) | required |
| `frameAt` | `(playhead) => Option<MediaFrame>` | — (no picture) |
| `alt` | `string` | required (a blank name reads as the player's own) |
| `label` | `string` | `"Media player"` (a blank name reads as the default) |
| `width` | `number` | `240` |
| `height` | `number` | `135` |
| `trackWidth` | `number` | `200` |
| `peaks` | `ReadonlyArray<number>` (`0…1`) | — (no waveform) |
| `defaultPlayhead` | `number` | `0` |
| `onPlayheadChange` | `(playhead: number) => void` | — |
| `defaultPlaying` | `boolean` | `false` |
| `onPlayingChange` | `(playing: boolean) => void` | — |
| `tickMs` | `number` | `100` |
| `seekStep` | `number` | `1000` |
| `playLabel` | `string` | `"Play"` (a blank label reads as the default) |
| `pauseLabel` | `string` | `"Pause"` (a blank label reads as the default) |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |
| `testId` | `string` | — |

A `MediaFrame` is `{ width, height, pixels }`, where `pixels` are straight RGBA
bytes (`width * height * 4`). The player pushes them with
`ImgInstance.setImagePixels` from a layout effect; the route is measured by the
`media-frame-lifecycle` probe. A frame whose box or buffer cannot be laid out
paints no new picture rather than a broken one.

## Keyboard

The seek pad is a focusable `role="slider"` named `<label> position` and
announces the clock through `aria-valuetext`:

| Key | What it does |
| --- | ------------ |
| `Home` | seek to the clip's start |
| `End` | seek to the clip's end (and stop a running clip) |
| `Left` | seek back by `seekStep` |
| `Right` | seek forward by `seekStep` |

The play/pause action is the shipped `Button`, so it activates on click, Enter
and Space and leaves the tab order while disabled.

## Pointer

The progress track is also a seek control: a press on it seeks to the share of
the clip the pointer names, and a drag while the primary button is held scrubs.
The painted rail is 6 points tall inside a **24-point** target
(`targetSize.minimum`, the same floor a checkbox's target keeps), and the rail
itself is pointer-transparent so a press anywhere in that band reaches the
track. A press outside the band's ends clamps to 0:00 or the clip's end; a
secondary press begins no scrub (it is a context-menu gesture); and a move that
holds no button ends the gesture, so a release outside the track cannot leave it
armed for the next hover. The player reads the track's box from the renderer at
press time — the route the shipped `Slider` uses — so a resize is picked up
without a second measurement.

## Limitations

- **Measured in a window**: `media-player-lifecycle` (63 checks, 0.11.0) mounts
  the shipped player on a four-second clip and reads the frame the playhead
  names (240×135), a 200×32 waveform silhouette in the palette's
  `mutedForeground` with page-coloured first and last rows, the `0:00 / 0:04`
  clock, the fill at the package's own `progressWidth`, `End`/`Home` and three
  `Right`s seeking to `0:03` with the picture repainted to that second's frame,
  a **press three quarters along the 24-point band** seeking to `0:03` at fill
  **150** and a **drag to its trailing edge** reaching `0:04` at **200** with the
  release ending the gesture (a hover afterwards reports nothing), and
  `disabled` refusing the transport and the track while the picture keeps
  painting.
- **No audio, and no decoding.** The runtime declares no `video` or `audio`
  element and no playback verb, so the caller supplies each frame's bytes. This
  player is the picture and the transport; a clip's frames must arrive from the
  app.
- **A pointer scrub is a press and a drag, not a click on a rail.** The track
  seeks to the share a press names and follows a drag while the primary button
  is held; the rail itself is pointer-transparent inside its 24-point target. A
  release delivered outside the target ends the scrub, so the next hover moves
  nothing. A caller that wants a finer pointer target can set `trackWidth`.
- **The pad announces through `aria-valuetext`**: `@gpuix/native@0.11.0` has no
  `aria-valuenow`/`aria-valuemin`/`aria-valuemax`, so the clock is the value a
  reader hears (the same rule the shipped sliders follow).
- **The waveform is decorative.** `peaks` draws one tinted `<svg>` silhouette
  (the runtime's single-mask route); it is not a second seek surface.
- **The clock is the player's.** `defaultPlayhead` and `defaultPlaying` are
  starting points and the two callbacks report every change; the component owns
  the interval, so a caller does not drive the playhead frame by frame.
- **A disabled player stops.** Its clock is not a background job, and its pad
  leaves the tab order while the picture and waveform keep painting.
- **A finished clip restarts on Play.** Pressing Play at the clip's end starts
  from zero, the way a player's own button does.
- **Values that cannot be laid out read as defaults**: a stored `duration` that
  is not positive is a zero-length clip, and a stored `tickMs`, `seekStep`,
  `width`, `height` or `trackWidth` that is not positive reads as its default.
- **A decoded frame is read structurally.** `frameAt`'s answer is a decoder's
  output, so a frame that arrived without its bytes, with a partial buffer or
  with a box that cannot be laid out paints no picture and keeps the transport
  running — a decoder's failure must not unmount the player (`isFrame`).
- **A stored `peaks` must be a list**: `peaks` is a decode's output or a saved
  record's field, so a value that is not a list — `null`, a number, an object
  from an older shape — paints no waveform rather than throwing out of the
  render, and a list whose entry is not a number keeps its shape and draws a
  flat point (`peaksOf`).
