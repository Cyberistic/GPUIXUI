---
title: DropZone
description: A labelled drop target that reports dropped files and offers a pick action
---

## Usage

```tsx
import { DropZone } from "@gpuixui/media";

<DropZone
  label="Drop files here"
  description="or pick them from the platform"
  onDrop={({ files }) => addFiles(files.map((file) => file.path))}
  onPick={() => renderer.promptForPaths({ allowMultiple: true })}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` (required) | — |
| `onDrop` | `(payload: DropPayload) => void` (required) | — |
| `description` | `string` | — |
| `onPick` | `() => void` | — |
| `pickLabel` | `string` | `"Choose files"` |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |

## Limitations

- **No drag preview or drag-over event** in 0.11.0; the highlight is the pointer wash.
- **No automatable live drop**: only the offscreen renderer simulates one.
- A drop is swallowed while a text field holds the input session.
