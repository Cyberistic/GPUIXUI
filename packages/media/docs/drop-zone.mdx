## Usage

```tsx
import { DropZone } from "@gpuixui/media";

<DropZone
  label="Drop files here"
  description="or pick them from the platform"
  onDrop={({ files }) => addFiles(files.map((file) => file.path))}
  onPick={() => renderer.promptForPaths({ allowMultiple: true })}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` (required) | `"Drop files"` (a blank label reads as the default) |
| `onDrop` | `(payload: DropPayload) => void` (required) | — |
| `description` | `string` | — |
| `onPick` | `() => void` | — |
| `pickLabel` | `string` | `"Choose files"` (a blank label reads as the default) |
| `disabled` | `boolean` | `false` |
| `className` | `string` | — |

## Limitations

- **No drag preview or drag-over event** in 0.11.0; the highlight is the pointer wash.
- **A disabled zone paints at rest**: it refuses the drop and the pick, and the hover highlight goes with them rather than promising an action it will not take.
- **No automatable live drop**: only the offscreen renderer simulates one.
- A drop is swallowed while a text field holds the input session.
- A **blank `label`** reads as `"Drop files"`: it is both the visible headline and the group's accessible name, so an empty i18n row would otherwise paint an empty line above a group with no name.
- A **blank `pickLabel`** reads as `"Choose files"` and is trimmed, so the one reliable route on a host without a drop event is never an unnamed action.
- **A blank `description` paints no line**: `description` is copy from a data table or an i18n file, so an empty or whitespace-only one is an absence — the pinned runtime lays out `""` at 0px and a run of spaces at 16px, so it is read through `visibleCopy` before the paint and a description given is painted exactly as written.
