---
title: Fieldset
description: A named group of fields with a disabled state.
---

## Usage

```tsx
import { Field, FieldInput, Fieldset } from "@gpuixui/components";

<Fieldset legend="Billing address" disabled={saving}>
  <Field label="Street" description="Street and number">
    <FieldInput value={street} onChange={(event) => setStreet(event.value ?? "")} />
  </Field>
  <Field label="City" description="Where the invoice is sent">
    <FieldInput value={city} onChange={(event) => setCity(event.value ?? "")} />
  </Field>
</Fieldset>;
```

## Composition

```text
Fieldset
└── FieldsetLegend
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Fieldset` | `div` with `role="group"` | `legend` (required), `disabled?` |
| `FieldsetLegend` | `text` | `disabled?` |

## Limitations

- No `fieldset` element and no `aria-disabled`.
- Disabled propagation is opt-in; `FieldInput` honours it.
- A disabled `FieldInput` is `readOnly`, not a disabled input.
