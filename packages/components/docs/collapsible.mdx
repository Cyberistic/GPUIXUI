title: Collapsible
description: One section that reveals its body on demand
---

<ComponentPreview name="collapsible-states" />

For several sections open at once, reach for [Accordion](/components/accordion):
it prerenders its bodies, which a collapsible does not.

## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@gpuixui/components/collapsible";

<Collapsible defaultOpen={false}>
  <CollapsibleTrigger>Advanced options</CollapsibleTrigger>
  <CollapsibleContent>
    <Option label="Retry budget" value="3 attempts" />
  </CollapsibleContent>
</Collapsible>;
```

## Composition

```text
Collapsible
├── CollapsibleTrigger
└── CollapsibleContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Collapsible` | `div` column | `open?`, `defaultOpen?` (default `false`), `onOpenChange?` |
| `CollapsibleTrigger` | `div role="button"` with `aria-expanded` | `disabled?`, `style?: StateStyle<CollapsibleTriggerState>`, `className?` |
| `CollapsibleContent` | `div`, mounted while open | `children`, `className?` |

## Limitations

- The body grows from zero to the height it measures; the target is read before the opening frame paints.
- A `Tab` traversal focuses the trigger **without running its `onFocus`**; the ring is declared at rest.
- No `aria-controls`; the trigger–body relationship is positional.
