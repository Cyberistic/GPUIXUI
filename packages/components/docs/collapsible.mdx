## Usage

```tsx
import {
  Collapsible,
  CollapsibleContent,
  CollapsibleTrigger,
} from "@gpuixui/components/collapsible";

<Collapsible defaultOpen={false}>
  <CollapsibleTrigger>Advanced options</CollapsibleTrigger>
  <CollapsibleContent>
    <Option label="Retry budget" value="3 attempts" />
  </CollapsibleContent>
</Collapsible>;
```

## Composition

```text
Collapsible
├── CollapsibleTrigger
└── CollapsibleContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Collapsible` | `div` column | `open?`, `defaultOpen?` (default `false`), `onOpenChange?` |
| `CollapsibleTrigger` | `div role="button"` with `aria-expanded` | `disabled?`, `style?: StateStyle<CollapsibleTriggerState>` |
| `CollapsibleContent` | `div`, mounted while open | `children` |

## Limitations

- The first open grows from zero; the body's height is its own measurement.
- A `Tab` traversal focuses the trigger without running its `onFocus`.
- No `aria-controls`; the trigger–body relationship is positional.
- The collapse unmounts the body, so state inside does not survive.
