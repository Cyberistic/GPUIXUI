## Usage

```tsx
import { Field, FieldInput, Form } from "@gpuixui/components";
import { Button } from "@gpuixui/primitives";

const Signup = Schema.Struct({
  email: Schema.NonEmptyString,
  name: Schema.NonEmptyString,
});

<Form schema={Signup} value={{ email, name }} pending={saving} onSubmit={save}>
  {(form) => (
    <div style={{ display: "flex", flexDirection: "column", gap: 12 }}>
      <Field label="Email">
        <FieldInput value={email} onChange={(event) => setEmail(event.value ?? "")} />
      </Field>
      <Field label="Name">
        <FieldInput value={name} onChange={(event) => setName(event.value ?? "")} />
      </Field>
      <Button onClick={form.submit} disabled={form.pending}>
        Create account
      </Button>
    </div>
  )}
</Form>;
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Form` | `div` (`role="form"` when `label` is given) | `schema` (required), `value` (required), `onSubmit` (required), `pending?`, `label?`, `children` |

## Limitations

- Owned-value: the caller passes the value.
- The `schema` and submit handler are read when the form mounts.
- One submit reports every failing field.

## Related

- **Field** — one label, control and message.
- **Fieldset** — a named group of fields.
- **Toast** — report the result of a successful submit.
