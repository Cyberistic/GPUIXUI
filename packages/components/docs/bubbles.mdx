## Usage

```tsx
import { Bubbles } from "@gpuixui/components/bubbles";

<div style={{ position: "relative", height: 260, overflow: "hidden" }}>
  <div style={{ position: "absolute", top: 0, right: 0, bottom: 0, left: 0 }}>
    <Bubbles count={32} seed={7} />
  </div>
  <EmptyState title="Preparing your workspace" />
</div>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `count` | `number` | `24` |
| `seed` | `number` | `1` |
| `minSize` | `number` | `6` |
| `maxSize` | `number` | `28` |
| `color` | `string` | theme `primary` |
| `riseMs` | `number` | `7_000` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<BubblesState>` | — |

## Limitations

- A rise, not a shape: bubbles travel without scaling or wobbling.
- The box must be bounded by the caller.
- A hidden field keeps animating; unmount it when off screen.
- No accessibility node; the content owns the words.
