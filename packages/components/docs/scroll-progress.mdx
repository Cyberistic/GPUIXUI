## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { ScrollProgress } from "@gpuixui/components/scroll-progress";

<ScrollProgress label="Settings read" style={{ height: 240 }}>
  {settings.map((setting) => (
    <SettingsRow key={setting.id} setting={setting} />
  ))}
</ScrollProgress>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `side` | `"top" \| "bottom"` | `"bottom"` |
| `thickness` | `number` | `3` |
| `color` | `string` | `theme.colors.primary` |
| `trackColor` | `string` | `theme.colors.muted` |
| `label` | `string` | — |
| `testId` | `string` | — |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |

## Limitations

- No tween; the line follows the offset.
- Vertical only.
- No `aria-valuenow`; the reading is text.
- A stored `label` that is not text is no name: `nameOf` reads it at the boundary, so the region keeps the primitives' `Scroll region` default and the bar is announced by value.
