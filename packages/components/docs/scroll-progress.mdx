## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { ScrollProgress } from "@gpuixui/components/scroll-progress";

<ScrollProgress label="Settings read" style={{ height: 240 }}>
  {settings.map((setting) => (
    <SettingsRow key={setting.id} setting={setting} />
  ))}
</ScrollProgress>;
```

## Keyboard

The viewport is a tab stop that names itself a scroll region, so the same box
the line reads is the one a keyboard reader moves: arrows scroll a row,
PageUp/PageDown a page and Home/End the ends. `label` names the region as well
as the reading line.

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `side` | `"top" \| "bottom"` | `"bottom"` |
| `thickness` | `number` | `3` |
| `color` | `string` | `theme.colors.primary` |
| `trackColor` | `string` | `theme.colors.muted` |
| `label` | `string` | — |
| `testId` | `string` | — |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |

## Limitations

- No tween; the line follows the offset.
- Vertical only.
- No `aria-valuenow`; the reading is text.
- The scrollbar's thumb takes no pointer input; the wheel and the keys are the routes.
