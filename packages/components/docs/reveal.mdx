title: Reveal

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Reveal } from "@gpuixui/components/reveal";

<Reveal>
  <text>Automatic updates are on.</text>
</Reveal>;
```

## Examples

### On a state change

Pass `open` to enter and leave; omit it for a mount reveal.

```tsx
<Reveal open={showing} from="right">…</Reveal>
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` | — |
| `from` | `RevealFrom` | `"below"` |
| `distance` | `number` | `8` |
| `level` | `MotionLevel` | `"normal"` |
| `delayMs` | `number` | `0` |
| `className` | `string` | — |
| `style` | `StateStyle<RevealState>` | — |

## Limitations

- No zoom or blur; `transform` and `filter` are absent.
- The offset does not reflow neighbours.
- One axis; a diagonal arrival is not expressible.
- A `from` the component does not name paints the house `below` arrival instead
  of failing: the value can be a stored setting the type never checked.
- No scroll-triggered reveal.
