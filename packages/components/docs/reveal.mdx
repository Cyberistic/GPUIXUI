## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Reveal } from "@gpuixui/components/reveal";

<Reveal>
  <text>Automatic updates are on.</text>
</Reveal>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `open` | `boolean` | — |
| `from` | `RevealFrom` | `"below"` |
| `distance` | `number` | `8` |
| `level` | `MotionLevel` | `"normal"` |
| `delayMs` | `number` | `0` |
| `className` | `string` | — |
| `style` | `StateStyle<RevealState>` | — |

## Limitations

- No zoom or blur; `transform` and `filter` are absent.
- The offset does not reflow neighbours.
- One axis; a diagonal arrival is not expressible.
