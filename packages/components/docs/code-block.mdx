## Usage

```tsx
import { CodeBlock } from "@gpuixui/components/code-block";

<CodeBlock
  code={source}
  title="src/app.tsx"
  language="tsx"
  lineNumbers
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `code` | `string` | — |
| `title` | `string` | falls back to `path` |
| `path` | `string` | — |
| `language` | `string` | path's extension |
| `lineNumbers` | `boolean` | `false` |
| `height` | `number` | — |
| `level` | `SurfaceLevel` | `"normal"` |
| `emptyLabel` | `string` | `"No code"` |
| `copyLabel` | `string` | `"Copy"` |
| `copiedLabel` | `string` | `"Copied"` |
| `onCopy` | `(code: string) => void` | — |
| `className` | `string` | — |
| `style` | `StateStyle<CodeBlockState>` | — |

## Limitations

- `level` is read through `surfaceLevelOf`, so a saved `"none"` paints at rest; the table's own `motionLevelOf` would animate it.
- The code text is not exposed to assistive technology.
- `@tanstack/highlight` decides what a run is; the palette only colours it.
- A language the tokenizer does not ship falls back to plain text.
- A stored `aria-label` (or copy label) that is not text is no name: `nameOf` reads it at the boundary, so the block announces its header's title (or `Code`) and the action its default words.
