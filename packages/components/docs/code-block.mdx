## Usage

```tsx
import { CodeBlock } from "@gpuixui/components/code-block";

<CodeBlock
  code={source}
  title="src/app.tsx"
  language="tsx"
  lineNumbers
/>;
```

## Examples

### Theme the syntax palette

```tsx
import { ThemeProvider } from "@gpuixui/components";
import { extendTheme, syntaxColors } from "@gpuixui/tokens";

const brand = extendTheme(theme, {
  syntax: { ...syntaxColors(theme), keyword: "#7A1F5C", string: "#0B5E4A" },
});

<ThemeProvider theme={brand}>
  <CodeBlock code={source} language="ts" />
</ThemeProvider>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `code` | `string` | — |
| `title` | `string` | falls back to `path` |
| `path` | `string` | — |
| `language` | `string` | path's extension |
| `lineNumbers` | `boolean` | `false` |
| `height` | `number` | — |
| `level` | `MotionLevel \| "none"` | `"normal"` |
| `emptyLabel` | `string` | `"No code"` |
| `copyLabel` | `string` | `"Copy"` |
| `copiedLabel` | `string` | `"Copied"` |
| `onCopy` | `(code: string) => void` | — |
| `className` | `string` | — |
| `style` | `StateStyle<CodeBlockState>` | — |

## Limitations

- The code text is not exposed to assistive technology.
- `@tanstack/highlight` decides what a run is; the palette only colours it.
- A language the tokenizer does not ship falls back to plain text.
- No clipboard write; `onCopy` hands the source to the caller.
