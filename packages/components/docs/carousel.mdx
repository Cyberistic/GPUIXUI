## Usage

```tsx
import {
  Carousel,
  CarouselControl,
  CarouselIndicators,
  CarouselSlide,
  CarouselTrack,
} from "@gpuixui/components";

<Carousel label="Workspace previews" value={index} onValueChange={setIndex} loop>
  <CarouselTrack>
    <CarouselSlide>…</CarouselSlide>
    <CarouselSlide>…</CarouselSlide>
  </CarouselTrack>
  <CarouselControl direction="previous" />
  <CarouselControl direction="next" />
  <CarouselIndicators />
</Carousel>;
```

## Composition

```text
Carousel
├── CarouselTrack
│   └── CarouselSlide
├── CarouselControl
└── CarouselIndicators
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Carousel` | `role="group"` named by `label`, `tabIndex={0}` | `label` (required), `value?`, `defaultValue?` (0), `onValueChange?`, `loop?`, `className?`, `children` |
| `CarouselTrack` | the slide row | `className?`, `children` (slides must be direct) |
| `CarouselSlide` | one slide, or nothing while another is on screen | `style?: StateStyle<CarouselSlideState>` (`{ index }`), `className?`, `children` |
| `CarouselControl` | button | `direction: "previous" \| "next"`, `label?`, `disabled?` |
| `CarouselIndicators` | `role="group"` of named dots | `label?`, `style?: StateStyle<CarouselIndicatorsState>`, `className?` |

## Limitations

- **Measured in a window**: `carousel-lifecycle` (97 checks, 0.11.0) mounts the
  shipped carousel on three slides that each carry their own fill, label ink and
  height. The two slides not on screen paint **0** fill and **0** ink at every
  index — the renderer ignores `display: none`, so unmounting is what keeps them
  out — and the frame takes the height of the slide on screen (122 → 162 → 102)
  while its origin and width hold, which is why the track does not travel. In
  the press's own frame the indicator's inks have already swapped while the
  widths are still the previous ones (an 18×6 `primary` pill and 6×6
  `mutedForeground` dots, measured inside their 24px targets).
- The track does not travel; the frame is sized by the slide on screen.
- No swipe, drag or scroll snap.
- No auto-advance or thumbnails.
- A slide's local state does not survive a visit, because only the mounted slide
  exists.
