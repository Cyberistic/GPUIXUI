title: Carousel

## Usage

```tsx
import {
  Carousel,
  CarouselControl,
  CarouselIndicators,
  CarouselSlide,
  CarouselTrack,
} from "@gpuixui/components";

<Carousel label="Workspace previews" value={index} onValueChange={setIndex} loop>
  <CarouselTrack>
    <CarouselSlide>…</CarouselSlide>
    <CarouselSlide>…</CarouselSlide>
  </CarouselTrack>
  <CarouselControl direction="previous" />
  <CarouselControl direction="next" />
  <CarouselIndicators />
</Carousel>;
```

## Composition

```text
Carousel
├── CarouselTrack
│   └── CarouselSlide
├── CarouselControl
└── CarouselIndicators
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Carousel` | `role="group"` named by `label`, `tabIndex={0}` | `label` (required), `value?`, `defaultValue?` (0), `onValueChange?`, `loop?` |
| `CarouselTrack` | the slide row | children (slides must be direct) |
| `CarouselSlide` | one slide | `style?: StateStyle<CarouselSlideState>` |
| `CarouselControl` | button | `direction: "previous" \| "next"`, `label?`, `disabled?` |
| `CarouselIndicators` | `role="group"` of named dots | `label?`, `style?: StateStyle<CarouselIndicatorsState>` |

## Limitations

- The track does not travel; the frame is sized by the visible slide.
- No swipe, drag or scroll snap.
- No auto-advance or thumbnails.
- Inactive slides stay mounted; many heavy slides cost render time.
