---
title: Accordion
description: Stacked sections where one — or several — can be open.
---

`Accordion` is a list of collapsible sections that agree on which ones are open.
The two modes have genuinely different state: a single optional value, or an
ordered set. That is modelled as a tagged union in `accordion/logic.ts`, not as a
list plus a boolean.

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@gpuixui/components/accordion";

<Accordion type="single" collapsible={false} defaultValue="what">
  <AccordionItem value="what">
    <AccordionTrigger>What is GPUix?</AccordionTrigger>
    <AccordionContent>A native rendering runtime…</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## Anatomy

| Part | Responsibility |
| ---- | -------------- |
| `Accordion` | the open state, the mode rules, the divider order |
| `AccordionItem` | one section, its value and its disabled flag |
| `AccordionTrigger` | a full-width button with `aria-expanded` and the glyph |
| `AccordionContent` | the body; unmounts while its section is closed |

## The two modes

| Mode | Rules |
| ---- | ----- |
| `type="single"` | opening another section closes the first; toggling the open one is a no-op unless `collapsible` |
| `type="single" collapsible` | toggling the open section closes it, leaving nothing open |
| `type="multiple"` | toggling adds or removes; the order sections were opened in is preserved and duplicates are impossible |

Disabled items are skipped by clicks and keys, and their trigger leaves the tab
order.

## Controlled and uncontrolled

```tsx
<Accordion type="multiple" defaultValue={["one"]}>…</Accordion>;

<Accordion
  type="single"
  collapsible
  value={openSection}                 // `null` means "nothing open"
  onValueChange={setOpenSection}
>
  …
</Accordion>;
```

Single mode reports `string | null` — `null` is how a controlled, collapsible
accordion expresses "closed". `undefined` is reserved for "uncontrolled", which
is why it is not used for the closed state. Multiple mode reports the array.

## Keyboard

The trigger is a button: Tab reaches it, Enter and Space toggle it.

| Key | Effect |
| --- | ------ |
| `Enter` / `Space` | toggle the focused section |
| `↓` / `↑` | focus the next/previous enabled header, wrapping |
| `Home` / `End` | focus the first/last enabled header |

Arrow movement changes focus only — it never opens or closes a section. Disabled
headers are skipped, and a control inside an open section keeps its own arrow
keys because the handler lives on the trigger, not the accordion root.

## Theming

Triggers use the `label` type role at `controlHeight(theme, "lg")`, with
`colors.foreground` and `colors.primary` on hover. Sections are separated by a
`borderWidth.thin` divider in `colors.border`; the last section draws none. The
indicator is a text glyph (`⌄` closed, `⌃` open) because 0.10.0's `StyleDesc`
has no `transform` — a rotation is not available.

## Style by state

`AccordionTrigger` takes a `StyleDesc` or a function of `AccordionTriggerState`
(`{ open, disabled, focused }`).

```tsx
<AccordionTrigger
  style={(state) => ({ opacity: state.open ? 1 : 0.8 })}
/>
```

## Accessibility and limitations

- `aria-expanded` on each trigger; the trigger names the section.
- **No `aria-controls`** in 0.10.0; the relationship is positional.
- The indicator glyph carries `aria-label="Expand"` / `"Collapse"`.
- Arrow keys move focus between enabled headers; they do not activate them.
- No height animation (see **Collapsible** for the measured reason).

## Verification

`src/behaviour/accordion.test.tsx` runs in the real GPUix renderer (13 tests):
single mode closing the previous section, the non-collapsible no-op, the
collapsible close, multiple mode keeping sections, the disabled section, Enter
activation, the controlled contract including the `null` close, arrow /
`Home` / `End` movement between headers (wrapping past a disabled one, without
opening it), and a caller header `ref`.

`src/accordion/logic.test.ts` covers the transition table (15 cases), and
`src/internal/collection.test.ts` covers the shared movement arithmetic.

```sh
nub run --filter @gpuixui/components test:behaviour
```
