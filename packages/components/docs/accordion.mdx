title: Accordion
description: Stacked sections where one — or several — can be open
---

## Usage

```tsx
import {
  Accordion,
  AccordionContent,
  AccordionItem,
  AccordionTrigger,
} from "@gpuixui/components/accordion";

<Accordion type="single" collapsible defaultValue="what">
  <AccordionItem value="what">
    <AccordionTrigger>What is GPUix?</AccordionTrigger>
    <AccordionContent>A native rendering runtime.</AccordionContent>
  </AccordionItem>
</Accordion>;
```

## Composition

```text
Accordion
├── AccordionItem
│   ├── AccordionTrigger
│   └── AccordionContent
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Accordion` | `type` | `"single" \| "multiple"` (required) | — |
| `Accordion` | `collapsible` | `boolean` | `false` |
| `Accordion` | `value` / `defaultValue` | `string \| null` (single) · `ReadonlyArray<string>` (multiple) | — |
| `Accordion` | `onValueChange` | `(value: string \| null) => void` | — |
| `AccordionItem` | `value` | `string` (required) | — |
| `AccordionItem` | `disabled` | `boolean` | `false` |
| `AccordionTrigger` | `style` | `StateStyle<AccordionTriggerState>` | recipe |
| `AccordionContent` | `children` | `ReactNode` | — |

## Limitations

- No `aria-controls`; the trigger–body relationship is positional.
- A `Tab` traversal focuses the trigger **without running its `onFocus`**; the ring is declared at rest.
- The body grows and collapses through its measured height.
