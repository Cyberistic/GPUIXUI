## Usage

```tsx
import {
  DatePicker,
  DatePickerCalendar,
  DatePickerContent,
  DatePickerTrigger,
} from "@gpuixui/components/date-picker";

<DatePicker value={due} onValueChange={setDue} today="2026-10-22">
  <DatePickerTrigger label="Due date" />
  <DatePickerContent>
    <DatePickerCalendar />
  </DatePickerContent>
</DatePicker>;
```

A span is the same parts with `mode="range"`; the value is `{ from, to }` of ISO
days, and the surface closes when the second day completes it.

```tsx
<DatePicker mode="range" value={window} onValueChange={setWindow}>
  <DatePickerTrigger label="Booking window" />
  <DatePickerContent>
    <DatePickerCalendar />
  </DatePickerContent>
</DatePicker>;
```

## Limitations

- Disabling a picker with its calendar open closes it; neither a day nor `Clear` writes the value.
- No `aria-current`; today is marked by a border.
- No `aria-disabled`; an unavailable day leaves the tab order.
