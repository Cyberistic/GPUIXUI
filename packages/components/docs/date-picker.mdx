## Usage

```tsx
import {
  DatePicker,
  DatePickerCalendar,
  DatePickerContent,
  DatePickerTrigger,
} from "@gpuixui/components/date-picker";

<DatePicker value={due} onValueChange={setDue}>
  <DatePickerTrigger label="Due date" />
  <DatePickerContent>
    <DatePickerCalendar />
  </DatePickerContent>
</DatePicker>;
```

## Composition

```text
DatePicker
├── DatePickerTrigger
└── DatePickerContent
    └── DatePickerCalendar
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `DatePicker` | `value` / `defaultValue` | `string \| null` — an ISO day | — / `null` |
| `DatePicker` | `onValueChange` | `(value: string \| null) => void` | — |
| `DatePicker` | `weekStartsOn` | `1..7` | `1` |
| `DatePicker` | `min` / `max` | ISO day, inclusive | unbounded |
| `DatePicker` | `clearable` | `boolean` | `false` |
| `DatePicker` | `disabled` | `boolean` | `false` |
| `DatePicker` | `today` | ISO day | runtime clock |
| `DatePickerTrigger` | `placeholder` / `label` | `string` | `"Pick a date"` / — |
| `DatePickerTrigger` | `onActivate` / `onClick` | `(event) => void` — the action's one handler; `onClick` is the deprecated alias | — |
| `DatePickerTrigger` | action props | `variant`, `size`, `disabled`, `loading`, `style` — the shared `Button` contract, because the trigger *is* that action | — |
| `DatePickerContent` | `side` / `align` | `"top" \| "right" \| "bottom" \| "left"` · `"start" \| "center" \| "end"` | `"bottom"` / `"start"` |
| `DatePickerContent` | `sideOffset` | `number` | `6` |
| `DatePickerCalendar` | `label` | `string` | `"Calendar"` |

## Limitations

- A picker the consumer disables while its calendar is open closes with it,
  and neither a day nor `Clear` writes the value (the trigger already refuses to
  open one that starts disabled).
- No `aria-current`; today is marked by a border.
- No `aria-disabled`; an unavailable day leaves the tab order.
- Fixed English labels; no i18n layer.
- No adjacent-month days, range selection or time of day.
