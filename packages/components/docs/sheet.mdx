## Usage

```tsx
import {
  Sheet,
  SheetClose,
  SheetContent,
  SheetDescription,
  SheetFooter,
  SheetHeader,
  SheetTitle,
  SheetTrigger,
} from "@gpuixui/components";
```

`Sheet` is shadcn's name for the surface `Drawer` already paints: a veil over
the window, a panel on one edge, a focus trap inside it, Escape and an outside
press to close, and focus returned to the opener. It re-exports that machinery,
so the drawing above is the Drawer page's — there is one implementation, not two.

The sheet **animates in**: the panel slides its own span from the edge it names
(a bottom sheet rises a whole 320px) over the `slow` level, the veil fades, and
the surface is clipped by the window while it travels. A bottom sheet wears the
vaul grabber and rounded inner corners; `MotionProvider preference="reduced"`
paints the settled frame at once. The veil is the page's background at 55%; the
blur the drawing carries has no native route (`StyleDesc` has no `filter`).

```tsx
<Sheet>
  <SheetTrigger>Filters</SheetTrigger>
  <SheetContent side="right" label="Filters">
    <SheetHeader>
      <SheetTitle>Filters</SheetTitle>
      <SheetDescription>Narrow the result set, then apply.</SheetDescription>
    </SheetHeader>
    <SheetFooter>
      <SheetClose>Cancel</SheetClose>
    </SheetFooter>
  </SheetContent>
</Sheet>
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Sheet` | `open` | `boolean` | uncontrolled |
| `Sheet` | `onOpenChange` | `(open: boolean) => void` | none |
| `Sheet` | `dismissible` | `boolean` | `true` |
| `SheetTrigger` | `disabled` | `boolean` | `false` |
| `SheetClose` | `disabled` | `boolean` | `false` |
| `SheetContent` | `side` | "left" \| "right" \| "top" \| "bottom" | `"right"` |
| `SheetContent` | `size` | "sm" \| "md" \| "lg" | `"md"` |
| `SheetContent` | `label` | `string` (required) | none |
| `SheetContent` | `grabber` | `boolean` — the vaul handle on a top/bottom sheet | `true` |
| `SheetContent` | `initialFocus` | `() => number \| null` | none |
| `SheetHeader` | `children` | `ReactNode` | — |
| `SheetTitle` | `children` | `ReactNode` | — |
| `SheetDescription` | `children` | `ReactNode` | — |
| `SheetFooter` | `children` | `ReactNode` | — |

## Limitations

- No swipe-to-dismiss and no snap points: the runtime has no drag host, so the
  grabber cannot be dragged.
- The slide is a numeric `left`/`top` offset of the surface's own span, not a
  `transform`; the content keeps its layout because the box moves, not the flow.
- The veil is an anchored element at window coordinates, not a portalled surface,
  and it cannot blur the page: `StyleDesc` has no `filter`.
- The surface rounds only the corners inside the window; the edge it opens from
  stays flush.
