---
title: Magnetic
description: A surface whose content leans toward the pointer while it is over it.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Magnetic } from "@gpuixui/components/magnetic";

<Magnetic onClick={open}>
  <Card>
    <CardTitle>Notes</CardTitle>
  </Card>
</Magnetic>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `strength` | `number` | `0.35` |
| `maxOffset` | `number` | `12` |
| `level` | `MotionLevel` | `"fast"` |
| `className` | `string` | — |
| `style` | `StateStyle<{ pulled, reducedMotion }>` | — |
| `onMouseMove` | `(event) => void` | — |
| `onMouseLeave` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |

## Limitations

- Inset travel only; the runtime has no `transform`.
- The lean follows the box centre, not the pointer entry.
- Nothing moves before the first `onLayout`.
- Reduced motion and keyboard readers get no lean.
