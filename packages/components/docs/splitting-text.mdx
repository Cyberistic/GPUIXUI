---
title: Splitting text
description: A headline that arrives word by word with a staggered fade and rise.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SplittingText } from "@gpuixui/components/splitting-text";

<SplittingText text="Build native interfaces" role="h1" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `split` | `"words" \| "characters"` | `"words"` |
| `stepMs` | `number` | `40` |
| `from` | `"start" \| "end" \| "center"` | `"start"` |
| `offset` | `number` | `8` |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<SplittingTextState>` | — |

## Limitations

- Every unit is a host; split words for long text.
- No slide, scale or mask — no `transform`.
- A unit that changes replays its own run.
- The type role owns the font metrics.
