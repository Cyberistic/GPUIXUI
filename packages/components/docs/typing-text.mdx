---
title: Typing text
description: A string that arrives a character at a time, with the whole string as its name.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { TypingText } from "@gpuixui/components";

<TypingText text="Deploying to production…" speed={35} />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `speed` | `number` | `45` |
| `delay` | `number` | `0` |
| `caret` | `boolean` | `false` |
| `label` | `string` | the whole `text` |
| `onComplete` | `() => void` | — |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<TypingTextState>` | — |

## Limitations

- Real-time reveal, not synced to the renderer clock.
- The caret cannot follow a wrapped line.
- No per-glyph paint or stagger.
- No pause, resume or skip-to-end.
