## Usage

```tsx
import { Countdown } from "@gpuixui/components";

<Countdown remainingMs={90_000} label="Offer ends in" />;
// 01:30
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `remainingMs` | `number` (required) | — (negative or unreadable renders `00:00`, expired) |
| `label` | `string` | — |
| `showDays` | `boolean` | `false` |
| `style` | `StateStyle<CountdownState>` | — |

## Limitations

- A `NaN` or infinite remaining time paints `00:00` and reports `expired`.
- No timer inside the component; the application ticks.
- Fixed locale-free format; no localised units.
