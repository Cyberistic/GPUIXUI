---
title: Countdown
description: A remaining duration as clock text.
---

## Usage

```tsx
import { Countdown } from "@gpuixui/components";

<Countdown remainingMs={90_000} label="Offer ends in" />;
// 01:30
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `remainingMs` | `number` (required) | — |
| `label` | `string` | — |
| `showDays` | `boolean` | `false` |
| `style` | `StateStyle<CountdownState>` | — |

## Limitations

- No timer inside the component; the application ticks and re-renders.
- Fixed locale-free format; no localised units.
- No `aria-live`, so a change is read when focused, not pushed.
- No progress bar or ring.
