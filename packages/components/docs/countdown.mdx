---
title: Countdown
description: A remaining duration as clock text — without owning a timer.
---

`Countdown` renders **one remaining duration it is given**. It does not tick, and
that is deliberate: an Effect `Clock` (or the app's clock) owns time, and a
renderer timer would keep running after unmount and drift from the app's state.

## Usage

```tsx
import { Countdown } from "@gpuixui/components";

<Countdown remainingMs={90_000} label="Offer ends in" />;
// 01:30
```

The application ticks and re-renders. An Effect fiber at the boundary is the
recommended pattern (this is the example's own code):

```tsx
const fiber = Effect.runFork(
  Effect.forever(
    Effect.sleep(Duration.seconds(1)).pipe(
      Effect.flatMap(() =>
        Effect.sync(() => setRemaining((value) => Math.max(0, value - 1000))),
      ),
    ),
  ),
);
// cleanup: Effect.runFork(Fiber.interrupt(fiber))
```

The runnable build is `examples/countdown.example.tsx`, which the native
playground mounts.

## Formats

| Remaining | Output |
| --------- | ------ |
| `90_000` ms | `01:30` |
| `3_600_000` ms | `01:00:00` |
| `90_000_000` ms (25 h) | `25:00:00` — hours are uncapped |
| `90_000_000` ms with `showDays` | `1d 01:00:00` |
| `3_600_000` ms with `showDays` | `01:00:00` — no day prefix without a full day |
| `0` or negative | `00:00` |

Seconds are **floored**, not rounded: `59_999` ms is `00:59`. The format is fixed
and locale-free (the repo has no i18n layer); `showDays` treats a day as 24
hours, not as a calendar day.

## API

| Prop | Type | Default | Notes |
| ---- | ---- | ------- | ----- |
| `remainingMs` | `number` | — | Required. Negative values render `00:00`. |
| `label` | `string` | — | The accessible name; the value stays the text. |
| `showDays` | `boolean` | `false` | Adds the `Nd ` prefix once a full day remains. |
| `style` | `StateStyle<CountdownState>` | — | `CountdownState` is `{ remainingMs, expired }`. |

`Countdown` takes the GPUix host props (`testId`, `role`, `aria-*`) and merges
`style` last.

## Theming

`caption` type; `foreground` while time remains and `mutedForeground` once
expired. The component has no colour of its own, so a custom theme changes it
with no code change — see [Theming](/docs/theming).

## Accessibility

- The text is the value; `label` becomes the accessible name, so a screen reader
  hears "Offer ends in" rather than only "01:30".
- There is no `role="timer"` in `@gpuix/native@0.10.0`, so no live announcement
  is claimed. A countdown that must announce changes needs the application's
  own announcement strategy.
- The expired colour is visual; the accessible name does not become "expired".

## Limitations

- **No timer inside the component** — by design, not as a missing feature.
- Fixed locale-free format; no "2 hours ago", no localised units.
- No `role="timer"` and no live-region announcement in 0.10.0.
- No progress bar or ring; pair it with `Progress` when one exists.
