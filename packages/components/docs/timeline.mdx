title: Timeline
description: A read-only rail of events with an explicit status.
---

<ComponentPreview name="timeline-states" />

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Timeline, TimelineItem } from "@gpuixui/components";

<Timeline label="Release 2.4.0">
  <TimelineItem title="Build started" timestamp="09:41" status="complete" />
  <TimelineItem
    title="Tests passed"
    description="412 tests, 0 failures"
    timestamp="09:44"
  />
  <TimelineItem title="Deploying" timestamp="09:52" status="current" />
  <TimelineItem title="Smoke checks" status="upcoming" />
</Timeline>;
```

## Composition

```text
Timeline
└── TimelineItem
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Timeline` | `div` with `role="list"` | `label?`, children |
| `TimelineItem` | `div` with `role="listitem"` | `title` (required), `description?`, `timestamp?`, `status?`, `style?` |

## Limitations

- Display-only: no click or row activation.
- `last` comes from direct children.
- No connector styles beyond the border line.
- No `aria-current`; the current event uses `aria-selected`.
