## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { PinnedList } from "@gpuixui/components/pinned-list";

<PinnedList
  testId="settings"
  aria-label="Settings"
  style={{ height: 360 }}
  sections={[
    { title: "Account", children: <AccountRows /> },
    { title: "Notifications", children: <NotificationRows /> },
    { title: "Danger zone", children: <DangerRows /> },
  ]}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `sections` | `ReadonlyArray<PinnedListSection>` (a value that is not a list reads as none; an entry without a text `title` is dropped) | — |
| `headerHeight` | `number` | `32` |
| `surfaceColor` | `string` | theme `background` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |
| `testId` | `string` | — |
| `aria-label` | `string` | the runtime's "Scroll region" |
| `onScrollChange` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |

## Limitations

- No `position: sticky`; the header is a repositioned layer.
- A held header is a painted surface over the rows, not a hit target: the layer,
  the header and its title all take `pointerEvents: "none"`, so a press in the
  first `headerHeight` points of the viewport reaches the row beneath. A control
  placed there still works, but it is visually covered while the header holds.
- Vertical only; the scrollbar's thumb takes no pointer input.
- One line per header.
- A section's height is measured once and kept with the section's **title**, so reordering `sections` places every header by the rows it actually holds. A section that changes height reports again; a section with no readable report yet counts as `0`, so its header sits at the start until the layout arrives.
- **A stored section list is read**: a sectioned list is restored with a saved layout as often as it is written in code, so a value that is not a list — JSON's `null` for one a record never carried — paints an empty list rather than throwing from the first header, and an entry without a text `title` is not a section: it is dropped while its neighbours paint (`sectionsOf`).
- A stored `aria-label` that is not text is no name: `nameOf` reads it at the boundary, so the region keeps the primitives' `Scroll region` default.
