title: Pinned list
description: A scroll box whose section headers stay pinned while rows scroll under them
---

<ComponentPreview name="pinned-list-demo" />

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { PinnedList } from "@gpuixui/components/pinned-list";

<PinnedList
  testId="settings"
  aria-label="Settings"
  style={{ height: 360 }}
  sections={[
    { title: "Account", children: <AccountRows /> },
    { title: "Notifications", children: <NotificationRows /> },
    { title: "Danger zone", children: <DangerRows /> },
  ]}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `sections` | `ReadonlyArray<PinnedListSection>` | — |
| `headerHeight` | `number` | `32` |
| `surfaceColor` | `string` | theme `background` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |
| `testId` | `string` | — |
| `aria-label` | `string` | the runtime's "Scroll region" |
| `onScrollChange` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |

## Limitations

- No `position: sticky`; the header is a repositioned layer.
- Vertical only; the scrollbar's thumb takes no pointer input.
- One line per header.
