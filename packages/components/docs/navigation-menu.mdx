---
title: Navigation menu
description: A horizontal nav whose items open one anchored panel at a time.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  NavigationMenu,
  NavigationMenuContent,
  NavigationMenuItem,
  NavigationMenuLink,
  NavigationMenuList,
  NavigationMenuTrigger,
} from "@gpuixui/components";

<NavigationMenu label="Product">
  <NavigationMenuList>
    <NavigationMenuItem value="platform">
      <NavigationMenuTrigger>Platform</NavigationMenuTrigger>
      <NavigationMenuContent>
        <NavigationMenuLink onSelect={() => go("overview")}>Overview</NavigationMenuLink>
      </NavigationMenuContent>
    </NavigationMenuItem>
  </NavigationMenuList>
</NavigationMenu>;
```

## Composition

```text
NavigationMenu
└── NavigationMenuList
    └── NavigationMenuItem
        ├── NavigationMenuTrigger
        └── NavigationMenuContent
            └── NavigationMenuLink
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `NavigationMenu` | `role="navigation"` named by `label` | `label` (required), `value?`, `defaultValue?`, `onValueChange?`, `openDelay?`, `closeDelay?`, children |
| `NavigationMenuList` | `role="list"` row | children |
| `NavigationMenuItem` | `role="listitem"` | `value` (required), children |
| `NavigationMenuTrigger` | button with `aria-expanded` | button props |
| `NavigationMenuContent` | anchored `role="group"` panel | children |
| `NavigationMenuLink` | a full-width button row | `onSelect?`, button props |

## Limitations

- No `href`; `NavigationMenuLink` is a button.
- Hover is a timer policy; touch opens by press.
- `ArrowDown` focuses the panel surface.
- No `aria-haspopup`.
