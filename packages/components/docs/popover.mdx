## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@gpuixui/components/popover";

<Popover>
  <PopoverTrigger>Columns</PopoverTrigger>
  <PopoverContent side="bottom" align="end">
    <ColumnToggles />
  </PopoverContent>
</Popover>;
```

## Composition

```text
Popover
├── PopoverTrigger
└── PopoverContent
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Popover` | `open` / `defaultOpen` | `boolean` | — / `false` |
| `Popover` | `onOpenChange` | `(open: boolean) => void` | — |
| `PopoverContent` | `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `PopoverContent` | `align` | `"start" \| "center" \| "end"` | `"start"` |
| `PopoverContent` | `sideOffset` | `number` | `6` |
| `PopoverContent` | `collisionPadding` | `number` | `8` |
| `PopoverContent` | `alignOffset` | `number` | `0` |

## Limitations

- No `aria-haspopup`, `aria-controls` or `aria-labelledby`.
- No arrow, custom anchor or backdrop.
- `align="center"` cannot centre a surface at the window edge.
- An outside press does not restore focus.
