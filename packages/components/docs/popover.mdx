## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@gpuixui/components/popover";

<Popover>
  <PopoverTrigger>Columns</PopoverTrigger>
  <PopoverContent side="bottom" align="end">
    <ColumnToggles />
  </PopoverContent>
</Popover>;
```

## Sides

<ComponentPreview name="popover-sides" />

`side` names the edge the surface opens on — `top`, `right`, `bottom` (the
default) or `left` — and `sideOffset` the gap to the trigger, 6px by default. The
requested side is kept unless it has **no room at all** for the surface; then it
flips to the opposite one, and the roomier side wins when neither fits. A panel
that merely overhangs the window keeps its side and slides back inside it.

```tsx
<PopoverContent side="right" align="start" sideOffset={8}>
  <ColumnToggles />
</PopoverContent>
```

## Collision

<ComponentPreview name="popover-collision" />

Near a window edge the runtime snaps the surface back by `collisionPadding`
(8px). The panel keeps the side it opened on and moves along that side; the
trigger does not move, and no sibling does either — the surface is an anchored
layer, out of the layout flow.

## Composition

```text
Popover
├── PopoverTrigger
└── PopoverContent
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Popover` | `open` / `defaultOpen` | `boolean` | — / `false` |
| `Popover` | `onOpenChange` | `(open: boolean) => void` | — |
| `Popover` | `children` | `PartChildren` | — |
| `PopoverTrigger` | `onActivate` / `onClick` | `(event) => void` — the action's one handler, then the popover toggles; `onClick` is the deprecated alias | — |
| `PopoverTrigger` | action props | `variant`, `size`, `disabled`, `loading`, `style` — the shared `Button` contract | `variant="secondary"` |
| `PopoverContent` | `side` | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"` |
| `PopoverContent` | `align` | `"start" \| "center" \| "end"` | `"center"` |
| `PopoverContent` | `sideOffset` | `number` | `6` |
| `PopoverContent` | `collisionPadding` | `number` | `8` |
| `PopoverContent` | `alignOffset` | `number` | `0` |
| `PopoverContent` | `className` | `string` | — |

## Motion

The panel fades and travels 8px out from the side it opens on, at the `normal`
level (200 ms); `MotionProvider preference="reduced"` paints the resting frame at
once. A leaving panel stays painted for its exit and takes no presses.
