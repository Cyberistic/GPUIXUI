## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Pagination,
  PaginationList,
  PaginationNext,
  PaginationPrevious,
} from "@gpuixui/components/pagination";

const [page, setPage] = useState(1);

<Pagination page={page} pageCount={9} onPageChange={setPage}>
  <PaginationPrevious />
  <PaginationList />
  <PaginationNext />
</Pagination>;
```

## Composition

```text
Pagination
├── PaginationPrevious
├── PaginationList
│   ├── PaginationItem
│   └── PaginationEllipsis
└── PaginationNext
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Pagination` | `page` | `number` (required) — 1-based, clamped | — |
| `Pagination` | `pageCount` | `number` (required) | — |
| `Pagination` | `onPageChange` | `(page: number) => void` (required) | — |
| `Pagination` | `siblingCount` | `number` | `1` |
| `Pagination` | `showEdges` | `boolean` | `true` |
| `PaginationPrevious` | `children` | `ReactNode` | a chevron and `Prev` |
| `PaginationPrevious` | `aria-label` | `string` | `"Previous page"` |
| `PaginationList` | `className` | `string` | — |
| `PaginationItem` | `page` | `number` (required) | — |
| `PaginationItem` | `style` | `StateStyle<PaginationItemState>` | recipe |
| `PaginationEllipsis` | `className` | `string` | — |
| `PaginationNext` | `children` | `ReactNode` | `Next` and a chevron |
| `PaginationNext` | `aria-label` | `string` | `"Next page"` |

`PaginationPrevious` and `PaginationNext` are the package's action at `ghost`
and `sm`, so they take the host props any button does; each leaves the tab order
and drops its handler at the edge it cannot pass (page 1 and the last page), and
the name a reader hears is the `aria-label` rather than the visible word.

## Limitations

- No `aria-current="page"`; the current page uses `aria-selected`.
- Controlled-only by design.
- No page-size selector.
