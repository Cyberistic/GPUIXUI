## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Pagination,
  PaginationList,
  PaginationNext,
  PaginationPrevious,
} from "@gpuixui/components/pagination";

const [page, setPage] = useState(1);

<Pagination page={page} pageCount={9} onPageChange={setPage}>
  <PaginationPrevious />
  <PaginationList />
  <PaginationNext />
</Pagination>;
```

## Composition

```text
Pagination
├── PaginationPrevious
├── PaginationList
│   ├── PaginationItem
│   └── PaginationEllipsis
└── PaginationNext
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Pagination` | `page` | `number` (required) — 1-based, clamped | — |
| `Pagination` | `pageCount` | `number` (required) | — |
| `Pagination` | `onPageChange` | `(page: number) => void` (required) | — |
| `Pagination` | `siblingCount` | `number` | `1` |
| `Pagination` | `showEdges` | `boolean` | `true` |
| `PaginationItem` | `page` | `number` (required) | — |
| `PaginationItem` | `style` | `StateStyle<PaginationItemState>` | recipe |

## Limitations

- No `aria-current="page"`; the current page uses `aria-selected`.
- Controlled-only by design.
- No page-size selector.
