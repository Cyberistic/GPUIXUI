## Usage

```tsx
import { ImageZoom } from "@gpuixui/components/image-zoom";

<ImageZoom
  src="/maps/harbour.png"
  alt="A chart of the harbour with four approaches"
  width={360}
  height={200}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `src` | `string` | — |
| `alt` | `string` (required) | — (a blank value reads as `"Picture"`) |
| `width` | `number` | `240` |
| `height` | `number` | `160` |
| `scale` | `number` | `1.6` |
| `radius` | `number` | `theme.radius.md` (a value that cannot be painted reads as the default; `0` stays square) |
| `level` | `MotionLevel` | `"normal"` |
| `className` | `string` | — |
| `style` | `StateStyle<ImageZoomState>` | — |
