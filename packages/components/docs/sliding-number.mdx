## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SlidingNumber } from "@gpuixui/components/sliding-number";

<SlidingNumber value={deploys} role="display" label={`${deploys} deploys`} />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `number` | — |
| `decimals` | `number` | `0` |
| `prefix` | `string` | — |
| `suffix` | `string` | — |
| `label` | `string` | the reading |
| `level` | `MotionLevel` | `"normal"` |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<{ value, text, reducedMotion }>` | — |

## Limitations

- A column is as wide as its widest digit.
- A carry rolls back through its column.
- No grouping or currency formatting.
- Not a live region; `aria-live` is absent.
