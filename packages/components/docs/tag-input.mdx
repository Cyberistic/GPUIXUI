## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { TagInput, TagInputChip, TagInputField } from "@gpuixui/components";

const [tags, setTags] = useState<ReadonlyArray<string>>(["design"]);

<TagInput label="Tags" value={tags} onValueChange={setTags} max={5}>
  {tags.map((tag) => (
    <TagInputChip key={tag} value={tag} />
  ))}
  <TagInputField placeholder="Add a tag…" />
</TagInput>;
```

## Composition

```text
TagInput
├── TagInputChip
└── TagInputField
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `TagInput` | `div` with `role="group"` | `value` (required), `onValueChange` (required), `label` (required), `max?`, `allowDuplicates?`, `disabled?`, children |
| `TagInputField` | `<input>` | input props minus `value`/`onChange`/`onSubmit`, `style?` |
| `TagInputChip` | chip `div` with a removal `role="button"` | `value` (required), `style?` |

## Limitations

- Controlled only.
- No Backspace-on-empty removal.
- No autocomplete, suggestions or validation.
- Commas are always separators.
