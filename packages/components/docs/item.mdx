## Usage

```tsx
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemGroup,
  ItemMedia,
  ItemTitle,
} from "@gpuixui/components/item";

export const Files = () => (
  <ItemGroup>
    <Item variant="outline">
      <ItemMedia variant="icon">▤</ItemMedia>
      <ItemContent>
        <ItemTitle>design-system.md</ItemTitle>
        <ItemDescription>Tokens and semantic roles.</ItemDescription>
      </ItemContent>
      <ItemActions>
        <Button size="sm">Open</Button>
      </ItemActions>
    </Item>
  </ItemGroup>
);
```

## Composition

```text
ItemGroup
└── Item
    ├── ItemHeader      (own line, above)
    ├── ItemMedia       (before the content)
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions     (after the content)
    └── ItemFooter      (own line, below)
```

## Limitations

- The row is a layout primitive: it paints no hover, focus or press state. Wrap
  it in a `ListItem` or a `Button` when the whole row acts.
- `line-clamp-2` has no native utility, so a long description clips its
  overflow rather than ending in an ellipsis after two lines.
- No `ItemSeparator`: put a `Separator` between rows when the surfaces are all
  `default`.
