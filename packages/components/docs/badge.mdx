---
title: Badge
description: A short status label on a pill.
---

## Usage

```tsx
import { Badge } from "@gpuixui/components/badge";

<Badge variant="success" size="sm">
  Passed
</Badge>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"neutral" \| "primary" \| "success" \| "warning" \| "danger" \| "info" \| "outline"` | `"neutral"` |
| `size` | `"sm" \| "md"` | `"md"` |
| `children` | `ReactNode` | — |

## Limitations

- Not a control: never clickable, focusable or a button.
- Out of the pointer; a press on a status badge selects its row.
- No dismiss, icon slot or count animation.
- A caller's `style` can hand the pointer back.

## Related

- **Alert** — the same status palette, for a message in the flow.
- **Card** — a surface a badge usually sits on.
- **List** — rows whose status column is made of badges.
