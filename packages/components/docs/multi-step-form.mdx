## Usage

```tsx
import { MultiStepForm } from "@gpuixui/components";
import * as Option from "effect/Option";

<MultiStepForm
  label="Create a workspace"
  steps={[
    {
      id: "name",
      title: "Name",
      content: <WorkspaceNameField value={name} onChange={setName} />,
      gate: () =>
        namePattern.test(name)
          ? Option.none()
          : Option.some("Use 3 to 24 lowercase letters, digits or hyphens"),
    },
    {
      id: "port",
      title: "Port",
      content: <PortField value={port} onChange={setPort} />,
      gate: () =>
        portUsable(port) ? Option.none() : Option.some("Enter a port from 1024 to 65535"),
    },
    {
      id: "review",
      title: "Review",
      content: <Review draft={{ name, port }} />,
      gate: () =>
        accepted ? Option.none() : Option.some("Accept the checklist first"),
    },
  ]}
  onSubmit={create}
/>;
```

## Steps

Each entry of `steps` is a `MultiStep`:

| Field | Type | Default | Notes |
| ----- | ---- | ------- | ----- |
| `id` | `string` | required | The step's stable key, shared with its indicator row. |
| `title` | `string` | required | The step's name in the indicator and in the content's announcement; a blank title reads as its position (`Step 2`). |
| `description` | `string` | — | One line of supporting copy in the indicator; a blank line paints nothing. |
| `content` | `ReactNode` | required | Mounted only while the step is current. |
| `gate` | `() => Option.Option<string>` | — | Runs before the step moves and before the last step submits; the message it returns keeps the reader put, and a message that says nothing paints the shipped sentence instead of an empty alert. |

| Prop | Type | Default |

## Names

`label` names the wizard group; a blank name is an **absence**, so the root is not published with an empty name. The indicator is always named (`Steps` when the wizard is not), a step whose `title` arrived blank is named by its position (`Step 2`) so no list item is unnamed and no announcement opens with a comma, and a title is published trimmed. That rule is the **stepper's** (`stepName` in `stepper/logic.ts`), so a `StepperStep` written directly and the wizard's content announcement cannot disagree about it. A blank `description` paints no line — an empty string lays out a zero-height run, but a run of spaces would lay out a full line. The three action labels are copy too: a blank `nextLabel`, `backLabel` or `submitLabel` reads as its documented default, because a missing i18n row must not paint a blank box as the wizard's only way forward.

A gate's message is copy on the same rule. `Some("")` still **refuses** the move, so a table with a missing row cannot release a step its author gated, but the painted alert reads `This step is not complete yet.` rather than nothing — an invisible refusal leaves the reader pressing a button that does nothing.

## Limitations

- **The draft is the caller's**: the component stores the step index and a
  refusal per step `id`, so a caller that reorders `steps` never paints one
  step's message under another.
- **No free navigation**: `Back` and the gates are the only moves.
- A step gate is not the record decode; decode the whole draft in `Form`.
