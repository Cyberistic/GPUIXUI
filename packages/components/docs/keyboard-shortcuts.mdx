title: Keyboard shortcuts

---

## Usage

```tsx
import {
  KeyboardShortcut,
  KeyboardShortcuts,
  KeyboardShortcutsGroup,
} from "@gpuixui/components";

<KeyboardShortcuts label="Editor shortcuts">
  <KeyboardShortcutsGroup label="File">
    <KeyboardShortcut label="New file" accelerator="mod+n" />
    <KeyboardShortcut label="Save" accelerator="mod+s" />
  </KeyboardShortcutsGroup>
</KeyboardShortcuts>;
```

## Composition

```text
KeyboardShortcuts
└── KeyboardShortcutsGroup
    └── KeyboardShortcut
        └── Keycap
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `KeyboardShortcuts` | `div` with `role="list"` | `label?` |
| `KeyboardShortcutsGroup` | `div` with `role="group"` | `label` (required) |
| `KeyboardShortcut` | `div` with `role="listitem"` | `label` (required), `accelerator` (required), `platform?`, `style?` |
| `Keycap` | one key cap | `children: string`, `style?` |

## Limitations

- Display-only; no handler is registered.
- No `aria-keyshortcuts`.
- Rows are separated by 1px elements rather than borders (`COMPONENTS.md`).
