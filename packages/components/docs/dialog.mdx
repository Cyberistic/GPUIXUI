## Usage

```tsx
import {
  Dialog,
  DialogClose,
  DialogContent,
  DialogDescription,
  DialogFooter,
  DialogHeader,
  DialogTitle,
  DialogTrigger,
} from "@gpuixui/components/dialog";

<Dialog>
  <DialogTrigger>Delete workspace</DialogTrigger>
  <DialogContent label="Delete workspace">
    <DialogHeader>
      <DialogTitle>Delete this workspace?</DialogTitle>
      <DialogDescription>
        The workspace and its 42 files are removed for everyone.
      </DialogDescription>
    </DialogHeader>
    <DialogFooter>
      <DialogClose>Cancel</DialogClose>
      <Button variant="danger">Delete workspace</Button>
    </DialogFooter>
  </DialogContent>
</Dialog>;
```

## Composition

```text
Dialog
├── DialogTrigger
└── DialogContent
    ├── DialogHeader
    │   ├── DialogTitle
    │   └── DialogDescription
    ├── DialogFooter
    │   └── DialogClose
    └── (close control)
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Dialog` | `open` | `boolean` | — |
| `Dialog` | `defaultOpen` | `boolean` | `false` |
| `Dialog` | `onOpenChange` | `(open: boolean) => void` | — |
| `Dialog` | `dismissible` | `boolean` | `true` |
| `DialogTrigger` | `variant` | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"secondary"` |
| `DialogTrigger` | `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `DialogTrigger` | `disabled` | `boolean` | `false` |
| `DialogTrigger` | `onClick` | `(event: EventPayload) => void` | — |
| `DialogContent` | `label` | `string` (required) | — |
| `DialogContent` | `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `DialogContent` | `showClose` | `boolean` | `true` |
| `DialogContent` | `initialFocus` | `() => number \| null` | — |
| `DialogContent` | `className` | `string` | — |
| `DialogHeader` | `className` | `string` | — |
| `DialogTitle` | `className` | `string` | — |
| `DialogDescription` | `className` | `string` | — |
| `DialogFooter` | `className` | `string` | — |
| `DialogClose` | `variant` | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"secondary"` |
| `DialogClose` | `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `DialogClose` | `disabled` | `boolean` | `false` |
| `DialogClose` | `onClick` | `(event: EventPayload) => void` | — |

`DialogTrigger` and `DialogClose` are ordinary actions: they take the button's
variant, size, disabled state and press handler, announce the surface's open
state through `aria-expanded`, and run the caller's `onClick` before opening or
closing. `DialogHeader` leaves the room the floating close control needs, and
`DialogTitle` is a level-2 heading while `DialogDescription` is a paragraph.

## Limitations

- No `aria-modal` or `aria-labelledby`; the name is `label`.
- The veil is an anchored layer at window coordinates, not a portal.
- Not resizable, draggable or multi-window.
- Focus enters on open and returns to the opener on close.
