---
title: Shine button
description: An action that a soft sheen crosses while the pointer is over it.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { ShineButton } from "@gpuixui/components/shine-button";

<ShineButton variant="primary" onClick={deploy}>
  Deploy
</ShineButton>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `variant` | `"primary" \| "secondary" \| "ghost" \| "danger"` | `"secondary"` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` |
| `disabled` | `boolean` | `false` |
| `level` | `MotionLevel` | `"notice"` |
| `sheenColor` | `string` | the label colour |
| `onMouseEnter` | `(event) => void` | — |
| `onLayout` | `(event) => void` | — |
| `style` | `StyleDesc` | — |

## Limitations

- Inset travel, not a scaled layer.
- Two stops, two halves; the runtime's gradient accepts two.
- One sweep per entry.
- Reduced motion and keyboard readers get none.
