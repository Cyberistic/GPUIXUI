## Usage

```tsx
import { useState } from "react";
import { CopyButton } from "@gpuixui/components";

const [mirror, setMirror] = useState("");

<CopyButton text={token} onCopy={setMirror} />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `onCopy` | `(text: string) => void` | — |
| `label` | `string` | `"Copy"` |
| `copiedLabel` | `string` | `"Copied"` |
| `acknowledgeMs` | `number` | `1200` |
| `size` | `"sm" \| "md" \| "lg"` | `"sm"` |
| `disabled` | `boolean` | `false` |
| `color` | `string` | `mutedForeground` |
| `level` | `SurfaceLevel` | `"fast"` |
| `className` | `string` | — |
| `style` | `StateStyle<CopyButtonState>` | — |

## Limitations

- `level` is read through `surfaceLevelOf`, so a saved `"none"` paints at rest; the table's own `motionLevelOf` would animate it.
- No clipboard write; the control calls `onCopy` and acknowledges the press.
- The confirmation is the button's name; no live region exists.
- The glyph fades and rises; it does not scale.
- A stored `label` or `copiedLabel` that is not text is no name: `nameOf` reads it at the boundary, so the action is named `Copy` and `Copied` rather than throwing on `Str.trim`.
