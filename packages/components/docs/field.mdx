## Usage

```tsx
import { Field, FieldInput } from "@gpuixui/components/field";

<Field
  label="Workspace URL"
  description="Lowercase words joined by hyphens."
  error={error}
  required
>
  <FieldInput value={slug} onChange={(event) => setSlug(event.value ?? "")} />
</Field>;
```

## Composition

```text
Field
├── FieldLabel
├── FieldDescription
├── FieldError
└── FieldInput
```

## Examples

### Validation

```tsx
import { validate } from "@gpuixui/components/validation/logic";

const Slug = Schema.NonEmptyString.check(
  Schema.isPattern(/^[a-z0-9]+(-[a-z0-9]+)*$/, {
    identifier: "WorkspaceSlugPattern",
    message: "Use lowercase letters, numbers and single hyphens",
  }),
);

const message = Effect.runSync(validate(Slug)(value));
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Field` | `label` | `string` (required) | — |
| `Field` | `description` | `string` | — |
| `Field` | `error` | `string` | — |
| `Field` | `required` | `boolean` | `false` |
| `FieldLabel` | `required` | `boolean` | `false` |
| `FieldDescription` | `children` | `ReactNode` | — |
| `FieldError` | `children` | `ReactNode` | — |
| `FieldInput` | `invalid` | `boolean` | the field's state |
| `FieldInput` | `disabled` | `boolean` | `false` |
| `FieldInput` | `style` | `StateStyle<FieldInputState>` | recipe |

## Limitations

- The error replaces the description rather than stacking under it.
- A `Tab` traversal focuses the input without running its `onFocus`.
- No `aria-describedby`, `aria-invalid` or `aria-required`.
- Not a form library; no value, submit or cross-field rules.

## Related

- **Alert** — a page-level message rather than a field message.
- **Toast** — feedback after a submit.
