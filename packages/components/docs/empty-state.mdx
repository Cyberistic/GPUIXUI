---
title: EmptyState
description: The "nothing here yet" panel for an empty collection.
---

## Usage

```tsx
import { EmptyState } from "@gpuixui/components/empty-state";

<EmptyState
  title="No projects yet"
  description="A project holds your files, runs and settings."
  action={<Button variant="primary">New project</Button>}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `title` | `string` (required) | — |
| `description` | `string` | — |
| `action` | `ReactNode` | — |
| `icon` | `ReactNode` | — |

## Limitations

- A panel, not a surface: no background or border of its own.
- The description's wrap width is a constant, 360px.
- No illustration slot; any `icon` paints muted.

## Related

- **Card** — the surface an empty state usually sits in.
- **List** — the collection that is empty.
- **Alert** — a message about a state that is not empty.
