## Usage

```tsx
import { GradientText } from "@gpuixui/components/gradient-text";

<GradientText text="Native by default" />;

// Own the colours.
<GradientText text="Fast by design" from="#7C5CFF" to="#24C6A8" role="h2" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` (required) | — |
| `from` | `string` | theme `foreground` |
| `to` | `string` | theme `primary` |
| `role` | `TextRole` | `"display"` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<GradientTextState>` | — |

## Limitations

- **A stored phrase that is not text paints no glyphs**: `textOf` reads `text` at the boundary, so a `null` a saved record kept no longer throws out of the render.
- No text fill; the blend is discrete at glyph resolution.
- No moving ramp; the glyphs would recolour every frame.
- Hex ends only; a non-hex end paints the run flat.
