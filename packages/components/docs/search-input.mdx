## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SearchInput } from "@gpuixui/components/search-input";

<SearchInput
  placeholder="Filter files…"
  onValueChange={setQuery}
  onSubmit={runSearch}
  onClear={() => setQuery("")}
/>;
```

## Limitations

- No debounce; debouncing is the consumer's.
- No history, suggestions or shortcut binding.
- A `Tab` traversal focuses the input **without running its `onFocus`**; the ring is declared at rest.
