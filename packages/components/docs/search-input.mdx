## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SearchInput } from "@gpuixui/components/search-input";

<SearchInput
  placeholder="Filter files…"
  onValueChange={setQuery}
  onSubmit={runSearch}
  onClear={() => setQuery("")}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` / `defaultValue` | `string` | — / `""` |
| `onValueChange` | `(value: string) => void` | — |
| `onSubmit` | `(value: string) => void` | — |
| `onClear` | `() => void` | — |
| `placeholder` | `string` | `"Search…"` |
| `disabled` | `boolean` | `false` |
| `style` | `StateStyle<SearchInputState>` | recipe |

## Limitations

- No debounce; debouncing is the consumer's.
- No history, suggestions or shortcut binding.
- `focused` misses a `Tab` traversal — focus without running its `onFocus`.
