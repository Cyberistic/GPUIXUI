## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MessageScroller,
  MessageScrollerItem,
  MessageScrollerJumpToLatest,
  MessageScrollerViewport,
} from "@gpuixui/components";

<MessageScroller label="Conversation">
  <MessageScrollerViewport style={{ height: 320 }}>
    {messages.map((message) => (
      <MessageScrollerItem key={message.id}>
        <text>{message.body}</text>
      </MessageScrollerItem>
    ))}
  </MessageScrollerViewport>
  <MessageScrollerJumpToLatest />
</MessageScroller>;
```

## Composition

```text
MessageScroller
├── MessageScrollerViewport
│   └── MessageScrollerItem
└── MessageScrollerJumpToLatest
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MessageScroller` | `role="group"` named by `label` | `label` (required), `threshold?`, `pinned?`, `defaultPinned?`, `onPinnedChange?`, children |
| `MessageScrollerViewport` | the scroll container and its tail sentinel | `style`, `onScroll?`, `ref?`, children |
| `MessageScrollerItem` | one row, no surface | `style`, children |
| `MessageScrollerJumpToLatest` | a secondary button; nothing while pinned | `label?`, `style` |

## When a measurement is unreadable

`threshold` defaults to the theme's `spacing["2xl"]`, and callers often compute
their own from a measured inset. A threshold that never arrived (`NaN`), or a
scroll distance the bounds arithmetic could not produce, is not an observation:
the scroller keeps the pin and unread state it had, so a reader resting at the
bottom keeps following new rows instead of being read as scrolled up. An
arrival count it cannot read is not an arrival either, so the affordance never
paints `NaN` where a number of messages belongs.

## Limitations

- Not virtualized; every row renders.
- The affordance sits beneath the viewport.
- No resize observer.
- No `aria-live`; new rows are not announced.
