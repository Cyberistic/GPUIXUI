---
title: Message Scroller
description: Follow new content at the end; never yank a reader who scrolled up.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MessageScroller,
  MessageScrollerItem,
  MessageScrollerJumpToLatest,
  MessageScrollerViewport,
} from "@gpuixui/components";

<MessageScroller label="Conversation">
  <MessageScrollerViewport style={{ height: 320 }}>
    {messages.map((message) => (
      <MessageScrollerItem key={message.id}>
        <text>{message.body}</text>
      </MessageScrollerItem>
    ))}
  </MessageScrollerViewport>
  <MessageScrollerJumpToLatest />
</MessageScroller>;
```

## Composition

```text
MessageScroller
├── MessageScrollerViewport
│   └── MessageScrollerItem
└── MessageScrollerJumpToLatest
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MessageScroller` | `role="group"` named by `label` | `label` (required), `threshold?`, `pinned?`, `defaultPinned?`, `onPinnedChange?`, children |
| `MessageScrollerViewport` | the scroll container and its tail sentinel | `style`, `onScroll?`, `ref?`, children |
| `MessageScrollerItem` | one row, no surface | `style`, children |
| `MessageScrollerJumpToLatest` | a secondary button; nothing while pinned | `label?`, `style` |

## Limitations

- Not virtualized; every row renders.
- The affordance sits beneath the viewport.
- No resize observer.
- No `aria-live`; new rows are not announced.
