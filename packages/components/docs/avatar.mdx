---
title: Avatar
description: A person or entity, as a picture with an initials fallback.
---

`Avatar` identifies a person, team or service. Given `src` it shows the picture;
without one it shows deterministic initials derived from `name`, so nothing about
the layout depends on the name and a person without a photo is never blank. When
`src` is set the picture is what paints — the runtime reports no image-load
failure, so a missing file leaves the disc empty (see **Limitations**).

## Usage

```tsx
import { Avatar } from "@gpuixui/components/avatar";

<Avatar name="Ada Lovelace" src="/photos/ada.png" size="md" status="online" />;

// No picture: the initials are derived from the name.
<Avatar name="Jean-Luc Picard" />;
```

## Initials

The fallback is a pure function (`src/avatar/logic.ts`) with these rules:

| Name | Initials | Rule |
| ---- | -------- | ---- |
| `Ada Lovelace` | `AL` | first letter of the first and last part |
| `Jean-Luc Picard` | `JP` | whitespace and `-` both separate parts |
| `J. Robert Oppenheimer` | `JO` | the **last** part, not the second |
| `ada` | `A` | one part, one letter |
| `李 小龙` | `李小` | code points, not code units |
| `🎨 Artist` | `🎨A` | an astral character stays whole |
| `  ` | `?` | no letter → a visible placeholder, never blank |

## Sizes

| `size` | Diameter | Initials type |
| ------ | -------- | ------------- |
| `xs` | 20px | 8px |
| `sm` | 26px | 10px |
| `md` (default) | 32px | 13px |
| `lg` | 40px | 16px |

The initials size is 40% of the diameter, so the letter keeps its proportion at
every size.

## Presence

`status` renders a 10px dot on the rim, filled from a semantic role:

| `status` | Fill |
| -------- | ---- |
| `online` | `success` |
| `away` | `warning` |
| `busy` | `destructive` |
| `offline` | `mutedForeground` |

The dot sits on the avatar's outer box — which is deliberately **not** clipped —
while an inner disc clips the picture into a circle. A clipped root would cut the
dot in half.

## API

`Avatar` takes the GPUix host props (`style`, `testId`, `role`, `aria-*`, pointer
and key handlers) and **merges `style` last**, so a consumer can override any rule
without forking the component.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `name` | `string` (required) | — |
| `src` | `string` | — |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` |
| `status` | `"online" \| "away" \| "busy" \| "offline"` | — |

## Accessibility

- The root is a single `role="img"` node whose accessible name is `name`, so the
  picture and the fallback are announced identically — a screen reader never
  reads "AL" as a word.
- The image also carries `alt={name}`.
- A `status` is described through `aria-description` — the one description
  0.10.0 supports — so the dot is announced while the name stays the person's.
  The caller's own `aria-description` wins. The example still prints the status
  as visible text.
- An avatar is not interactive and takes no tab stop.

## Theming

The disc uses `colors.muted`, the initials `colors.foreground`, the dot the four
status roles, and the dot's rim `colors.card` (the surface it sits on) at
`borderWidth.strong`. No literal colours. See `docs/tokens.md`.

## Limitations

- **No image loading or error state.** If `src` points at a missing file, the
  runtime paints nothing inside the disc until the image arrives; the initials are
  not restored, because the runtime reports no image-load failure to React. Pass
  the picture only when you can rely on it, or omit `src` and use initials.
- The four diameters are component constants, not tokens: `@gpuixui/tokens` ships
  no avatar scale (`TODO.md` → Interlocks).
- The docs site cannot render this component live — it is a GPUix host tree, not
  DOM. The code above is the real source.

## Verification

`src/behaviour/avatar.test.tsx` runs in the real GPUix renderer (9 tests) plus
`src/avatar/logic.test.ts` (8 tests) for the initials rules. The suite covers the
initials and picture paths, the accessible name, a status as its description
(authored descriptions winning), dot colours, sizes and the caller's style.

```sh
nub run --filter @gpuixui/components test:behaviour
nub run --filter @gpuixui/components test
```
