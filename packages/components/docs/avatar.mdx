---
title: Avatar
description: A person or entity, as a picture with an initials fallback.
---

`Avatar` identifies a person, team or service. Given `src` it shows the picture;
without one — or before the picture paints — it shows deterministic initials, so
the layout never shifts and a missing image never leaves a blank hole.

## Usage

```tsx
import { Avatar } from "@gpuixui/components/avatar";

<Avatar name="Ada Lovelace" src="/photos/ada.png" size="md" status="online" />;

// No picture: the initials are derived from the name.
<Avatar name="Jean-Luc Picard" />;
```

## Initials

The fallback is a pure function (`src/avatar/logic.ts`) with these rules:

| Name | Initials | Rule |
| ---- | -------- | ---- |
| `Ada Lovelace` | `AL` | first letter of the first and last part |
| `Jean-Luc Picard` | `JP` | whitespace and `-` both separate parts |
| `J. Robert Oppenheimer` | `JO` | the **last** part, not the second |
| `ada` | `A` | one part, one letter |
| `李 小龙` | `李小` | code points, not code units |
| `🎨 Artist` | `🎨A` | an astral character stays whole |
| `  ` | `?` | no letter → a visible placeholder, never blank |

## Sizes

| `size` | Diameter | Initials type |
| ------ | -------- | ------------- |
| `xs` | 20px | 8px |
| `sm` | 26px | 10px |
| `md` (default) | 32px | 13px |
| `lg` | 40px | 16px |

The four diameters are the token scale `avatarSize`, read through the package's
theme seam. It is a fixed scale rather than a `Theme` group, because a diameter
is content-sized like an image: a brand restyles the colours around it, not the
person chip's size. The initials size is 40% of the diameter, so the letter keeps
its proportion at every size.

## Presence

`status` renders a 10px dot on the rim, filled from a semantic role:

| `status` | Fill |
| -------- | ---- |
| `online` | `success` |
| `away` | the `warning` tone's foreground (`statusTone(theme, "warning").foreground`) |
| `busy` | `destructive` |
| `offline` | `mutedForeground` |

A dot is a **mark**, not text, so every one of those is a role the token contract
measures at the mark floor (`indicatorRoles`). `warning`'s solid fill is designed
to carry near-black text and measures 1.89:1 as a dot on the light card, so
`away` paints the tone's readable role instead.

The dot sits on the avatar's outer box — which is deliberately **not** clipped —
while an inner disc clips the picture into a circle. A clipped root would cut the
dot in half.

A dot is colour-only information, so `status` is also the avatar's announced
description: a reader hears `Ada Lovelace, image, busy`. Pass your own
`aria-description` to say something else — it replaces the presence text, because
GPUix 0.11.0 has one description field per node and no `aria-describedby`.

For a sighted reader the four states differ only by colour, so print the state as
text beside the avatar where that difference matters — the members row in the
example does.

## API

`Avatar` takes the GPUix host props (`style`, `testId`, `role`, `aria-*`, pointer
and key handlers) and **merges `style` last**, so a consumer can override any rule
without forking the component.

| Prop | Type | Default |
| ---- | ---- | ------- |
| `name` | `string` (required) | — |
| `src` | `string` | — |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` |
| `status` | `"online" \| "away" \| "busy" \| "offline"` | — |

## Accessibility

- The root is the avatar's **one** accessible node: a `role="img"` named `name`.
  The initials and the picture are presentational, so a reader never hears "AL"
  as a word beside the name and a picture does not publish a second image node.
  `src/behaviour/avatar.test.tsx` measures both halves in the renderer.
- The presence dot is published as the avatar's description (see Presence), so
  a status is never conveyed by colour alone.
- An avatar is not interactive and takes no tab stop.

## Theming

The disc uses `colors.muted`, the initials `colors.foreground`, the dot the
measured mark roles (`success`, `destructive`, `mutedForeground` and the `warning`
tone's foreground), and the dot's rim `colors.card` (the surface it sits on) at
`borderWidth.strong`. No literal colours. See `docs/tokens.md` §Indicator marks.

## Limitations

- **No image loading or error state.** If `src` points at a missing file, the
  runtime paints nothing inside the disc until the image arrives; the initials are
  not restored, because the runtime reports no image-load failure to React. Pass
  the picture only when you can rely on it, or omit `src` and use initials.
- The docs site cannot render this component live — it is a GPUix host tree, not
  DOM. The code above is the real source.
