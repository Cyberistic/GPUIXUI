---
title: Avatar
description: A person or entity, as a picture with an initials fallback.
---

## Usage

```tsx
import { Avatar } from "@gpuixui/components/avatar";

<Avatar name="Ada Lovelace" src="/photos/ada.png" size="md" status="online" />;

// No picture: initials are derived from the name.
<Avatar name="Jean-Luc Picard" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `name` | `string` (required) | — |
| `src` | `string` | — |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` |
| `status` | `"online" \| "away" \| "busy" \| "offline"` | — |

## Limitations

- No image loading or error state; a missing `src` shows nothing.
- The presence dot is colour-only; print the state beside it when it matters.

## Related

- **Badge** — a role or status label beside an avatar.
- **Card** — the members panel an avatar usually sits in.
