title: Avatar
description: A person or entity, as a picture with an initials fallback
---

<ComponentPreview name="avatar-states" />

## Usage

```tsx
import { Avatar } from "@gpuixui/components/avatar";

<Avatar name="Ada Lovelace" src="/photos/ada.png" size="md" status="online" />;

// No picture: initials are derived from the name.
<Avatar name="Jean-Luc Picard" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `name` | `string` (required) | — |
| `src` | `string` | — |
| `size` | `"xs" \| "sm" \| "md" \| "lg"` | `"md"` |
| `status` | `"online" \| "away" \| "busy" \| "offline"` | — |
| `color` | `string` — the disc's fill, in place of the muted role | — |
| `radius` | `number` — a rounded square in place of the circle | — |
| `initials` | `boolean` — `false` paints a plain colour dot; the name stays the accessible label | `true` |
| `clickThrough` | `boolean` | on, unless the avatar has its own press handler |
| `className` | `string` | — |
