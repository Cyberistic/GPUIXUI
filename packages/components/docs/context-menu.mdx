## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuTrigger,
} from "@gpuixui/components/context-menu";

<ContextMenu>
  <ContextMenuTrigger>
    <text>GPUIXUI</text>
  </ContextMenuTrigger>
  <ContextMenuContent label="Project actions">
    <ContextMenuItem onSelect={open}>Open</ContextMenuItem>
    <ContextMenuItem onSelect={copyPath}>Copy path</ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuItem tone="destructive" onSelect={remove}>
      Delete…
    </ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>;
```

## Composition

```text
ContextMenu
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    ├── ContextMenuCheckboxItem
    ├── ContextMenuRadioGroup
    │   └── ContextMenuRadioItem
    ├── ContextMenuSeparator
    ├── ContextMenuLabel
    ├── ContextMenuGroup
    └── ContextMenuSub
        ├── ContextMenuSubTrigger
        └── ContextMenuSubContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `ContextMenu` | root context | `open?`, `defaultOpen?` (default `false`), `onOpenChange?` |
| `ContextMenuTrigger` | the area whose right click opens the menu | `disabled?` |
| `ContextMenuContent` | `anchored` surface at the pointer | `label?` (default `"Context menu"`) |
| `ContextMenuItem` / `ContextMenuCheckboxItem` | the shared rows | `onSelect?`, `disabled?`, `tone?`, `leading?`, `trailing?`, `textValue?`, `closeOnSelect?` |
| `ContextMenuRadioGroup` / `ContextMenuRadioItem` | the shared exclusive choice: one marked row, and a choice closes the menu | `value` / `onValueChange` / `label?` on the group; `value` (required) on the row |
| `ContextMenuSeparator` / `ContextMenuLabel` / `ContextMenuGroup` | the shared structure | `ContextMenuGroup` takes `label?` — the group's accessible name |
| `ContextMenuSub` / `ContextMenuSubTrigger` / `ContextMenuSubContent` | one secondary level | `ContextMenuSubContent` takes the root surface's placement props |

## Choice rows

The rows are the dropdown menu's, so an exclusive choice works the same way:
`ContextMenuRadioGroup` owns the value, one `ContextMenuRadioItem` per choice
is marked, and choosing a row closes the menu. A `ContextMenuCheckboxItem` is
the on/off row that stays open. Both mark their state with a check and
`aria-selected` because 0.11.0 has no `aria-checked`.

Pass the choice's `label` to the group (`label="Group by"`): 0.11.0 has no
`aria-labelledby`, so a painted `ContextMenuLabel` does not name the group a
reader enters.

## Limitations

- No `onContextMenu`; a right click arrives as `onAuxClick`.
- The surface is not portalled; it is painted at window coordinates.
- One level of submenus is tested.
- A pointer-opened menu dismisses with focus `none`.
