title: Context menu

## Usage

```tsx
import {
  ContextMenu,
  ContextMenuContent,
  ContextMenuItem,
  ContextMenuSeparator,
  ContextMenuTrigger,
} from "@gpuixui/components/context-menu";

<ContextMenu>
  <ContextMenuTrigger>
    <text>GPUIXUI</text>
  </ContextMenuTrigger>
  <ContextMenuContent label="Project actions">
    <ContextMenuItem onSelect={open}>Open</ContextMenuItem>
    <ContextMenuItem onSelect={copyPath}>Copy path</ContextMenuItem>
    <ContextMenuSeparator />
    <ContextMenuItem tone="destructive" onSelect={remove}>
      Delete…
    </ContextMenuItem>
  </ContextMenuContent>
</ContextMenu>;
```

## Composition

```text
ContextMenu
├── ContextMenuTrigger
└── ContextMenuContent
    ├── ContextMenuItem
    ├── ContextMenuCheckboxItem
    ├── ContextMenuRadioGroup
    │   └── ContextMenuRadioItem
    ├── ContextMenuSeparator
    ├── ContextMenuLabel
    ├── ContextMenuGroup
    └── ContextMenuSub
        ├── ContextMenuSubTrigger
        └── ContextMenuSubContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `ContextMenu` | root context | `open?`, `defaultOpen?` (default `false`), `onOpenChange?`, `children` |
| `ContextMenuTrigger` | the area whose right click opens the menu | `disabled?` |
| `ContextMenuContent` | `anchored` surface at the pointer | `label?` (default `"Context menu"`), `className?`, `children` |
| `ContextMenuItem` / `ContextMenuCheckboxItem` | the shared rows | `onSelect?`, `disabled?`, `tone?` (default `"default"`; a stored name that is neither tone reads as `"default"`), `leading?`, `trailing?`, `textValue?`, `closeOnSelect?` |
| `ContextMenuRadioGroup` / `ContextMenuRadioItem` | the shared exclusive choice: one marked row, and a choice closes the menu | `value` / `onValueChange` / `label?` on the group; `value` (required) on the row |
| `ContextMenuSeparator` / `ContextMenuLabel` / `ContextMenuGroup` | the shared structure | `ContextMenuGroup` takes `label?` — the group's accessible name |
| `ContextMenuSub` / `ContextMenuSubTrigger` / `ContextMenuSubContent` | one secondary level | `ContextMenuSubContent` takes the root surface's placement props |

## Limitations

- No `onContextMenu`; a right click arrives as `onAuxClick`.
- The surface is not portalled; it is painted at window coordinates.
- One level of submenus is tested.
- **A stored `tone` the union does not carry paints `"default"`**: a menu built
  from a saved action list may hold another vocabulary's word for the same idea
  (`"danger"`) or the `null` a store writes for a field it never set, and the
  emphasis is decoration — the action still runs — where a name outside the two
  would otherwise take the whole menu down.
