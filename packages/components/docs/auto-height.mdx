## Usage

```tsx
import { AutoHeight } from "@gpuixui/components/auto-height";

<AutoHeight open={open}>
  <text>Retry budget: 5 attempts</text>
  <text>Timeout: 30 seconds</text>
</AutoHeight>;
```

The caller owns `open`; the reveal owns the measurement and the tween. While it
collapses the box takes no presses: the seam's `PresenceShield` covers the
content it keeps mounted for the exit, because `pointerEvents` does not inherit
and the box's own rule cannot reach the controls inside it — so the press that
closed the section is not run by a control the reader can no longer see.

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `open` | `boolean` (required) | — |
| `level` | `MotionLevel` | `"normal"` |
| `className` | `string` | — |
| `contentClassName` | `string` | — |
| `style` | `StateStyle<AutoHeightState>` | — |

## Limitations

- The first open paints at zero for one frame.
- A measurement belongs to the content on screen: a reveal reopened after its
  body changed grows to the new height, not the one it closed with.
- A closed reveal unmounts its subtree after the collapse.
- Vertical axis only; no width animation.
