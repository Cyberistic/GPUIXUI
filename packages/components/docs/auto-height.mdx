## Usage

```tsx
import { AutoHeight } from "@gpuixui/components/auto-height";

<AutoHeight open={open}>
  <text>Retry budget: 5 attempts</text>
  <text>Timeout: 30 seconds</text>
</AutoHeight>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `open` | `boolean` (required) | — |
| `level` | `MotionLevel` | `"normal"` |
| `className` | `string` | — |
| `contentClassName` | `string` | — |
| `style` | `StateStyle<AutoHeightState>` | — |

## Limitations

- The first open paints at zero for one frame.
- A measurement belongs to the content on screen: a reveal reopened after its body changed grows to the new height, not the one it closed with.
- A closed reveal unmounts its subtree after the collapse.
