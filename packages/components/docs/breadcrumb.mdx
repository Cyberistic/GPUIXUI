---
title: Breadcrumb
description: The trail to the current page, with an optional collapsed middle.
---

`Breadcrumb` shows where the current page sits in a hierarchy. The trail is
declarative — `BreadcrumbItem`, `BreadcrumbLink`, `BreadcrumbPage` — and
`maxItems` collapses the middle while always keeping the first entry and the
current page.

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@gpuixui/components/breadcrumb";

<Breadcrumb maxItems={3}>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink onSelect={() => go("Projects")}>Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator>›</BreadcrumbSeparator>
    <BreadcrumbItem>
      <BreadcrumbLink onSelect={() => go("GPUIXUI")}>GPUIXUI</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator>›</BreadcrumbSeparator>
    <BreadcrumbItem>
      <BreadcrumbPage>components</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

## Anatomy

| Part | Responsibility |
| ---- | -------------- |
| `Breadcrumb` | `role="navigation"`, the `maxItems` budget and an optional separator |
| `BreadcrumbList` | `role="list"` and the collapse |
| `BreadcrumbItem` | one `role="listitem"` |
| `BreadcrumbLink` | a link (`role="link"`) with Enter/Space and `onSelect` |
| `BreadcrumbPage` | the current page: plain text, no tab stop |
| `BreadcrumbSeparator` | the glyph between entries (`children`, default `/`); not focusable |

## Collapse rule

`maxItems` below 3 is clamped to 3, so the trail can always show its start, a gap
and its end. When the trail fits, every entry renders. Otherwise the control
keeps the first entry, an ellipsis, and the last `maxItems - 2` entries. A hidden
entry takes its separator with it — the list pairs each separator with the item
that follows it — and the ellipsis keeps the separator authored before the first
hidden entry, so a composed trail never falls back to `/` in the middle.

`BreadcrumbList` reads its **direct** children to do this, which is why the parts
are plain elements rather than wrappers: a custom component around an item is
counted as one entry.

## Keyboard

Tab reaches each link in order. `Enter` fires `onSelect` on press; `Space` fires
it on release, so moving focus before letting go cancels the navigation. The
current page and the ellipsis are not focusable.

`autoFocus` sets the initial `focused` state, so the link's ring is painted on
the first commit — the runtime applies native focus after React's effects and
never dispatches `onFocus`.

## API

Every part takes the GPUix host props and **merges `style` last**.

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Breadcrumb` | `div` (`role="navigation"`) | `maxItems?: number` (clamped to at least 3), `separator?: ReactNode` (default `/`), `currentLabel?: string` (default `"Current page"`) |
| `BreadcrumbList` | `div` (`role="list"`) | — |
| `BreadcrumbItem` | `div` (`role="listitem"`) | — |
| `BreadcrumbLink` | `div` (`role="link"`), or `text` when `current` | `onSelect?: () => void`, `current?: boolean` |
| `BreadcrumbPage` | `text` | — |
| `BreadcrumbSeparator` | `text` (`role="presentation"`) | `children?: ReactNode` (default `/`) |

## Theming

Links and separators use the `caption` type role; links are
`colors.mutedForeground` and hover to `colors.foreground`; the current page is
`colors.foreground`. The root has no surface of its own.

## Accessibility and limitations

- `role="navigation"` with `aria-label="Breadcrumb"`, `role="list"`, and
  `role="listitem"` on the entries.
- A link names itself from its plain-text child, because 0.10.0 reports no name
  from contents; a composed link passes `aria-label`.
- **No `aria-current`** in `@gpuix/native@0.10.0`. The item holding the current
  page (`BreadcrumbPage`, or `BreadcrumbLink current`) is described by
  `currentLabel` (default `"Current page"`) through the supported
  `aria-description` on its `role="listitem"`; an authored description wins. The
  page itself stays plain text, so its name is unchanged.
- The collapsing ellipsis is a text node with `aria-label="More"`; it is not a
  button and not in the tab order.
- Separators are `role="presentation"`.

## Verification

`src/behaviour/breadcrumb.test.tsx` runs in the real GPUix renderer (12 tests):
the trail and its separator count, an authored separator glyph, selecting a link
but not the current page, Enter on press and Space on release, collapsing the
middle while keeping both ends and the authored separator, the ellipsis staying
out of the tab order, and the current item's description (`BreadcrumbPage` and
`BreadcrumbLink current`, with a caller label and description).

`src/breadcrumb/logic.test.ts` covers the collapse arithmetic for lengths 0–8 and
budgets 3–6.

```sh
nub run --filter @gpuixui/components test:behaviour
```
