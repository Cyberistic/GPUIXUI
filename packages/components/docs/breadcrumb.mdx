## Usage

```tsx
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
  BreadcrumbSeparator,
} from "@gpuixui/components/breadcrumb";

<Breadcrumb maxItems={3}>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink onSelect={() => go("Projects")}>Projects</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbSeparator />
    <BreadcrumbItem>
      <BreadcrumbPage>components</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>;
```

## Composition

```text
Breadcrumb
└── BreadcrumbList
    └── BreadcrumbItem
        ├── BreadcrumbLink
        ├── BreadcrumbPage
        └── BreadcrumbSeparator
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Breadcrumb` | `div role="navigation"` | `maxItems?` (clamps below 3), `separator?` (default `/`), `className?`, `children` |
| `BreadcrumbList` | `div role="list"` | `className?`, `children` (the trail's items, direct) |
| `BreadcrumbItem` | `div role="listitem"` | `className?`, `children` |
| `BreadcrumbLink` | `div role="link"` | `onSelect?`, `current?`, `className?` |
| `BreadcrumbPage` | `text` | the current page, not focusable; `className?` |
| `BreadcrumbSeparator` | `text role="presentation"` | `className?` |

## Limitations

- No `aria-current`; the current page carries `aria-selected`.
- The collapsing ellipsis is text, not a button.
- Separators are `role="presentation"`.
