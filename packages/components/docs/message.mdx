---
title: Message
description: One row of a conversation, with reasoning, tool calls, citations and wiring-free actions.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MessageActions,
  MessageAvatar,
  MessageContent,
  MessageRoot,
} from "@gpuixui/components";

<MessageRoot variant={message.role}>
  <MessageAvatar />
  <MessageContent
    reasoning={message.reasoning}
    toolCalls={message.tools}
    sources={message.sources}
    streaming={message.streaming}
  >
    <text>{message.body}</text>
    <MessageActions onCopy={copy} onRetry={retry} />
  </MessageContent>
</MessageRoot>;
```

## Composition

```text
MessageRoot
├── MessageAvatar
└── MessageContent
    └── MessageActions
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MessageRoot` | `role="group"` named by `label` or the variant | `variant?`, `label?`, `className?`, children |
| `MessageAvatar` | the shipped `Avatar` at `sm` | `name?`, `src?`, `className?` |
| `MessageContent` | the slot column and the variant's body box | `reasoning?`, `toolCalls?`, `sources?`, `streaming?`, `streamingLabel?`, `reasoningLabel?`, `sourcesLabel?`, `className?`, `style?` |
| `MessageActions` | a `role="group"` action row, or `null` | `onCopy?`, `onRetry?`, `onFeedback?`, `copyLabel?`, `retryLabel?`, `helpfulLabel?`, `notHelpfulLabel?`, `className?` |

## Limitations

- Reasoning grows through a measured height.
- No clipboard write; `onCopy` is the consumer's path.
- A citation is a row, not a link.
- The body is one run.
