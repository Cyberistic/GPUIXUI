## Usage

```tsx
import { Fireworks } from "@gpuixui/components/fireworks";

<div style={{ position: "relative", height: 260, overflow: "hidden" }}>
  <div style={{ position: "absolute", top: 0, right: 0, bottom: 0, left: 0 }}>
    <Fireworks bursts={3} sparks={20} seed={5} />
  </div>
  <EmptyState title="Release published" />
</div>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `bursts` | `number` | `3` |
| `sparks` | `number` | `18` |
| `seed` | `number` | `1` |
| `minSize` | `number` | `2` |
| `maxSize` | `number` | `4` |
| `color` | `string` | theme `primary` |
| `burstMs` | `number` | `1_400` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<FireworksState>` | — |

## Limitations

- A dot, not a streak; sparks travel without arcing.
- The box must be bounded by the caller.
- A hidden field keeps animating; unmount it when off screen.
- No accessibility node; the content owns the words.
