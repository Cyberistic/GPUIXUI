## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@gpuixui/components";

<Drawer>
  <DrawerTrigger>Filters</DrawerTrigger>
  <DrawerContent side="right" size="md" label="Filters">
    <DrawerHeader>
      <DrawerTitle>Filters</DrawerTitle>
      <DrawerDescription>Narrow the result set.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>;
```

## Composition

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerFooter
    │   └── DrawerClose
    └── (close control)
```

The close control is painted in the box around the surface's own scroller, not
inside it, so a body longer than the drawer scrolls under the control instead of
carrying the one visible way out of the panel (`src/behaviour/drawer.test.tsx`
scrolls a 30-row body and holds the control's box).

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Drawer` | nothing; owns open state | `open?`, `defaultOpen?`, `onOpenChange?`, `dismissible?`, `children` |
| `DrawerTrigger` | button | button props |
| `DrawerClose` | button | button props |
| `DrawerContent` | veil + `role="dialog"` surface | `side?`, `size?`, `label` (required), `showClose?`, `initialFocus?`, `className?`, `children` |
| `DrawerHeader` | heading block | `className?`, `children` |
| `DrawerTitle` | level-2 heading | text props, `className?` |
| `DrawerDescription` | muted copy | text props, `className?` |
| `DrawerFooter` | right-aligned actions | `children`, `className?` |

## Limitations

- **Measured in a window**: the playground's `drawer-lifecycle` (34 checks,
  0.11.0) mounts the shipped Drawer and reads the surface flush to the edge it
  names — `500,0,400,520` for a right `md` column, `340,0,560,520` for a right
  `lg`, `0,0,400,520` for a left `md`, and `0,100,900,420` for a bottom `lg` —
  over a veil that measurably dims the page it leaves uncovered. A press is
  hit-tested: one inside the surface keeps the drawer open, while the veil's
  dismisses it, reports the close and returns the focus to the opener. The Tab
  trap is the window's own traversal, so the opener is never a stop while the
  drawer is open, and `dismissible={false}` removes Escape and the veil while
  the close control still works.
- Slides 12px from its edge and fills the window's other axis; a full-width
  column is not available.
- No swipe-to-dismiss; no drag host feature.
- The entry is a fade and a 12px travel from the named edge, not a slide across
  the window: the runtime has no `transform`, and animating `width`/`left`
  would reflow the content.
- No `aria-modal` or `aria-labelledby` in 0.11.0: the surface is named by its own
  `label`, and the Tab traversal is the containment a reader gets.
- Not portalled; painted at window coordinates.
- Sizes are layout constants, not tokens.
- A `side` restored from persisted state that the union does not name opens the
  house `right` edge, and travels in from it; the box, the layout and the entry
  frame read one edge, so a panel never opens from an edge it is not on.
- A `size` restored from persisted state that the union does not name paints the
  house `md` box; the table lookup never hands the renderer an `undefined`, so a
  renamed or dropped size cannot shrink the panel to its content.
