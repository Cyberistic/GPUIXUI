## Usage

```tsx
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@gpuixui/components";

<Drawer>
  <DrawerTrigger>Filters</DrawerTrigger>
  <DrawerContent side="right" size="md" label="Filters">
    <DrawerHeader>
      <DrawerTitle>Filters</DrawerTitle>
      <DrawerDescription>Narrow the result set.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <DrawerClose>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>;
```

## Composition

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    ├── DrawerFooter
    │   └── DrawerClose
    └── (close control)
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Drawer` | nothing; owns open state | `open?`, `defaultOpen?`, `onOpenChange?`, `dismissible?` |
| `DrawerTrigger` | button | button props |
| `DrawerClose` | button | button props |
| `DrawerContent` | veil + `role="dialog"` surface | `side?`, `size?`, `label` (required), `showClose?`, `initialFocus?` |
| `DrawerHeader` | heading block | children |
| `DrawerTitle` | level-2 heading | text props |
| `DrawerDescription` | muted copy | text props |
| `DrawerFooter` | right-aligned actions | children |

## Limitations

- Slides 12px from its edge; a full-width slide is not available.
- No swipe-to-dismiss; no drag host feature.
- Not portalled; painted at window coordinates.
- Sizes are layout constants, not tokens.
