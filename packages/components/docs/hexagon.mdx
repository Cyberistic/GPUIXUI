## Usage

```tsx
import { Hexagon } from "@gpuixui/components/hexagon";

<Hexagon
  radius={34}
  stroke={1}
  style={{ width: 520, height: 260 }}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `radius` | `number` | `30` |
| `stroke` | `number` | `1` |
| `color` | `string` | theme `border` |
| `breatheMs` | `number` | `8_000` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<HexagonState>` | — |

## Limitations

- One ink; a multi-colour grid is several `<svg>` elements.
- No transform; the breath is the only motion.
- Generated for its box; a resize re-generates the grid.
