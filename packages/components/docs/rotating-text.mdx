## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { RotatingText } from "@gpuixui/components/rotating-text";

<RotatingText
  phrases={["Faster builds", "Safer releases", "One runtime"]}
  intervalMs={3000}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `phrases` | `ReadonlyArray<string>` | — |
| `intervalMs` | `number` | `3000` |
| `index` | `number` | — |
| `defaultIndex` | `number` | `0` |
| `onIndexChange` | `(index: number) => void` | — |
| `label` | `string` | the phrase on screen |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<RotatingTextState>` | — |

## Limitations

- The phrase changes by remounting the host.
- No width animation.
- No `aria-live`; a screen reader is not pushed a phrase.
- The phrase list is read at the boundary: a stored list that is absent reads as no phrases (the frame still paints), and an entry that is not text is dropped rather than painted as a blank frame. A blank `label` reads as the phrase on screen.
- A stored `label` that is not text is no name: `nameOf` reads it at the boundary, so the announcement is the phrase on screen.
