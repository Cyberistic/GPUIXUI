## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { RotatingText } from "@gpuixui/components/rotating-text";

<RotatingText
  phrases={["Faster builds", "Safer releases", "One runtime"]}
  intervalMs={3000}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `phrases` | `ReadonlyArray<string>` | — |
| `intervalMs` | `number` | `3000` |
| `index` | `number` | — |
| `defaultIndex` | `number` | `0` |
| `onIndexChange` | `(index: number) => void` | — |
| `label` | `string` | the phrase on screen |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<RotatingTextState>` | — |

## Limitations

- The phrase changes by remounting the host.
- No width animation.
- No `aria-live`; a screen reader is not pushed a phrase.
- Linear order only; no shuffle or pause.
