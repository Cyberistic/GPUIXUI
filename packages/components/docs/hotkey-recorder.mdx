## Usage

```tsx
import { HotkeyRecorder } from "@gpuixui/components";

<HotkeyRecorder
  label="Toggle command palette"
  value={hotkey}
  onChange={setHotkey}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` | — |
| `value` | `string \| null` | `null` |
| `onChange` | `(value: string \| null) => void` | — |
| `placeholder` | `string` | `"Click to record"` |
| `disabled` | `boolean` | `false` |
| `style` | `StateStyle<HotkeyRecorderState>` | — |

## Limitations

- A recorded key is swallowed; the app's own binding does not fire.
- Clearing is a control, not `Backspace`.
- No conflict detection against already-bound chords.
