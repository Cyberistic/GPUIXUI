## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  TimePicker,
  TimePickerClear,
  TimePickerSegment,
  TimePickerSeparator,
} from "@gpuixui/components/time-picker";

const [standup, setStandup] = useState<string | null>("09:30");

<TimePicker value={standup} onValueChange={setStandup} minuteStep={15}>
  <TimePickerSegment segment="hours" />
  <TimePickerSeparator />
  <TimePickerSegment segment="minutes" />
  <TimePickerClear />
</TimePicker>;
```

## Composition

```text
TimePicker
├── TimePickerSegment
├── TimePickerSeparator
└── TimePickerClear
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `TimePicker` | `value` / `defaultValue` | `string \| null` — `HH:mm`, 24-hour | — / `null` |
| `TimePicker` | `onValueChange` | `(value: string \| null) => void` | — |
| `TimePicker` | `label` | `string` | `"Time"` |
| `TimePicker` | `minuteStep` | `number` | `1` |
| `TimePicker` | `clearable` | `boolean` | `false` |
| `TimePicker` | `disabled` | `boolean` | `false` |
| `TimePickerSegment` | `segment` | `"hours" \| "minutes"` (required) | — |
| `TimePickerSegment` | `style` | `StateStyle<TimePickerSegmentState>` | recipe |
| `TimePickerSeparator` | `children` | `ReactNode` | `:` |
| `TimePickerClear` | `label` | `string` | `"Clear time"` |

## Limitations

- No `aria-valuenow` / spinbutton role.
- Fixed 24-hour display; no AM/PM or locale.
- `minuteStep` is arrow keys only.
- A `Tab` traversal focuses the field **without running its `onFocus`**, because the
  automation window the probe runs in never becomes active and so delivers no
  focus pair (`blur-delivery-lifecycle`); the ring declared at rest is the cue.
