## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MentionInput,
  MentionInputItem,
  MentionInputList,
} from "@gpuixui/components";

<MentionInput
  label="Comment"
  value={comment}
  onValueChange={setComment}
  onMention={(name) => notify(name)}
>
  <MentionInputList>
    {people.map((person) => (
      <MentionInputItem key={person} value={person} />
    ))}
  </MentionInputList>
</MentionInput>;
```

## Composition

```text
MentionInput
├── MentionInputList
│   └── MentionInputItem
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MentionInput` | a `role="group"` field wrapping an `<input>` | `label` (required), `value?`, `defaultValue?`, `onValueChange?`, `onMention?`, `maxVisible?`, `disabled?`, children |
| `MentionInputList` | anchored suggestion surface, labelled "Mentions" | children |
| `MentionInputItem` | a selected button row | `value` (required), `label?`, `style?` |

## Limitations

- The query comes from the text, not the caret.
- A space typed while open is consumed by the runtime.
- `maxVisible` is a row budget: a value that cannot be read (`NaN`, from a height
  measured before the first layout) falls back to the house budget of 6 rather
  than hiding every row; an unbounded budget shows every candidate.
- No async or remote candidates.
- No `role="listbox"` in the accessibility dump.
