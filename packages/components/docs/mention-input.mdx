## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MentionInput,
  MentionInputItem,
  MentionInputList,
} from "@gpuixui/components";

<MentionInput
  label="Comment"
  value={comment}
  onValueChange={setComment}
  onMention={(name) => notify(name)}
>
  <MentionInputList>
    {people.map((person) => (
      <MentionInputItem key={person} value={person} />
    ))}
  </MentionInputList>
</MentionInput>;
```

## Composition

```text
MentionInput
├── MentionInputList
│   └── MentionInputItem
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MentionInput` | a `role="group"` field wrapping an `<input>` | `label` (required), `value?`, `defaultValue?`, `onValueChange?`, `onMention?`, `maxVisible?`, `disabled?`, `className?`, `children`, `placeholder?`, `readOnly?`, `autoFocus?`, `invalid?`, `size?`, `fullWidth?`, `tabIndex?`, `testId?`, `onClick?`, `onKeyDown?`, `onKeyUp?`, `onFocus?`, `onBlur?`, `ref?`, `aria-id?`, `onLayout?`, `description?` |
| `MentionInputList` | anchored suggestion surface, labelled "Mentions" | `className?`, `children` |
| `MentionInputItem` | a selected button row | `value` (required), `label?`, `style?`, `className?` |

## Limitations

- The query comes from the text, not the caret.
- A space typed while open is consumed by the runtime.
- `maxVisible` is a row budget; an unreadable value falls back to 6, and an unbounded budget shows every candidate.
