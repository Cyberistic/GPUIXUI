## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  MentionInput,
  MentionInputItem,
  MentionInputList,
} from "@gpuixui/components";

<MentionInput
  label="Comment"
  value={comment}
  onValueChange={setComment}
  onMention={(name) => notify(name)}
>
  <MentionInputList>
    {people.map((person) => (
      <MentionInputItem key={person} value={person} />
    ))}
  </MentionInputList>
</MentionInput>;
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `MentionInput` | a `role="group"` field wrapping an `<input>` | `label` (required), `value?`, `defaultValue?`, `onValueChange?`, `onMention?`, `maxVisible?`, `disabled?`, `className?`, `children`, `placeholder?`, `readOnly?`, `autoFocus?`, `invalid?`, `size?`, `fullWidth?`, `tabIndex?`, `testId?`, `onClick?`, `onKeyDown?`, `onKeyUp?`, `onFocus?`, `onBlur?`, `ref?`, `aria-id?`, `onLayout?`, `description?` |
| `MentionInputList` | anchored suggestion surface, labelled "Mentions" | `className?`, `children` |
| `MentionInputItem` | a selected button row | `value` (required), `label?`, `style?`, `className?` |

## Motion

The suggestion list enters and leaves on the house `normal` level: a fade plus 4px
of travel out from the field's bottom edge. Closing the query — `Escape` or a
selection — keeps the box painted for its exit window, carrying the rows the
reader dismissed rather than re-ranking an empty query mid-fade, and the seam's
leaving guard stops a ghost row taking the press while the row drops its own tab
stop with the box. A list that only narrows to nothing is cut instead: the field
is still open and a ghost of rows the query no longer matches would misreport the
search. A field the caller disables cuts its list too, because the control
refuses every route and there is no gesture to finish.
`MotionProvider preference="reduced"` removes the journey: the box is gone in the
frame it closes.

## Limitations

- The query comes from the text, not the caret.
- A space typed while open is consumed by the runtime.
- `maxVisible` is a row budget; an unreadable value falls back to 6, and an unbounded budget shows every candidate.
