## Usage

```tsx
import { ColorPicker } from "@gpuixui/components";

<ColorPicker
  label="Accent colour"
  value={accent}
  onValueChange={setAccent}
  swatches={["#ef4444", "#f59e0b", "#22c55e", "#3b82f6"]}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `label` | `string` | — |
| `value` | `string` | — |
| `defaultValue` | `string` | `"#000000"` |
| `onValueChange` | `(value: string) => void` | — |
| `swatches` | `ReadonlyArray<string>` | six theme colours |
| `disabled` | `boolean` | `false` |
| `style` | `StateStyle<ColorPickerState>` | — |

## Limitations

- No saturation/value square; two-stop gradients only.
- No alpha, HSL/RGB fields or eyedropper.
- HEX only; named colours are not parsed.
- Validation runs on commit, not on each keystroke.
- A `disabled` picker refuses both commit paths (Enter and blur) as well as its
  swatches, because a read-only host still receives keys — a draft typed before
  the field was disabled is never written to the caller's value. Its swatches
  and HEX field also leave the tab order, because a read-only host still takes
  focus.
