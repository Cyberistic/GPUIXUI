title: Stepper
description: A read-only indicator of progress through named steps.
---

<ComponentPreview name="stepper-states" />

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Stepper, StepperStep } from "@gpuixui/components";

<Stepper value={2} label="Checkout">
  <StepperStep value={1} label="Account" description="Email and password" />
  <StepperStep value={2} label="Billing" description="Card and address" />
  <StepperStep value={3} label="Review" />
</Stepper>;
```

## Composition

```text
Stepper
└── StepperStep
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Stepper` | `div` with `role="list"` | `value` (required), `orientation?`, `label?`, children |
| `StepperStep` | `div` with `role="listitem"` | `value` (required), `label` (required), `description?`, `style?` |

## Limitations

- Display-only: no step click, disabled policy or `onValueChange`.
- No connector line between steps.
- No `aria-current`; the current step uses `aria-selected`.
