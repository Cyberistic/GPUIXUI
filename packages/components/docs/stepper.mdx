---
title: Stepper
description: A read-only indicator of progress through named steps
---

<ComponentPreview name="stepper-states" />

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Stepper, StepperStep } from "@gpuixui/components";

<Stepper value={2} label="Checkout">
  <StepperStep value={1} label="Account" description="Email and password" />
  <StepperStep value={2} label="Billing" description="Card and address" />
  <StepperStep value={3} label="Review" />
</Stepper>;
```

## Composition

```text
Stepper
└── StepperStep
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Stepper` | `div` with `role="list"` | `value` (required), `orientation?` (default `"horizontal"`; a stored name that is neither axis reads as `"horizontal"`), `label?` (a blank one publishes no name), `className?`, `children` |
| `StepperStep` | `div` with `role="listitem"` | `value` (required), `label` (required; a blank one reads as the step's position, `Step 2`), `description?` (a blank one paints no line), `style?`, `className?` |
