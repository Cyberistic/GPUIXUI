---
title: Motion grid
description: A grid whose cells travel to their new slots when the order changes.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { MotionGrid } from "@gpuixui/components/motion-grid";

<MotionGrid
  items={tools.map((tool) => ({ id: tool.id, content: <ToolCard tool={tool} /> }))}
  columns={3}
  cellWidth={160}
  rowHeight={120}
  gap={12}
  label="Tool board"
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `items` | `ReadonlyArray<MotionGridItem>` | — |
| `columns` | `number` | `3` |
| `cellWidth` | `number` | `160` |
| `rowHeight` | `number` | `120` |
| `gap` | `number` | `12` |
| `level` | `MotionLevel` | `"normal"` |
| `label` | `string` | — |
| `className` | `string` | — |
| `style` | `StateStyle<MotionGridState>` | — |

## Limitations

- No cell sizes its row; the caller names both.
- Inset movement, no `transform`.
- A fixed number of columns.
- The wrapper paints nothing.
