## Usage

```tsx
import {
  Combobox,
  ComboboxContent,
  ComboboxEmpty,
  ComboboxInput,
  ComboboxList,
  ComboboxTrigger,
} from "@gpuixui/components/combobox";

<Combobox
  options={[
    { value: "ada", label: "Ada Lovelace", description: "Engineering" },
    { value: "grace", label: "Grace Hopper", description: "Compilers" },
  ]}
  onValueChange={setReviewer}
>
  <ComboboxTrigger label="Assign reviewer" />
  <ComboboxContent>
    <ComboboxInput label="Search reviewers" />
    <ComboboxList label="Reviewers" />
    <ComboboxEmpty />
  </ComboboxContent>
</Combobox>;
```

## Composition

```text
Combobox
├── ComboboxTrigger
└── ComboboxContent
    ├── ComboboxInput
    ├── ComboboxList
    │   └── ComboboxItem
    └── ComboboxEmpty
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Combobox` | `options` | `ReadonlyArray<ComboboxOption>` (required) | — |
| `Combobox` | `value` / `defaultValue` | `string \| ReadonlyArray<string>` | — |
| `Combobox` | `onValueChange` | `(value) => void` | — |
| `Combobox` | `multiple` | `boolean` | `false` |
| `Combobox` | `disabled` | `boolean` | `false` |
| `Combobox` | `onCreate` | `(query: string) => void` | — |
| `Combobox` | `createLabel` | `(query: string) => string` | `Create "…"` |
| `ComboboxTrigger` | `placeholder` / `label` | `string` | `"Select…"` / — |
| `ComboboxContent` | `side` / `align` | `"top" \| "right" \| "bottom" \| "left"` · `"start" \| "center" \| "end"` | `"bottom"` / `"start"` |
| `ComboboxContent` | `sideOffset` / `alignOffset` | `number` | `4` / `0` |
| `ComboboxInput` | `placeholder` / `label` | `string` | `"Search…"` / `"Search options"` |
| `ComboboxList` | `label` | `string` | `"Options"` |
| `ComboboxList` | `itemStyle` | `StateStyle<ComboboxItemState>` | recipe |
| `ComboboxItem` | `value` | `string` (required) | — |
| `ComboboxEmpty` | `children` | `ReactNode` | `No matches` |

## Limitations

- No async option loading or group headers.
- Create-new is single-select and offered only when nothing matches.
- No `aria-activedescendant`; `aria-selected` is the signal.
- The popup has an entry tween only.

## Related
