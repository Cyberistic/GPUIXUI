## Usage

```tsx
import { Gradient } from "@gpuixui/components/gradient";

<Gradient
  from="#7C5CFF"
  to="#101014"
  angle={120}
  shift={80}
  style={{ padding: 32 }}
>
  <text>Ship faster with panels</text>
</Gradient>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `from` | `string` | theme `primary` |
| `to` | `string` | `from` at zero alpha |
| `angle` | `number` | `135` |
| `shift` | `number` | `90` |
| `durationMs` | `number` | `6_000` |
| `radius` | `number` | `0` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<GradientState>` | — |
| `children` | `ReactNode` | — |

## Limitations

- Two stops is the whole grammar; no multi-stop ramps.
- No rotate or scale; the second ramp is redrawn at another angle.
- The layers are rectangles; pass `radius` for a rounded field.
- The field owns no semantics; the content must carry them.
