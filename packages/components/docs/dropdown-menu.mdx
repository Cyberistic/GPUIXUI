## Usage

```tsx
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@gpuixui/components/dropdown-menu";

<DropdownMenu>
  <DropdownMenuTrigger>Actions</DropdownMenuTrigger>
  <DropdownMenuContent label="File actions">
    <DropdownMenuItem onSelect={rename}>Rename</DropdownMenuItem>
    <DropdownMenuItem disabled>Duplicate</DropdownMenuItem>
    <DropdownMenuSeparator />
    <DropdownMenuItem tone="destructive" onSelect={remove}>
      Delete
    </DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>;
```

## Composition

```text
DropdownMenu
├── DropdownMenuTrigger
└── DropdownMenuContent
    ├── DropdownMenuItem
    ├── DropdownMenuCheckboxItem
    ├── DropdownMenuRadioGroup
    │   └── DropdownMenuRadioItem
    ├── DropdownMenuSeparator
    ├── DropdownMenuLabel
    ├── DropdownMenuGroup
    └── DropdownMenuSub
        ├── DropdownMenuSubTrigger
        └── DropdownMenuSubContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `DropdownMenu` | root context | `open?`, `defaultOpen?` (default `false`), `onOpenChange?` |
| `DropdownMenuTrigger` | button with `aria-expanded` | `disabled?`, button `variant`/`size`/`label` |
| `DropdownMenuContent` | floating `role="menu"` surface | `label?`, `side?` (default `"bottom"`), `align?` (default `"start"`), `sideOffset?` (default `4`), `alignOffset?` (default `0`), `collisionPadding?` (default `8`) |
| `DropdownMenuItem` | one action row | `onSelect?`, `disabled?`, `tone?`, `leading?`, `trailing?`, `textValue?`, `closeOnSelect?` (default `true`) |
| `DropdownMenuCheckboxItem` | an on/off row that stays open | `checked` (required), `onCheckedChange` (required) |
| `DropdownMenuRadioGroup` | the exclusive choice its rows belong to, named by `label` | `value` (required), `onValueChange` (required), `label?`, `className?` |
| `DropdownMenuRadioItem` | one choice; choosing it closes the menu | `value` (required), `disabled?`, `leading?`, `trailing?`, `textValue?` |
| `DropdownMenuSub` / `DropdownMenuSubTrigger` / `DropdownMenuSubContent` | one secondary level | `DropdownMenuSubContent` takes the root surface's placement props |
| `DropdownMenuSeparator` / `DropdownMenuLabel` / `DropdownMenuGroup` | the structure between rows | `DropdownMenuGroup` takes `label?` — the group's accessible name; a visible `DropdownMenuLabel` is painted text and does not name it |

## Limitations

- No `aria-haspopup`, `aria-controls`, `aria-checked` or `aria-activedescendant`.
- One level of submenus is tested.
- A hover does not preview a highlight; the pointer activates on click.
