## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { ScrollFade } from "@gpuixui/components/scroll-fade";

<ScrollFade color={theme.colors.card} style={{ height: 240 }}>
  {notes.map((note) => (
    <Note key={note.id} note={note} />
  ))}
</ScrollFade>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `color` | `string` | theme `background` |
| `edgeSize` | `number` | `32` |
| `className` | `string` | — |
| `style` | `StyleDesc` | — |

## Limitations

- No keyboard scrolling; use `ScrollArea`.
- Vertical only.
- No animation; the strips toggle with the offset.
- The strips paint over the content.
