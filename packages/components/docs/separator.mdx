## Usage

```tsx
import { Separator } from "@gpuixui/components/separator";

<Separator />;
<Separator orientation="vertical" />;
<Separator decorative />;
```

A semantic rule is a `separator` node a reader can find between two regions;
`decorative` keeps a rule in the drawing and out of the accessibility tree. The
default is semantic, because a divider that separates content is content.

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `decorative` | `boolean` | `false` |
| `inset` | `"2xs" \| "xs" \| "sm" \| "md" \| "lg" \| "xl" \| "2xl" \| "3xl" \| "4xl" \| "5xl"` | — |
| `label` | `string` | — |
| `style` | `StyleDesc` | — |
| `className` | `string` | — |
| `testId` | `string` | — |
| `aria-id` | `string` | — |
