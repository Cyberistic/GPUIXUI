---
title: Sliding text
description: A value that slides horizontally into place when it changes.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { SlidingText } from "@gpuixui/components/sliding-text";

<div style={{ width: 220 }}>
  <SlidingText text={status} role="bodyStrong" />
</div>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `text` | `string` | — |
| `direction` | `"forward" \| "back"` | `"forward"` |
| `level` | `MotionLevel` | `"normal"` |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<SlidingTextState>` | — |

## Limitations

- The box decides the travel; width is measured after paint.
- One line only; a wide value is clipped.
- The outgoing value fades out of the clip.
- No per-character slide.
