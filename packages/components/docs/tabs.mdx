## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@gpuixui/components/tabs";

<Tabs defaultValue="profile">
  <TabsList label="Account">
    <TabsTrigger value="profile">Profile</TabsTrigger>
    <TabsTrigger value="notifications">Notifications</TabsTrigger>
  </TabsList>
  <TabsContent value="profile">…</TabsContent>
  <TabsContent value="notifications">…</TabsContent>
</Tabs>;
```

## Composition

```text
Tabs
├── TabsList
│   └── TabsTrigger
└── TabsContent
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Tabs` | `value` / `defaultValue` | `string` | — / `""` |
| `Tabs` | `onValueChange` | `(value: string) => void` | — |
| `Tabs` | `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `Tabs` | `activation` | `"automatic" \| "manual"` | `"automatic"` |
| `Tabs` | `className` | `string` | — |
| `Tabs` | `children` | `PartChildren` | — |
| `TabsList` | `label` | `string` | — |
| `TabsList` | `className` | `string` | — |
| `TabsList` | `children` | `PartChildren` | — |
| `TabsTrigger` | `value` | `string` (required) | — |
| `TabsTrigger` | `disabled` | `boolean` | `false` |
| `TabsTrigger` | `style` | `StateStyle<TabsTriggerState>` | recipe |
| `TabsTrigger` | `className` | `string` | — |
| `TabsContent` | `value` | `string` (required) | — |
| `TabsContent` | `className` | `string` | — |

## Limitations

- No `aria-orientation`, `aria-controls` or `aria-labelledby`.
- `focused` misses a `Tab` traversal: the trigger gains focus **without running its `onFocus`**.
- The selected surface is measured, not styled per trigger.
