## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  Tabs,
  TabsContent,
  TabsList,
  TabsTrigger,
} from "@gpuixui/components/tabs";

<Tabs defaultValue="profile">
  <TabsList label="Account">
    <TabsTrigger value="profile">Profile</TabsTrigger>
    <TabsTrigger value="notifications">Notifications</TabsTrigger>
  </TabsList>
  <TabsContent value="profile">…</TabsContent>
  <TabsContent value="notifications">…</TabsContent>
</Tabs>;
```

## Composition

```text
Tabs
├── TabsList
│   └── TabsTrigger
└── TabsContent
```

| `Tabs` | `value` / `defaultValue` | `string` | — / `""` |

| `Tabs` | `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

## Limitations

- No `aria-orientation`, `aria-controls` or `aria-labelledby`.
- `focused` misses a `Tab` traversal: the traversal focuses the trigger
  **without running its `onFocus`**, because the automation window the probe
  runs in never becomes active and so delivers no focus pair
  (`blur-delivery-lifecycle`). The event is not a channel to depend on — the
  ring declared at rest is the cue, and an arrow move anchors on the key's own
  element rather than a `focused` flag.
- The selected surface is measured, not styled per trigger. It is re-measured
  after a reflow, because a layout event reports a **size** change rather than a
  move: a tab pushed along by a longer neighbour, or by a trigger appearing
  before it, would otherwise leave the pill at the place it used to occupy. The
  pill slides to its new box on the `normal` level; `MotionProvider
  preference="reduced"` paints it there in the frame the reflow lands.
