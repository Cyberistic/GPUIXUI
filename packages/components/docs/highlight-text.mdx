## Usage

```tsx
import { HighlightText } from "@gpuixui/components/highlight-text";

<HighlightText text="Native by default" query="native" />;
```

## Ranges

`ranges` names `[start, end)` pairs in the phrase's **UTF-16 units** and wins
over `query`. A pair is the part of it **inside the phrase**: a start below `0`
or an end past the phrase is clamped to it, a fractional index is truncated to
the unit it names, and a pair that is not two numbers or whose ends meet after
that is **no range at all**. A find bar can therefore pass the ranges its own
arithmetic produced — `indexOf` answers `-1` for no match — without sending a
negative offset to the runtime's `highlight`, which reads absolute units.

## Limitations

- The sweep is a real-time timer, not a motion-clock tween.
- `ranges` index UTF-16 units; `ranges` wins over `query`.
- The default wash is the theme's translucent `findHighlight` pair, which holds the matched text to the theme's body floor; a caller's own `color`/`activeColor` is not measured.
