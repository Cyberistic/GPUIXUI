## Usage

```tsx
import {
  Alert,
  AlertContent,
  AlertDescription,
  AlertTitle,
} from "@gpuixui/components/alert";

<Alert tone="warning">
  <AlertContent>
    <AlertTitle>3 tokens are missing</AlertTitle>
    <AlertDescription>
      The platform themes fall back to the default palette.
    </AlertDescription>
  </AlertContent>
</Alert>;
```

## Composition

```text
Alert
├── AlertIcon
├── AlertContent
│   ├── AlertTitle
│   ├── AlertDescription
│   └── AlertLink
└── AlertDismiss
```

## API

| Part | Prop | Type | Default |
| ---- | ---- | ---- | ------- |
| `Alert` | `tone` | `"info" \| "success" \| "warning" \| "danger"` | `"info"` |
| `Alert` | `className` | `string` | — |
| `AlertIcon` | `className` | `string` | — |
| `AlertContent` | `className` | `string` | — |
| `AlertTitle` | `className` | `string` | — |
| `AlertDescription` | `className` | `string` | — |
| `AlertLink` | `onSelect` | `() => void` | — |
| `AlertLink` | `className` | `string` | — |
| `AlertDismiss` | `onDismiss` | `() => void` (required) | — |
| `AlertDismiss` | `label` | `string` | `"Dismiss"` |

`AlertIcon` takes the glyph as its children and paints it in the tone's readable
role; `AlertTitle` paints the same role, and `AlertDescription` keeps the page
foreground because body copy is read on the tint rather than as the message's
own signal. `AlertContent` is presentational — it is the growing column the
title, description and link sit in.

## Limitations

- `role="alert"` is a marker, not an announcement: no `aria-live` exists.
- Put the state in the title and move the focus when it must be noticed.
- No automatic timeout; an alert stays until dismissed.
- A part outside `Alert` throws.
