## Usage

```tsx
import { Calendar } from "@gpuixui/components/calendar";
import { useState } from "react";

export const Review = () => {
  const [day, setDay] = useState<string | null>("2026-10-17");

  return <Calendar selected={day} onSelect={setDay} today="2026-10-17" />;
};
```

## Dropdown caption

A date that is not near today is reached through two dropdowns rather than
eleven presses of the previous-month arrow. `captionLayout="dropdown"` paints a
month select and a year select; `fromYear`/`toYear` narrow the years on offer,
and the default window is **1900 to a century past today** — a calendar is not
limited to the decade it is looked at in.

## Limitations

- No `aria-current`, so today is a border rather than an attribute.
- No `aria-disabled` and no live region: an unavailable day leaves the tab order,
  and a selection change is named by the focused cell, not announced.
- Fixed English labels; no week numbers and no time of day.
