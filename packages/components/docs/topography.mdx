---
title: Topography
description: A contour map generated for its own box.
---

## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { Topography } from "@gpuixui/components/topography";

<Topography
  spacing={30}
  amplitude={10}
  seed={3}
  style={{ width: 520, height: 260 }}
/>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `spacing` | `number` | `32` |
| `amplitude` | `number` | `8` |
| `stroke` | `number` | `1` |
| `seed` | `number` | `1` |
| `color` | `string` | theme `border` |
| `breatheMs` | `number` | `8_000` |
| `level` | `MotionLevel` | `"slow"` |
| `className` | `string` | — |
| `style` | `StateStyle<{ width, height, reducedMotion }>` | — |

## Limitations

- One ink; the runtime paints markup as a single tint.
- Not a terrain model — two seeded sine waves.
- No `transform`; the breath is the only motion.
- A resize re-generates the map; it owns no semantics.
