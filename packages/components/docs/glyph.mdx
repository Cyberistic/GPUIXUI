## Usage

```tsx
import { Glyph } from "@gpuixui/components/glyph";

<Glyph
  marks="+/*<>[]{}"
  cellSize={20}
  density={0.6}
  seed={5}
  style={{ width: 520, height: 220 }}
>
  <text>Open the command deck</text>
</Glyph>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `children` | `ReactNode` | — |
| `marks` | `string` | `.+*/\<>[]{}~` |
| `cellSize` | `number` | `22` |
| `density` | `number` | `0.55` |
| `seed` | `number` | `1` |
| `color` | `string` | theme `border` |
| `breatheMs` | `number` | `8_000` |
| `level` | `MotionLevel` | `"slow"` |
| `style` | `StateStyle<GlyphState>` | — |

## Limitations

- Paint, not content; the wall publishes no accessibility node.
- One `<text>` host per painted cell, so the wall is capped at **240** cells and a
  box that would need more grows its cell instead — including a strip narrower
  than one cell, which would otherwise paint a column of every row it fits.
- No drift, zoom or rotate; the breath is the only motion.
- A hidden wall keeps breathing; unmount it when off screen.
