## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@gpuixui/components/card";

<Card>
  <CardHeader>
    <CardTitle>Pro plan</CardTitle>
    <CardDescription>Everything in Starter, plus seats and invoicing.</CardDescription>
  </CardHeader>
  <CardContent>{/* rows, a form, a chart */}</CardContent>
  <CardFooter className="pb-3">{/* actions */}</CardFooter>
</Card>;
```

## Composition

```text
Card
├── CardHeader
│   ├── CardTitle
│   └── CardDescription
├── CardContent
└── CardFooter
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `Card` | `div` | `variant?: "outline" \| "elevated" \| "plain"` (default `"outline"`; a stored name that is neither reads as the default), `className?`, `children` |
| `CardHeader` | `div` | `className?`, `children` |
| `CardTitle` | `text` | `role="heading"`, `aria-level={3}`, `className?` |
| `CardDescription` | `text` | `className?` |
| `CardContent` | `div` | `className?` |
| `CardFooter` | `div` | `className?` |

## Limitations

- The footer recipe has no bottom padding; add `className="pb-3"`.
- `overflow` is hidden on the surface; put the scroller in `CardContent`.
- Not focusable and not a landmark.
- **A stored `variant` the table does not carry paints `"outline"`**: a saved card whose treatment a release renamed keeps its edge instead of painting with no boundary at all.
