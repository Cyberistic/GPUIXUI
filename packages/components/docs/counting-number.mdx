## Usage

```tsx
import { CountingNumber } from "@gpuixui/components";

<CountingNumber value={1284} from={0} role="display" />;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `value` | `number` (required) | — |
| `from` | `number` | `value` |
| `durationMs` | `number` | `320` |
| `decimals` | `number` | `0` |
| `format` | `(value: number) => string` | — |
| `label` | `string` | the target's text |
| `role` | `TextRole` | `"body"` |
| `className` | `string` | — |
| `style` | `StateStyle<CountingNumberState>` | — |

## Limitations

- Re-rendered text, not a rolling reel; no per-digit slide.
- One tween per value change; no spring or stagger.
- The clock is real time, not the renderer's motion clock.
- A stored `label` that is not text is no name: `nameOf` reads it at the boundary, so the announcement is the value the count reads.
