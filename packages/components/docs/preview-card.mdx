## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import {
  PreviewCard,
  PreviewCardContent,
  PreviewCardTrigger,
} from "@gpuixui/components";

<PreviewCard>
  <PreviewCardTrigger>design-system.md</PreviewCardTrigger>
  <PreviewCardContent label="design-system.md">
    <text>Tokens, semantic roles and the theme extension mechanism.</text>
  </PreviewCardContent>
</PreviewCard>;
```

## Composition

```text
PreviewCard
├── PreviewCardTrigger
└── PreviewCardContent
```

## API

| Part | Renders | Props |
| ---- | ------- | ----- |
| `PreviewCard` | a positioning root; owns open state and the timers | `open?`, `defaultOpen?`, `onOpenChange?`, `openDelay?`, `closeDelay?`, `children` |
| `PreviewCardTrigger` | button, `aria-expanded` | button props |
| `PreviewCardContent` | anchored `role="group"` named by `label` | `label` (required), `side?`, `align?`, `sideOffset?`, `collisionPadding?`, `className?`, `children` |

## Limitations

- Timers are the component's; pass `0` to disable them.
- Disabling a trigger while its hover open is still waiting cancels the open; the trigger has to be entered again after it is re-enabled.
- No pointer-type signal; touch is press-to-toggle.
