## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { PageTransition } from "@gpuixui/components";

<PageTransition viewKey={section}>
  {section === "account" ? <AccountView /> : <BillingView />}
</PageTransition>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `viewKey` | `string` | — |
| `children` | `ReactNode` | — |
| `direction` | `"forward" \| "back"` | `"forward"` |
| `distance` | `number` | `16` |
| `level` | `SurfaceLevel` | `"normal"` |
| `className` | `string` | — |
| `style` | `StateStyle<PageTransitionPaint>` | — |

## Limitations

- `level` is read through `surfaceLevelOf`, so a saved `"none"` paints at rest; the table's own `motionLevelOf` would animate it.
- One view at a time; the two never cross-fade.
- A clipped region; travel is a relative `left`.
- No vertical direction.
