## Installation

```bash
nub add @gpuixui/components
```

## Usage

```tsx
import { PageTransition } from "@gpuixui/components";

<PageTransition viewKey={section}>
  {section === "account" ? <AccountView /> : <BillingView />}
</PageTransition>;
```

## API

| Prop | Type | Default |
| ---- | ---- | ------- |
| `viewKey` | `string` | — |
| `children` | `ReactNode` | — |
| `direction` | `"forward" \| "back"` | `"forward"` |
| `distance` | `number` | `16` |
| `level` | `MotionLevel \| "none"` | `"normal"` |
| `className` | `string` | — |
| `style` | `StateStyle<PageTransitionPaint>` | — |

## Limitations

- One view at a time; the two never cross-fade.
- A clipped region; travel is a relative `left`.
- No vertical direction.
- The focus does not move with the swap.
- The leaving view takes no presses: it is still painted for its exit half, so a
  shield covers its content until the incoming view arrives. A press meant for
  the new page cannot re-run an action on the old one (the exit is skipped
  entirely under `level="none"` or `MotionProvider preference="reduced"`).
