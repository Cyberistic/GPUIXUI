`Meter` reports where a measurement sits in a known range. It is not `Progress`.

## Usage

```tsx
import { Meter, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="xs">
  <Text role="caption" tone="muted">Disk usage · 68 of 100 GB</Text>
  <Meter label="Disk usage" value={68} max={100} formatValue={(v) => `${v} GB`} />
</Stack>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `Meter` | role, accessible name, announced measurement |
| `MeterTrack` | the bar's background and overflow clip |
| `MeterIndicator` | the measurement's share of the track |
| `MeterLabel` | visible subject, defaulting to the root's `label` |
| `MeterValue` | the formatted measurement |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | required | the measurement; clamped into the range |
| `min` / `max` | `number` | `0` / `100` | the range the fill is a fraction of |
| `tone` | `primary \| success \| destructive \| muted` | `"primary"` | the fill's colour role |
| `size` | `"sm" \| "md"` | `"md"` | track height from `spacing.xs` / `sm` |
| `label` | `string` | none | accessible name, and `MeterLabel`'s default text |
| `formatValue` | `(value: number) => string` | `String` | the announced and displayed measurement; a blank answer keeps the number |
| `children` | `ReactNode` | the track | the parts to draw |
| `style` | `StyleDesc` | — | merged last, on the root frame |
| `className` | `string` | — | Tailwind classes, joined last on the root frame |
| `testId` | `string` | — | stable locator, on the root |

`formatValue` is interface copy, so a **blank answer is absence**: a formatter
whose lookup table has no row for this measurement returns `""`, and the meter
announces and paints the clamped number rather than an empty value. A real
answer is trimmed and used as it is.

## Limitations

- No `aria-valuenow`/`min`/`max`: the measurement is `aria-valuetext`.
- No threshold segments, tick marks or a part inside the track.
- The fill does not animate between values.
