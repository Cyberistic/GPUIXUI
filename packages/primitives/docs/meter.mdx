---
title: Meter
description: A measurement inside a range — distinct from a task's progress.
---

`Meter` reports where a measurement sits in a known range: disk used, signal
strength, a score out of 16. It is not `Progress`: a progress bar reports how
far a task has got, is always 0–100, and often has no known end. A meter has a
`min` and a `max` that mean something, and it is never a control.

## Usage

```tsx
import { Meter, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="xs">
  <Text role="caption" tone="muted">Disk usage · 68 of 100 GB</Text>
  <Meter label="Disk usage" value={68} max={100} formatValue={(v) => `${v} GB`} />
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | required | the measurement; clamped into the range |
| `min` / `max` | `number` | `0` / `100` | the range the fill is a fraction of |
| `tone` | `primary \| success \| destructive \| muted` | `"primary"` | the fill's colour role |
| `size` | `"sm" \| "md"` | `"md"` | track height from `spacing.xs` / `sm` |
| `label` | `string` | none | accessible name, trimmed; a blank label leaves the meter unnamed |
| `formatValue` | `(value: number) => string` | `String` | the announced measurement |
| `style` | `StyleDesc` | — | merged last, on the track |
| `testId` | `string` | — | stable locator |

## Keyboard

Not focusable and not interactive. A meter is status; there is no slider
behaviour and no tab stop.

## Accessibility

- Role: `meter` (AccessKit `Meter` — verified in the real renderer).
- The measurement is announced through **`aria-valuetext`**, because GPUix
  0.10.0 has no `aria-valuenow`/`min`/`max`.
- With no `aria-valuemax`, the announcement is the value alone unless
  `formatValue` says more — pair the meter with visible text when the range
  matters ("68 of 100 GB" in the example above).
- The name comes from `label`. Without one the meter is unnamed; give it the
  measurement's subject ("Disk usage").

## Theming

The paint is `Progress`'s: `colors.muted` track, the tone's role for the fill
(`colors.primary`, `colors.success`, `colors.destructive`,
`colors.mutedForeground`), height a spacing step, both ends `radius.full`. One
bar painter means `Progress` and `Meter` cannot drift apart.

## Limitations

- No `aria-valuenow`/`min`/`max` (above).
- No threshold segments, tick marks or a label inside the track.
- The fill cannot animate between values; the measurement is a percentage, so it
  repaints rather than interpolates (a `motion` target is a number, plan `329`).
