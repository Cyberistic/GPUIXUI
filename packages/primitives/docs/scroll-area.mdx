---
title: ScrollArea
description: A bounded container that scrolls on the chosen axes.
---

`ScrollArea` sets the overflow axes and nothing else. GPUix paints the
scrollbar with the platform theme, so the thumb cannot be tinted and there is no
fade mask. It is a `<div>`: the runtime has no separate scroller element.

## Usage

```tsx
import { ScrollArea, Stack, Text } from "@gpuixui/primitives";

<ScrollArea axis="vertical" style={{ height: 240 }}>
  <Stack direction="column" gap="sm">
    {rows.map((row) => (
      <Text role="body" key={row}>{row}</Text>
    ))}
  </Stack>
</ScrollArea>;
```

**Give it a bounded size.** A scroll container with no height constraint grows
with its content and never scrolls.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `axis` | `"vertical" \| "horizontal" \| "both"` | `"vertical"` | which overflow axes are `scroll` (the others are `hidden`) |
| `onScroll` | `(event: EventPayload) => void` | none | wheel/trackpad **deltas** (`deltaX`, `deltaY`, `precise`, `touchPhase`) |
| `style` | `StyleDesc` | — | merged last; put the bounded size here |
| `children` | `ReactNode` | — | content |
| `testId` | `string` | — | stable locator |

`onScroll` reports a delta, not a position: there is no `onScrollChange` and no
absolute offset in `EventPayload`. A consumer that needs a position accumulates
deltas itself and clamps at the content's ends.

## Keyboard

Not focusable by itself. The runtime scrolls with the wheel; keyboard scrolling
belongs to the focused content inside the area. The wrapper does not intercept
keys, so Space/PageDown reach whatever holds focus.

## Accessibility

No role. The content inside is what assistive technology traverses; a scroll
region with no label is not announced as a region. Keep lists short enough to
navigate, or pair the area with a heading.

## Theming

Only the axes are resolved (`scrollStyle`). The scrollbar's colour and width
belong to the platform theme; `theme.colors.scrollbar` exists but cannot reach
the 0.10.0 scrollbar.

## Limitations

- **No scrollbar tint and no scrollbar width control** in GPUix 0.10.0
  (`scrollbarColor`/`scrollbarWidth` exist only on the unreleased `main`).
- **No fade mask** at the edges.
- **No absolute scroll position.** `onScroll` carries deltas only; the runtime
  has no `onScrollChange` and no offset field.
- No virtualisation: a long list mounts every row. `packages/data-grid` owns the
  virtual-list work when it lands.
