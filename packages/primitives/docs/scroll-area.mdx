`ScrollArea` is a frame around the one scroll container the runtime has.

## Usage

```tsx
import { ScrollArea, Stack, Text } from "@gpuixui/primitives";

<ScrollArea axis="vertical" style={{ height: 240 }} padding="md" label="Rows">
  <Stack direction="column" gap="sm">
    {rows.map((row) => (
      <Text role="body" key={row}>{row}</Text>
    ))}
  </Stack>
</ScrollArea>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `ScrollArea` | the frame: padding, radius, border, bounded size |
| `ScrollAreaViewport` | the overflow axes, scroll callbacks, keyboard scrolling |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `axis` | `"vertical" \| "horizontal" \| "both"` | `"vertical"` | which overflow axes are `scroll` |
| `onScroll` | `(event: EventPayload) => void` | none | wheel/trackpad deltas |
| `onScrollChange` | `(event: EventPayload) => void` | none | the absolute offset after any move |
| `onLayout` | `(event: EventPayload) => void` | none | the scroller's painted box (`width`/`height`), reported on mount and on a size change; a composed `ScrollAreaViewport` defaults to it |
| `padding` | spacing step | none | frame padding; it does not scroll |
| `radius` | radius step | none | frame radius; the scroller is clipped by it |
| `border` | `boolean` | `false` | the frame's `border` role |
| `scrollbarColor` | `string` | `colors.scrollbar` | the viewport thumb's colour |
| `scrollbarWidth` | `number` | platform's | the viewport thumb's thickness in px |
| `focusable` | `boolean` | `true` | whether the viewport is a tab stop |
| `label` | `string` | `"Scroll region"` | names the region (`role="group"` + `aria-label`) |
| `style` | `StyleDesc` | — | merged last on the frame; put the bounded size here |
| `className` | `string` | — | Tailwind classes, joined last on the frame |
| `children` | `ReactNode` | — | viewport content, or a composed `ScrollAreaViewport` |
| `testId` | `string` | — | the frame's locator |
| `viewportTestId` | `string` | — | the implicit viewport's locator |
| `viewportRef` | `Ref<PublicInstance>` | — | the implicit viewport's element |

A composed `ScrollAreaViewport` takes every scroll prop above, each defaulting
to the area's, and adds one name of its own:

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `ref` | `Ref<PublicInstance>` | — | the scroller itself; `scrollTo` and `scrollIntoView` address this element |

`onLayout` is the **scroller's** box, not the frame's: a scroll reading — an edge
fade, a position bar, a "more below" cue — needs the viewport's own height, and
the frame is smaller wherever it has padding. It reports on mount and whenever
the size changes, so a reading re-measures a pane that opened or a window that
resized. `onScrollChange` names the offset on the same element, which is why the
two belong together: one says how tall the window is, the other where the
content sits in it.

## Limitations

- No `Scrollbar`/`Thumb`/`Corner` parts: the platform paints one native thumb.
- No fade mask at the edges.
- No smooth scrolling: a key jumps the offset.
- No virtualisation: compose `@gpuixui/data`'s `VirtualList` for a long list.
