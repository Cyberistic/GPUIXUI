---
title: Separator
description: One theme-coloured rule between regions, with an optional caption.
---

`Separator` paints a single border step: horizontal or vertical, optionally
inset, optionally carrying a centred caption. It is a visual divider, not a
sectioning element and not a resizable splitter.

## Usage

```tsx
import { Separator, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="md">
  <Text role="h3">Account</Text>
  <Separator orientation="horizontal" />
  <Text role="body">Profile and sign-in details.</Text>
</Stack>;
```

A labelled rule is still one call:

```tsx
<Separator orientation="horizontal" label="Advanced" />
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `orientation` | `"horizontal" \| "vertical"` | — (required) | which way the rule runs |
| `inset` | spacing step | none | margin at both ends, from `spacing` |
| `label` | `string` | none | a centred caption; ignored for vertical rules |
| `style` | `StyleDesc` | — | merged last, onto the **control** (for a labelled separator, the row that holds the caption and rules) |
| `testId` | `string` | — | stable locator |

The rule's thickness is `theme.borderWidth.thin` and its colour is
`theme.colors.border`. A labelled separator is composed from two rules and a
`caption`-role text, not a new visual primitive.

Because the caption and its rules are the control's internal structure, a
labelled separator's `style` styles its root: `marginTop`/`gap`/padding move the
whole thing. To recolour the rule itself, use a `Box` with a border — the rule
keeps the theme's border role (plan `364`).

## Keyboard

Not focusable. A focusable divider is a resize handle, which is a docking
component, not this one.

## Accessibility

No role. The rule is decorative: it conveys grouping visually, so a region whose
only structure is a rule must still be understandable from headings and order.
The optional label is painted as text and is therefore readable, but it is not
associated with a region.

## Theming

`ruleStyle` reads `spacing[inset]`, `borderWidth.thin` and `colors.border`. No
literal colour or thickness appears in the component.

## Limitations

- No dashed or dotted style: the runtime paints solid borders.
- No draggable splitter and no resize event.
- A vertical separator does not stretch to its parent automatically; give it a
  bounded parent or a `fullHeight` box around it.
