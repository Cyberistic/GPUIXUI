`Separator` paints a single border step: horizontal or vertical, optionally inset
or carrying a centred caption.

## Usage

```tsx
import { Separator, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="md">
  <Text role="h3">Account</Text>
  <Separator orientation="horizontal" />
  <Text role="body">Profile and sign-in details.</Text>
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `orientation` | `"horizontal" \| "vertical"` | required | which way the rule runs |
| `inset` | spacing step | none | margin at both ends, from `spacing` |
| `label` | `string` | none | a centred caption; ignored for vertical rules |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |

## Limitations

- No dashed or dotted rule: it paints a **filled** 1px box, not a border.
- `borderStyle: "dashed"` styles nothing; Compose a `Box` for a dashed divider.
- No draggable splitter and no resize event.
- A vertical rule needs a bounded parent to stretch.
