`OTPField` is a one-time-code entry: `length` single-character cells over one
string.

## Usage

```tsx
import { OTPField, Label, Stack } from "@gpuixui/primitives";
import { useState } from "react";

const [code, setCode] = useState("");

<Stack direction="column" gap="xs">
  <Label description="Six digits from your authenticator">
    Verification code
  </Label>
  <OTPField
    label="Verification code"
    value={code}
    onValueChange={setCode}
    onComplete={(complete) => verify(complete)}
  />
</Stack>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `OTPField` | the named group, the code, focus and the per-cell context |
| `OTPFieldInput` | one cell: its value, name, handlers and ring |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `length` | `number` | `6` | number of cells; a nonsense value resolves to at least one |
| `value` | `string` | — | controlled code, normalised to letters/digits |
| `defaultValue` | `string` | — | initial code when uncontrolled |
| `onValueChange` | `(value: string) => void` | — | the code after every edit that changed it |
| `onChange` | `(value: string) => void` | — | deprecated alias for `onValueChange` |
| `onComplete` | `(value: string) => void` | — | fires when an edit makes the code full |
| `onSubmit` | `(event: EventPayload) => void` | — | Enter in any cell, with the code unchanged |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | cell height and width, from the density scale |
| `disabled` | `boolean` | `false` | read-only, out of the tab order, inert |
| `invalid` | `boolean` | `false` | destructive border on every cell |
| `label` | `string` | none | group name; each cell is named `<label> digit N` |
| `description` | `string` | none | announced help, carried by every cell (`aria-description`) |
| `autoFocus` | `boolean` | `false` | focuses the first cell on mount |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StateStyle<FieldState>` | — | on the group; resolved against the live state, merged last |
| `children` | `ReactNode` | `length` cells | the cell parts to draw |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with each cell's own, on every cell |
| `ref` / `aria-id` / `onLayout` | host props | none | land on the first cell; the code belongs to the group |
| `testId` | `string` | — | the group's locator; cells are `<testId>-cell-N` |

## Limitations

- There is no `onPaste`: a pasted code arrives as one multi-character edit and
  fills it forward; a longer code truncates at six.
- Arrows do not repeat: they are handled on key up.
- The code is contiguous: clearing a middle character shifts the rest left.
- No letter casing rule; normalise in `onValueChange`.
