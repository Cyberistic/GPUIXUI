`Input` is the runtime's native `<input>` with the shared field chrome.

## Usage

```tsx
import { Input, Label, labelledBy } from "@gpuixui/primitives";

const email = "Contact email";
const help = "Where notifications are delivered.";

<Label description={help}>{email}</Label>
<Input
  {...labelledBy(email)}
  description={help}
  value={value}
  onValueChange={setValue}
  placeholder="you@example.com"
  fullWidth
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `string` | — | controlled text |
| `defaultValue` | `string` | `""` | initial text when uncontrolled |
| `onValueChange` | `(value: string) => void` | none | called after each edit that changed the value |
| `onChange` | `(value: string) => void` | none | deprecated alias for `onValueChange` |
| `onSubmit` | `(event) => void` | none | Enter; the raw runtime event |
| `placeholder` | `string` | none | empty-state text |
| `readOnly` | `boolean` | `false` | accepts focus and selection, refuses edits |
| `disabled` | `boolean` | `false` | read-only, out of the tab order, de-emphasised |
| `autoFocus` | `boolean` | `false` | takes focus on mount |
| `invalid` | `boolean` | `false` | border and focus ring take the destructive role |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | height and padding from density |
| `fullWidth` | `boolean` | `false` | `width: 100%` |
| `label` | `string` | none | accessible name; a visible `Label` does not name the field on its own |
| `description` | `string` | none | announced help after the name (`aria-description`) |
| `tabIndex` | `number` | none | the field's place in the tab order |
| `ref` / `aria-id` / `onLayout` | host props | none | the native `<input>` is the addressed element |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the field's own; yours runs first |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StateStyle<FieldState>` | — | resolved against the live state, merged last |
| `testId` | `string` | — | stable locator |

## Limitations

- No `maxLength`, filter or mask: the runtime applies a value only when it **changes**, so a refused character cannot be taken back from the box (the reports run `abcde`, `abcdef`, `abcdefg`).
- No `type`, `inputMode` or `pattern`; validate with `Schema` at the boundary.
- `disabled` is emulated: read-only, out of the tab order.
- No `aria-describedby`: help is a string the field carries as `aria-description`,
  so the visible help line and the announced one are written twice.
