`ThemeProvider` puts a `PrimitiveTheme` in context; every primitive reads it
through `useTheme()`, and a missing provider throws.

## Usage

```tsx
import { ThemeProvider, Box, Text } from "@gpuixui/primitives";
import { darkTheme } from "@gpuixui/tokens";

<ThemeProvider theme={darkTheme}>
  <Box tone="background" padding="lg">
    <Text role="h2">Settings</Text>
  </Box>
</ThemeProvider>;
```

## Words

A control's state is announced in words, because this runtime has no
`aria-checked`, `aria-pressed` or `aria-busy`. The provider carries them as
`messages`, one complete group per state set: `selection` and `press`, `star` and
`starName`, `scrollRegion` and `codeDigit`, and `loading`.

`loading` is the busy vocabulary: `busy` is what a busy action says instead of
`aria-busy` (it is the action's description and the busy spinner's name) and
`indeterminate` is what a `Progress` bar says when it has no percentage to
report. Those two words are the defaults for `loadingLabel`, a `Spinner`'s `label`
and `Progress`'s `loadingText`; a prop on one instance still wins, so a tree can
translate once and still give one action its own wording.

A group named whole replaces the inherited one; a group left out — or written
`undefined` — keeps it, so a provider forwarding an optional group it never
received cannot erase the words around it. That matters most for `starName` and
`codeDigit`: they are sentences a control calls, so a hole there is a render
that throws.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `theme` | `PrimitiveTheme` | required | every colour, size, radius and font a primitive paints |
| `density` | `Density` | `theme.density` | swaps the numeric metrics group; colours stay |
| `messages` | `Partial<PrimitiveMessages>` | the shipped English | the words a control announces |
| `children` | `ReactNode` | — | the tree that may render primitives |

## Limitations

- The density override is a whole group, not a partial patch.
- No built-in light/dark toggle and no persistence.
- Providers do not merge: the nearest `ThemeProvider` supplies the whole theme.
- One vocabulary for the tree; a control that needs a name still takes `label`.
