---
title: Skeleton
description: A pulsing placeholder for content that has not arrived.
---

`Skeleton` paints a block in the skeleton role and pulses its opacity between two
states. It is not a spinner and not a progress bar: it stands in for the shape of
content while that content loads.

## Usage

```tsx
import { Skeleton, Stack } from "@gpuixui/primitives";

<Stack direction="column" gap="sm">
  <Skeleton height={36} width="45%" />
  <Skeleton height={14} width="70%" />
  <Skeleton height={12} />
</Stack>;
```

An avatar placeholder:

```tsx
<Skeleton width={32} height={32} circle />
```

`circle` already makes the block as wide as it is tall, so a bare
`<Skeleton circle />` is a square at the body line height; pass `width` and
`height` for a larger avatar.

A list row — an avatar beside text that has not arrived. The default width takes
the space the row leaves, so the lines need no pixel widths:

```tsx
<Stack direction="row" align="center" gap="sm">
  <Skeleton circle height={40} />
  <Stack direction="column" gap="2xs" grow>
    <Skeleton height={12} width="60%" />
    <Skeleton height={12} />
  </Stack>
</Stack>;
```

`grow` is the column's own width: a column in a row has no width unless it is
told to take one, and its percentage-width children resolve against it.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `width` | `number \| string` | `"100%"`, or the height when `circle` | the block's width; a percentage takes the space its row leaves, a pixel size is kept, and a non-finite or negative pixel value uses the default |
| `height` | `number \| string` | body line height | the block's height, a floor a bounded column cannot squash; a non-finite or negative pixel value uses the default |
| `radius` | `sm \| md \| lg \| xl \| none` | `"sm"` | corner radius |
| `circle` | `boolean` | `false` | full radius and a square default; an avatar or icon placeholder |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |

A default or percentage width **shrinks to fit**: `100%` is the parent's width,
so beside a sibling it would paint outside the row without giving any back. A
numeric width — including a circle's — does not shrink, so an avatar keeps its
shape. The height is set as a floor too, so an over-full column keeps every
placeholder at the height it was asked for.

## Keyboard

Not focusable. A skeleton is decoration; loading state must be announced by
something else.

## Accessibility

The block has **no role** and no text, which is the honest arrangement — a
placeholder must not be read out as content. Announce the wait with a `Spinner`
label ("Loading projects") or a `Progress` label, or with visible text beside the
skeleton.

## Theming

`skeletonStyle` paints `colors.skeleton`; height defaults to
`typography.body.lineHeight`. The pulse alternates opacity `1` / `0.6` every
700 ms. The box's shrink rule is layout, not paint: a percentage width may
shrink in a row and the height is a floor, so a placeholder keeps the shape it
stands in for.

## Limitations

- **No looping shimmer.** A swept highlight band is expressible — `motion`
  animates `left` inside a clipped box — but `MotionTransition` has no `repeat`,
  so the second cycle would rewind visibly or remount the element. The pulse
  stays a discrete interval (plan `329`).
- No automatic count or list-shape generation; compose the blocks you need.
- No reduced-motion switch: the pulse is a plain interval.
- A percentage width resolves against its parent's width. A column placed in a
  row has no width of its own — give it `grow` (or an explicit width) before its
  `100%` placeholders can fill anything.

## Verification

- `src/core/loading.test.ts` — the two pulse states and the block geometry; a
  circle is as wide as it is tall, an explicit width wins, a plain block stays
  `100%`, a pixel dimension the runtime cannot paint falls back to its default
  (plans `330`, `371`), and a percentage width shrinks while a numeric width
  and the height floor do not (plan `384`).
- `runtime/loading.runtime.test.tsx` — opacity samples take both `1` and `0.6`
  in the real renderer, and a bare circle paints a square box.
- `runtime/nonsense-numbers.runtime.test.tsx` — a `NaN` height paints the body
  line height instead of a zero-high block (plan `371`).
- `runtime/skeleton-containment.runtime.test.tsx` — a default line beside an
  avatar stays inside a 220 px row, an over-full column keeps every explicit
  height, and a lone placeholder still fills its row (plan `384`).
