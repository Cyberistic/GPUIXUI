`Skeleton` paints a block in the skeleton role and pulses its opacity.

## Usage

```tsx
import { Skeleton, Stack } from "@gpuixui/primitives";

<Stack direction="column" gap="sm">
  <Skeleton height={36} width="45%" />
  <Skeleton height={14} width="70%" />
  <Skeleton height={12} />
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `width` | `number \| string` | `"100%"` | the block's width |
| `height` | `number \| string` | body line height | the block's height |
| `radius` | `sm \| md \| lg \| xl \| none` | `"sm"` | corner radius |
| `circle` | `boolean` | `false` | full radius; the missing side mirrors the other |
| `reducedMotion` | `boolean` | the motion provider | paints the full-opacity frame and schedules no pulse; the prop overrides the provider |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |

## Motion

The pulse alternates every 700 ms — its own constant rather than a
`motionLevels` entry, because the house levels time a transition between two
states while a placeholder alternates for as long as it is on screen. A pulse
therefore reads slower than a spinner's step (`motionLevels.step`, 120 ms).

## Limitations

- No shimmer sweep: motion animates opacity and size only.
- No automatic count or list-shape generation; compose the blocks you need.
- The reduced-motion preference is the caller's to supply.
