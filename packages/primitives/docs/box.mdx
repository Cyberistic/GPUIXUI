---
title: Box
description: The one container — a GPUix box with a semantic surface and flex facts.
---

`Box` is a `<div>` with a resolved surface: tone, padding, radius, border,
elevation and the two flex facts a layout needs. It is the **only** primitive
that merges a caller's `style` over a resolved one and the escape hatch for
anything the named props do not cover. It is not a card, a panel or a dialog;
those are compositions.

## Usage

```tsx
import { Box, Text } from "@gpuixui/primitives";

<Box tone="card" padding="md" radius="md" border>
  <Text role="body">A surface with the card role.</Text>
</Box>;
```

## Tones

| `tone` | Background role | Use for |
| ------ | --------------- | ------- |
| `none` | none | a layout wrapper that must not paint |
| `background` | `background` | the application frame |
| `card` | `card` | a raised content surface |
| `popover` | `popover` | menus, overlays, tooltips |
| `muted` | `muted` | a quiet inset region |
| `accent` | `accent` | a highlighted region |
| `selected` | `selected` | a selected row or tile |
| `skeleton` | `skeleton` | a placeholder block |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `tone` | `SurfaceTone` | — (required) | which semantic background is painted |
| `padding` | spacing step | none | padding on all sides from the theme scale |
| `radius` | `none \| sm \| md \| lg \| xl \| full` | none | corner radius |
| `border` | `boolean` | `false` | one thin border on the `border` role |
| `elevation` | `sm \| md \| lg \| overlay` | none | the theme's first shadow at that level |
| `grow` | `boolean` | `false` | takes leftover space on the parent's main axis |
| `shrink` | `boolean` | `false` | may shrink below its content |
| `fullWidth` / `fullHeight` | `boolean` | `false` | `100%` on that axis |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged **last**, so it wins property by property |
| `children` | `ReactNode` | — | content |
| `testId` | `string` | — | stable locator for automation |

`shrink` is deliberately `false` by default: chrome must not squash, which is the
opposite of the browser's flex default and the right one for application layout.

## Keyboard

Not focusable and not interactive. A clickable surface is a `Button` or an
application-level host element with its own contract.

## Accessibility

`Box` contributes **no role** and no `aria-*`. A decorative container must stay
out of the accessibility tree; semantic regions belong to the content or to a
composed component such as `ButtonGroup`.

## Theming

Surface tones resolve through `surfaceStyle` in `src/core/style.ts`. Padding,
radius and border width come from `spacing`, `radius` and `borderWidth`;
elevation from the theme's shadow list, of which GPUix paints the first entry.

## Limitations

- No `role`, `tabIndex` or event props: the public API is a container, not a
  host-element re-export. Compose a host element when you need semantics.
- No gradient or border-style prop: `Box` resolves the theme's solid surface
  roles. GPUix 0.11.0's `StyleDesc` does accept a linear-gradient `background`
  and `borderStyle: "dashed"`, so this is a gap in `Box`'s API, not a runtime
  absence — pass them through `style` today.
- One shadow per element — the runtime paints a single `boxShadow`.
