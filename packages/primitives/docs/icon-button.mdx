`IconButton` is `Button` for an action whose only visible content is a glyph; the
name is required.

## Usage

```tsx
import { IconButton, Stack, useTheme } from "@gpuixui/primitives";
import { Icon } from "@gpuixui/icons";

const theme = useTheme();

<Stack direction="row" gap="2xs">
  <IconButton
    label="Delete layer"
    icon={<Icon name="trash" color={theme.colors.destructiveForeground} />}
    variant="destructive"
    onActivate={removeLayer}
  />
  <IconButton
    label="Layer settings"
    icon={<Icon name="settings" color={theme.colors.foreground} />}
    onActivate={openSettings}
  />
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `label` | `string` | required | the accessible name; never derived from the glyph |
| `icon` | `ReactNode` | required | the glyph painted inside the button |
| `variant` | `ButtonVariant` | `"ghost"` | the paint from `core/variants.ts` |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | square side from `density.controlHeight` |
| `disabled` | `boolean` | `false` | blocks activation; out of the Tab order (`tabIndex: -1`) |
| `loading` | `boolean` | `false` | spinner, busy description, blocks activation |
| `loadingLabel` | `string` | `"Loading"` | the busy word, announced as the description and the spinner's name |
| `reducedMotion` | `boolean` | `false` | holds the busy spinner's lit dot |
| `onActivate` | `(event: EventPayload) => void` | none | click or activating key; not called while busy |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the button's own; a click is observed first, an activating key acts first |
| `ref` | `Ref<PublicInstance>` | — | the element itself |
| `aria-expanded` / `aria-selected` | `boolean` | — | announced state, forwarded through `ActionHostProps` |
| `className` | `string` | — | a Tailwind string joined after the recipe |
| `style` | `StateStyle<ButtonState>` | — | resolved against `{ disabled, focused }`, merged last |
| `testId` | `string` | — | stable locator |

## Limitations

- No `aria-disabled` and no `aria-pressed`: use `Toggle` for a pressed mode.
- No tooltip of its own, but it is a `Tooltip` trigger.
- The glyph is not sized by `size`; pass `icon={<Icon size="sm" … />}`.
- No native button element: a `div` with a role and handlers.
