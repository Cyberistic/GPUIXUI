---
title: IconButton
description: A square button whose only content is an icon, with a required accessible name.
---

`IconButton` is the icon-only shape of `Button`: dialogs close, menus and
popovers open, toasts dismiss. It is not a second button — it composes `Button`
with `square`, forwards its state props, and owns the three things a hand-rolled
copy gets wrong: the icon tint, the busy state, and the accessible name.

## Usage

```tsx
import { IconButton, Stack } from "@gpuixui/primitives";

<Stack direction="row" gap="sm">
  <IconButton icon="pencil" label="Edit" variant="ghost" onActivate={edit} />
  <IconButton
    icon="trash"
    label="Delete"
    variant="destructive"
    onActivate={remove}
  />
</Stack>;
```

`icon` names an icon from `@gpuixui/icons`; `label` is the button's name and is
required, because an icon alone cannot name anything.

## Variants and sizes

The paint is [`Button`](button.mdx)'s `buttonVariants`; the icon is tinted with
the same **foreground** role that variant paints its text in, so it cannot
disappear on a filled button.

| `variant` | Icon tint |
| --------- | --------- |
| `primary` (default) | `primaryForeground` |
| `secondary` | `secondaryForeground` |
| `outline` | `foreground` |
| `ghost` | `foreground` |
| `destructive` | `destructiveForeground` |
| `link` | `primary` |

| `size` | Button box | Icon |
| ------ | ---------- | ---- |
| `sm` | 32 (`size-8`) | `iconSize.sm` (14 px) |
| `md` (default) | 36 (`size-9`) | `iconSize.md` (16 px) |
| `lg` | 40 (`size-10`) | `iconSize.lg` (20 px) |

The box is shadcn's new-york-v4 icon table (`BUTTON_SIZES` through
`buttonRecipeStyle`), the same slice `Button` uses. It is **not** the density
scale: a `ThemeProvider density` override leaves the box at 32/36/40, exactly as
it leaves a text button at `h-8`/`h-9`/`h-10` (plan `370`; measured 375).

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `icon` | `IconName` | — | the glyph that is painted |
| `label` | `string` | — | accessible name; required |
| `variant` | `ButtonVariant` | `"primary"` | fill, border and icon tint |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | square box and icon size |
| `radius` | `RadiusStep` | `"md"` | corner radius |
| `disabled` | `boolean` | `false` | leaves the tab order, refuses activation, fades to 50% |
| `loading` | `boolean` | `false` | paints a spinner **instead of** the icon, sized to the square (9/10/12 px dots at `sm`/`md`/`lg`), announces `Loading`, refuses activation |
| `onActivate` / `onClick` | — | none | the shared `Button` activation path; `onClick` receives the click or the key event |
| `style` | `StateStyle<ButtonState>` | — | merged last over the button's own rules |
| `testId` | `string` | — | stable locator |

`children`, `leading`, `trailing` and `fullWidth` are deliberately absent: an
icon button has one content slot and a square box.

The **slot trigger contract is inherited from `Button`** (plan `341`): a
`Tooltip` wrapping an `IconButton` opens on hover and focus, closes on click and
Escape, and the tip text arrives as the button's `aria-description`.

## Keyboard

| Key | Contract |
| --- | -------- |
| Enter | activates on key **down** |
| Space | activates on key **up** |
| held key | repeat events never activate |

`disabled` and `loading` refuse activation. `disabled` removes the tab stop;
`loading` keeps it, so a keyboard user is not dropped mid-action. When both are
set, `disabled` wins. The loading indicator is fitted to the square's content
box — three 9/10/12 px dots at `sm`/`md`/`lg`, less a border — because the
text-sized row was 46 px and painted outside a 36 px button (plan `644`). Its
dots take the same variant **foreground** as the icon it replaces, so the busy
state stays visible on a filled `primary` button (plan `754`).

## Accessibility

- **Release-runtime focus:** the pinned 0.10.0 runtime moves native focus but
  delivers no `onFocus`/`onBlur` to a component
  ([measured](../../../docs/gpuix-capabilities.md#focus-events)). The ring still
  paints: `ThemeProvider`'s native-focus tracker samples
  `getFocusedElementId()` every 50 ms, so focus reaches the paint up to one tick
  late (plan `590`). Role, name, tab order, keyboard operation and activation
  are unaffected.
- One `button` node named `label`. The icon is decorative (`presentation`), so
  the tree has no second node for it — measured in the runtime: a `Button` named
  `"Close"` and **no** `Image` node.
- No `aria-disabled`: a disabled button leaves the tab order instead.
- `loading` sets `aria-description="Loading"`; GPUix has no `aria-busy`.
- The icon's visual tint is `style.color`, so contrast follows the button's
  foreground role in every theme.

## Theming

No new token: the box and the focus ring come from the button recipe
(`buttonRecipeStyle`, `buttonRecipeRing`), the fill from `buttonVariants`, the
tint from the same variant's **foreground** role, and the icon size from
`theme.iconSize`. A theme change repaints the button and the icon together
because both read the same `Theme`. The ring is the recipe's 3 px, 50 % ring —
the same one a text button paints, and the same one the attached-`ButtonGroup`
inset overlay uses (plans `344`, `370`).

## Limitations

- The icon must be a name in the set. There is no arbitrary child slot.
- No `focusVisible` in GPUix 0.10.0: a mouse click paints the same ring as
  `Tab`.
- No native `<button>`: the runtime exposes a `div` with `role="button"`.
- The icon cannot carry its own label; the button owns the name.

## Verification

- `src/components/IconButton.test.tsx` — composes a square `Button` with the
  required name, paints the named icon, tints it with each variant's foreground,
  maps the size scale, and omits the icon while loading.
- `runtime/controls.runtime.test.tsx` — one named `Button` and no `Image` node;
  click/Enter/Space activation; the painted `svg` tint and square bounds; the
  loading spinner with no icon; a disabled button skipped by `Tab`.
- `runtime/focus-ring.runtime.test.tsx` — the icon button is in the matrix: it
  paints exactly one `buttonRecipeRing`, inside its own box (plan `375`).
- `runtime/theme-axes.runtime.test.tsx` — under the compact and spacious
  presets the box stays 36 square at `md`, so the recipe, not density, owns it
  (plan `375`).

```sh
nub run --filter @gpuixui/primitives test
nub run --filter @gpuixui/primitives test:runtime
```
