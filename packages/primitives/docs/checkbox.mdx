`Checkbox` is a square selection control for an independent choice.

<ComponentPreview name="checkbox-states" />

## Usage

```tsx
import { Checkbox } from "@gpuixui/primitives";

<Checkbox
  checked={email}
  onCheckedChange={setEmail}
  label="Email notifications"
/>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `Checkbox` | the box, its state and the press target |
| `CheckboxIndicator` | the mark; `Checkbox`'s children are its content |

## API

### `Checkbox`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `checked` | `boolean` | — | controlled state; omit to let the box keep its own |
| `defaultChecked` | `boolean` | `false` | initial state when uncontrolled |
| `onCheckedChange` | `(next: boolean) => void` | none | the next boolean |
| `onChange` | `(next: boolean) => void` | none | deprecated alias for `onCheckedChange` |
| `children` | `ReactNode` | the default glyph | the mark's content |
| `indeterminate` | `boolean` | `false` | paints a dash and announces `mixed`; overrides `checked` |
| `disabled` | `boolean` | `false` | refuses pointer and keys, leaves the tab order |
| `invalid` | `boolean` | `false` | the empty box takes the destructive border |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | box side from `iconSize` |
| `accent` | `"primary" \| "destructive"` | `"primary"` | the fill and mark colour |
| `label` | `string` | none | accessible name |
| `description` | `string` | none | announced help (`aria-description`) |
| `onMouseEnter` / `onMouseLeave` / `aria-description` | `TooltipTriggerProps` | none | forwarded to the press target, so the box can be a `Tooltip` trigger |
| `ref` / `aria-id` / `onLayout` | host address | none | the box is the addressed element |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the box's own; yours runs first |
| `style` | `StateStyle<CheckboxState>` | — | resolved against the live state, merged last |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `testId` | `string` | — | stable locator |

### `CheckboxIndicator`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | the default check/dash | the glyph |
| `className` | `string` | — | compiled through the recipe, after the part's rules |
| `style` | `StyleDesc` | — | merged last |

## Limitations

- No `aria-checked`: the state is announced through `aria-valuetext`.
- No label-inside-the-control composition: a `Label` beside the box does not name
  the box — pass `label` or `labelledBy(name)` — and a press on those words
  focuses it (`Label target`) rather than toggling it, because the runtime
  publishes no press verb for another element. A row whose words toggle is a
  `CheckboxGroup`: the row itself is the control, and a group of one is a valid
  row.
- No partial-state animation.
