`Spinner` is the activity indicator for work with no known proportion: three dots
advance a lit position.

## Usage

```tsx
import { Spinner, Stack, Text } from "@gpuixui/primitives";

<Stack direction="row" align="center" gap="sm">
  <Spinner label="Refreshing revenue" />
  <Text role="caption" tone="muted">Refreshing…</Text>
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `size` | `IconSize \| number` | `"md"` | the dot side: a theme step, or raw pixels |
| `accent` | `primary \| destructive \| muted \| on-primary \| on-secondary \| on-destructive \| on-accent \| on-disabled` | `"primary"` | the role every dot paints |
| `label` | `string` | `loading.busy` (`"Loading"`) | accessible name announced as a status; a blank one paints the dots as decoration (no node to walk into) |
| `reducedMotion` | `boolean` | the motion provider | holds the lit dot and schedules no interval; the prop overrides the provider |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |

## Motion

The lit dot advances one place per tick at `motionLevels.step` (120 ms in the
shipped timing) — the house level `@gpuixui/motion` publishes for a step
indicator, read rather than copied, so a brand that moves the level moves the
spinner with it. A full turn is the row's own length, and an indeterminate
`Progress` ticks its segment on the same cadence.

## Limitations

- Cannot rotate: a discrete lit-dot step instead.
- No smooth animation, and the three dots share one size.
- No inline placement inside a text run; put it in a `Stack`.
- The reduced-motion preference is the caller's to supply.
- A blank `label` is silence, and silence is **decoration**: the dots paint
  `role="presentation"` rather than a `status` node with no name — an unnamed
  status is still a node an assistive technology walks into. The shipped word is
  what names a spinner nobody named; only an explicit blank opts out, which is
  the word `Button`'s blank `loadingLabel` composes.
