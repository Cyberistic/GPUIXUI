`Spinner` is the activity indicator for work with no known proportion: three dots
advance a lit position.

## Usage

```tsx
import { Spinner, Stack, Text } from "@gpuixui/primitives";

<Stack direction="row" align="center" gap="sm">
  <Spinner label="Refreshing revenue" />
  <Text role="caption" tone="muted">Refreshing…</Text>
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `size` | `IconSize \| number` | `"md"` | the dot side: a theme step, or raw pixels |
| `accent` | `primary \| destructive \| muted \| on-primary \| on-secondary \| on-destructive \| on-accent \| on-disabled` | `"primary"` | the role every dot paints |
| `label` | `string` | `"Loading"` | accessible name announced as a status |
| `reducedMotion` | `boolean` | `false` | holds the lit dot and schedules no interval |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |

## Limitations

- Cannot rotate: a discrete lit-dot step instead.
- No smooth animation, and the three dots share one size.
- No inline placement inside a text run; put it in a `Stack`.
- The reduced-motion preference is the caller's to supply.
