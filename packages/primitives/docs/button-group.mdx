---
title: ButtonGroup
description: A row or column of related actions, attached or separated.
---

`ButtonGroup` lays buttons out on one axis with `role="group"`.

## Usage

```tsx
import { Button, ButtonGroup } from "@gpuixui/primitives";

<ButtonGroup mode="attached" label="Text alignment">
  <Button variant="ghost">Left</Button>
  <Button variant="secondary">Center</Button>
  <Button variant="ghost">Right</Button>
</ButtonGroup>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `ButtonGroup` | the axis, gap, radius and `role="group"` |
| `Button` / `IconButton` | each action; attached children square their own corners |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `mode` | `"attached" \| "separated"` | `"attached"` | zero gap + clipped group, or a spaced group |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | a row, or a column with one shared width |
| `gap` | spacing step | `"sm"` | the gap in separated mode |
| `label` | `string` | none | the group's accessible name, written as `aria-label` |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |
| `children` | `ReactNode` | — | the buttons |

## Limitations

- Only this package's actions are reshaped; other children keep their radius.
- The name must be passed as `label`.
- No overflow-to-menu for a group wider than its parent.
- No responsive axis switch.
