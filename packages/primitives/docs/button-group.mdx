---
title: ButtonGroup
description: A row of related actions, attached or separated.
---

`ButtonGroup` lays buttons out as one row and gives the row `role="group"`. In
`attached` mode the gap is zero, every action inside squares its own corners and
the **group** is rounded and clipped, so the row reads as one control.

## Usage

```tsx
import { Button, ButtonGroup } from "@gpuixui/primitives";

<ButtonGroup mode="attached" label="Text alignment">
  <Button variant="ghost">Left</Button>
  <Button variant="secondary">Center</Button>
  <Button variant="ghost">Right</Button>
</ButtonGroup>;
```

## Modes

| `mode` | Gap | Shape |
| ------ | --- | ----- |
| `attached` (default) | 0 | children square their corners; group radius `md`, `overflow: hidden` |
| `separated` | `gap` step (`sm` default) | buttons keep their own radius |

The runtime has no `:first-child`/`:last-child` selector and a ref exposes no
style mutation, so the group cannot reshape a child from outside. It instead
tells the actions it attaches that the **container** owns the silhouette
(`AttachedGroup`): each `Button` and `IconButton` inside squares its own
`borderRadius`, and the group's radius plus `overflow: hidden` clip the two ends.
Without that, two adjacent rounded fills leave a notch at every seam where the
page shows through. A caller who wants one end rounded passes `style` on that
button, which merges after the group's rule; a child that is not one of this
package's actions is not reshaped.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `mode` | `"attached" \| "separated"` | `"attached"` | zero gap + clipped group, or a spaced row |
| `gap` | spacing step | `"sm"` | the gap in separated mode |
| `label` | `string` | none | the group's accessible name, written as `aria-label` |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last, e.g. `justifyContent: "flex-end"` |
| `testId` | `string` | — | stable locator |
| `children` | `ReactNode` | — | the buttons |

## Keyboard

The group adds no key handling. Tab moves through each button in order; Enter and
Space follow each `Button`'s contract. A segmented control that should be one tab
stop with arrow navigation is a radio group, not a button group.

## Accessibility

- Role: `group`. The runtime has no `aria-labelledby`, so a visible heading
  cannot name the group by reference; pass its words as `label` and the group
  carries `aria-label`. Without `label` the group is anonymous, exactly as the
  runtime reports it.
- Each button keeps its own name and role.

## Theming

The gap uses `spacing[gap]`; the group radius is `radius.md`. No literal. The
children do not take a radius role of their own while attached: the group's
radius is the only one painted on the silhouette.

## Limitations

- Only this package's actions are reshaped: a raw `div` or another component
  placed inside an attached group keeps its own radius, because the runtime has
  no child selector and the group cannot reach into it.
- The name must be passed as `label`; there is no automatic association with a
  heading.
- No overflow behaviour: a group wider than its parent does not collapse into a
  menu.

## Verification

- `src/components/presentational.test.tsx` — attached and separated geometry
  plus `role="group"`, and the `label` → `aria-label` contract.
- `src/components/Button.test.tsx` / `IconButton.test.tsx` — an attached action
  squares its corners and a caller's `style` still restores a radius.
- `runtime/controls.runtime.test.tsx` — attached children are 0px apart and
  paint `borderRadius: 0` while separated children paint the theme's `md` radius
  and sit the `sm` gap apart; a labelled group is an accessibility `Group` with
  that name.

```sh
nub run --filter @gpuixui/primitives test
nub run --filter @gpuixui/primitives test:runtime
```
