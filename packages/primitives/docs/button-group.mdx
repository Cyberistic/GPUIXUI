---
title: ButtonGroup
description: A row of related actions, attached or separated.
---

`ButtonGroup` lays buttons out as one row and gives the row `role="group"`. In
`attached` mode the gap is zero and the **group** is rounded and clipped; it does
not reshape individual buttons.

## Usage

```tsx
import { Button, ButtonGroup } from "@gpuixui/primitives";

<ButtonGroup mode="attached" label="Text alignment">
  <Button variant="ghost">Left</Button>
  <Button variant="secondary">Center</Button>
  <Button variant="ghost">Right</Button>
</ButtonGroup>;
```

## Modes

| `mode` | Gap | Shape |
| ------ | --- | ----- |
| `attached` (default) | 0 | group radius `md`, `overflow: hidden`; buttons are square, so the clip supplies the rounded ends |
| `separated` | `gap` step (`sm` default) | buttons keep their own `radius` (`md` by default) |

The runtime has no `:first-child`/`:last-child` selector and a component cannot
restyle a child without cloning it, so `attached` cannot round only the ends. It
asks every `Button` to be **square** through a React context and rounds and clips
the **group** instead: the clip supplies the outer corners, and two adjacent
buttons meet on a straight shared edge instead of two rounded corners with a
notch between them. Pass `radius` to a single button when it needs a different
shape; an explicit value wins over the group's.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `mode` | `"attached" \| "separated"` | `"attached"` | zero gap + clipped group, or a spaced row |
| `gap` | spacing step | `"sm"` | the gap in separated mode |
| `label` | `string` | none | the group's accessible name, written as `aria-label` |
| `style` | `StyleDesc` | — | merged last, e.g. `justifyContent: "flex-end"` |
| `testId` | `string` | — | stable locator |
| `children` | `ReactNode` | — | the buttons |

## Keyboard

The group adds no key handling. Tab moves through each button in order; Enter and
Space follow each `Button`'s contract. A segmented control that should be one tab
stop with arrow navigation is a radio group, not a button group.

## Accessibility

- Role: `group`. The runtime has no `aria-labelledby`, so a visible heading
  cannot name the group by reference; pass its words as `label` and the group
  carries `aria-label`. Without `label` the group is anonymous, exactly as the
  runtime reports it.
- Each button keeps its own name and role.

## Theming

The gap uses `spacing[gap]`; the group radius is `radius.md`. No literal.

## Limitations

- The shape rule reaches `Button` children only (through `GroupShapeContext`); a
  `Toggle` or another control in the group keeps its own radius. A pressed set
  belongs in `ToggleGroup`, which owns that paint.
- The name must be passed as `label`; there is no automatic association with a
  heading.
- No overflow behaviour: a group wider than its parent does not collapse into a
  menu.
