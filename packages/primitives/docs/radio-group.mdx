`RadioGroup` is a radio group whose options arrive as data or as
`<RadioGroupItem>` children; the arrows select and move focus together.

## Usage

```tsx
import { RadioGroup } from "@gpuixui/primitives";

<RadioGroup
  label="Digest cadence"
  value={cadence}
  onValueChange={setCadence}
  options={[
    { value: "daily", label: "Daily" },
    { value: "weekly", label: "Weekly", description: "Every Monday." },
    { value: "never", label: "Never" },
  ]}
/>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `RadioGroup` | the named group, the roving tab stop and the value |
| `RadioGroupItem` | an option row; the data prop's element form |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `options` | `ReadonlyArray<RadioOption>` | — | the choices as data; omit when the items are children |
| `children` | `ReactNode` | — | `<RadioGroupItem>` elements, for rich content |
| `value` | `string` | — | controlled selection |
| `defaultValue` | `string` | `""` | initial selection when uncontrolled |
| `onValueChange` | `(value: string) => void` | none | the selected item's value |
| `onChange` | `(value: string) => void` | none | deprecated alias for `onValueChange` |
| `orientation` | `"vertical" \| "horizontal"` | `"vertical"` | layout and the arrow axis |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | radio circle size |
| `accent` | `"primary" \| "destructive"` | `"primary"` | the dot's fill |
| `disabled` | `boolean` | `false` | disables every option |
| `label` | `string` | none | accessible name for the group |
| `description` | `string` | none | announced help for the group (`aria-description`) |
| `ref` / `aria-id` / `onLayout` | host address | none | land on the row that holds the tab stop |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StateStyle<RadioGroupState>` | — | resolved against the live state, merged last |
| `itemStyle` | `StateStyle<RadioItemState>` | — | resolved per option row, merged last |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the group's own; yours runs first |
| `testId` | `string` | — | stable locator |

## Limitations

- No `aria-checked`: a row's state is announced through `aria-valuetext`.
- An option's `description` is a caption beside the name, announced as that
  row's help through `aria-description` (the runtime has no `aria-describedby`);
  a blank one paints and announces nothing.
- `""` is a value like any other: an option whose `value` is the empty string
  paints checked when the group's value is `""`.
- Item content must stay presentational; rich content uses `RadioGroupItem`.
