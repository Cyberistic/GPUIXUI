title: Switch
description: An immediate on/off, distinct from a checkbox in intent.
---

`Switch` is the "takes effect now" control: a track and a thumb, announced with
the switch role.

<ComponentPreview name="switch-states" />

## Usage

```tsx
import { Switch } from "@gpuixui/primitives";

<Switch
  checked={paused}
  onCheckedChange={setPaused}
  label="Pause all notifications"
/>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `Switch` | the track, state and press target |
| `SwitchThumb` | the knob; `Switch`'s children are its content |

## API

### `Switch`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `checked` | `boolean` | — | controlled; omit to let the switch keep its own state |
| `defaultChecked` | `boolean` | `false` | initial state when uncontrolled |
| `onCheckedChange` | `(next: boolean) => void` | none | the next boolean |
| `onChange` | `(next: boolean) => void` | none | deprecated alias for `onCheckedChange` |
| `children` | `ReactNode` | none | a glyph inside the knob |
| `disabled` | `boolean` | `false` | refuses pointer and keys, leaves the tab order |
| `invalid` | `boolean` | `false` | the track takes the destructive role |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | track height from `iconSize` |
| `accent` | `"primary" \| "destructive"` | `"primary"` | the on-track fill |
| `label` | `string` | none | accessible name |
| `description` | `string` | none | announced help (`aria-description`) |
| `onMouseEnter` / `onMouseLeave` / `aria-description` | `TooltipTriggerProps` | none | forwarded to the press band, so the switch can be a `Tooltip` trigger |
| `ref` / `aria-id` / `onLayout` | host address | none | the press band is the addressed element |
| `reducedMotion` | `boolean` | the motion provider | the thumb lands instead of sliding; the prop overrides the provider |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the switch's own; yours runs first |
| `style` | `StateStyle<SwitchState>` | — | resolved against the live state, merged last |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `testId` | `string` | — | stable locator |

### `SwitchThumb`

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `children` | `ReactNode` | none | a glyph on the knob |
| `className` | `string` | — | compiled through the recipe, joined after the thumb's rules |
| `style` | `StyleDesc` | — | merged last |

## Limitations

- No `aria-checked`: the state is announced through `aria-valuetext`.
- A visible `Label` is not associated with the switch — pass `label` or
  `labelledBy(name)` — and a press on those words focuses the switch
  (`Label target`) rather than flipping it; the switch's own target is the
  control, because the runtime publishes no press verb for another element.
- No loading or pending state; disable it while a request is in flight.
- The slide is 150ms; `reducedMotion` lands the thumb. It defaults to the
  motion provider's preference (`MotionProvider`), so one wrapper covers a tree.
- A theme restored from storage writes `null` for the paint it did not carry
  (JSON has no `undefined`): that is no declaration, so the switch paints the
  accent family in the derived box. A table that lost one of its three slots is
  no paint either — `switchFailures` from `@gpuixui/tokens` names the slot to
  repair before the platform's own paint returns.
