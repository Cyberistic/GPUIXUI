## Usage

```tsx
import { Label, Select } from "@gpuixui/primitives";

<Label>Region</Label>
<Select
  value={region}
  onValueChange={setRegion}
  label="Region"
  fullWidth
  options={[
    { value: "eu-west", label: "Europe — West" },
    { value: "us-east", label: "United States — East" },
    { value: "legacy", label: "Legacy region", disabled: true },
  ]}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `options` | `ReadonlyArray<SelectOption \| SelectOptionGroup>` | required | `{ value, label, disabled? }` items, or `{ label, options }` groups |
| `value` | `string` | — | controlled selection |
| `defaultValue` | `string` | — | initial selection when uncontrolled |
| `selectedValue` | `string` | `value ?? defaultValue` | the choice the trigger announces; outranks `value`/`defaultValue`, for a parent that mirrors an uncontrolled select's value |
| `open` | `boolean` | — | controlled open state |
| `defaultOpen` | `boolean` | `false` | the list's initial state |
| `onOpenChange` | `(open: boolean) => void` | none | the open state GPUix reported |
| `onValueChange` | `(value: string) => void` | none | the committed value |
| `onChange` | `(value: string) => void` | none | deprecated alias for `onValueChange` |
| `placeholder` | `string` | none | shown before a choice |
| `disabled` | `boolean` | `false` | refuses opening |
| `invalid` | `boolean` | `false` | destructive border on the trigger |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | trigger height and padding |
| `fullWidth` | `boolean` | `false` | trigger and list fill the parent |
| `side` | `FloatingSide` | GPUix's choice | which side the list opens on |
| `align` | `FloatingAlign` | GPUix's default | how the list is aligned against the trigger |
| `label` | `string` | none | accessible name for the select |
| `description` | `string` | none | announced help after the name (`aria-description`); a blank one publishes nothing |
| `ref` / `aria-id` / `onLayout` | host props | none | the trigger is the addressed element — the one a form focuses, an automation host names and a layout measures |
| `style` | `StyleDesc` | — | merged last on the select root |
| `triggerStyle` | `StateStyle<SelectTriggerState>` | — | resolved against the trigger's live state, merged last |
| `itemStyle` | `StateStyle<SelectItemState>` | — | resolved per option, merged last |
| `testId` | `string` | — | the root's locator |
| `triggerTestId` | `string` | — | the trigger's locator |
| `itemTestId` | `(value: string) => string` | — | per-option locator, derived from its value |

## Limitations

- No `aria-activedescendant` and no native combobox value: the closed trigger announces its choice through `aria-valuetext`, and an empty select announces nothing.
- The list is not associated with the trigger by an ARIA attribute (0.11.0 has no `aria-controls`); the trigger says `expanded` and the rows announce themselves.
- Options are data: no rich options or compound escape hatch. A stored `options` list is read structurally — a list a store wrote as absent (JSON's `null`) paints an empty list instead of taking the control down, an entry with no text `value` (or a group whose list is not a list) is dropped rather than hiding the options beside it, and a missing or blank `label` reads as the option's `value`.
