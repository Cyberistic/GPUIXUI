---
title: Select
description: One choice from a list, in a popover.
---

`Select` reuses `@gpuix/react/select` for the interaction and themes it to match
the field chrome. A closed select announces the choice it shows — the chosen
option's label, in `aria-valuetext` — because 0.11.0's combobox publishes no
value of its own.

<ComponentPreview name="select-states" />

## Usage

```tsx
import { Label, Select } from "@gpuixui/primitives";

<Label>Region</Label>
<Select
  value={region}
  onValueChange={setRegion}
  label="Region"
  fullWidth
  options={[
    { value: "eu-west", label: "Europe — West" },
    { value: "us-east", label: "United States — East" },
    { value: "legacy", label: "Legacy region", disabled: true },
  ]}
/>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `options` | `ReadonlyArray<SelectOption \| SelectOptionGroup>` | required | `{ value, label, disabled? }` items, or `{ label, options }` groups |
| `value` | `string` | — | controlled selection |
| `defaultValue` | `string` | — | initial selection when uncontrolled |
| `selectedValue` | `string` | `value ?? defaultValue` | the choice the trigger announces; a parent's mirror of an uncontrolled select's value |
| `open` | `boolean` | — | controlled open state |
| `defaultOpen` | `boolean` | `false` | the list's initial state |
| `onOpenChange` | `(open: boolean) => void` | none | the open state GPUix reported |
| `onValueChange` | `(value: string) => void` | none | the committed value |
| `onChange` | `(value: string) => void` | none | deprecated alias for `onValueChange` |
| `placeholder` | `string` | none | shown before a choice |
| `disabled` | `boolean` | `false` | refuses opening |
| `invalid` | `boolean` | `false` | destructive border on the trigger |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | trigger height and padding |
| `fullWidth` | `boolean` | `false` | trigger and list fill the parent |
| `side` | `FloatingSide` | GPUix's choice | which side the list opens on |
| `label` | `string` | none | accessible name for the select |
| `description` | `string` | none | announced help after the name (`aria-description`); a blank one publishes nothing |
| `ref` / `aria-id` / `onLayout` | host props | none | the trigger is the addressed element — the one a form focuses, an automation host names and a layout measures |
| `style` | `StyleDesc` | — | merged last on the select root |
| `triggerStyle` | `StateStyle<SelectTriggerState>` | — | resolved against the trigger's live state, merged last |
| `itemStyle` | `StateStyle<SelectItemState>` | — | resolved per option, merged last |
| `testId` | `string` | — | the root's locator |
| `triggerTestId` | `string` | — | the trigger's locator |
| `itemTestId` | `(value: string) => string` | — | per-option locator, derived from its value |

The trigger is the control: it carries `role="combobox"`, the `label` as its
name, the open state in `aria-expanded`, the chosen option's words in
`aria-valuetext`, and the caller's `description` as `aria-description`. The same
element takes the `ref`, the `aria-id` and the `onLayout`, so a form can focus
the select it failed on, an automation host can address it and a layout can
measure it; the wrapper around the trigger is not focusable and carries no name.
`src/components/Select.test.tsx` holds those four props on the trigger (and a
blank `description` publishing nothing), and
`runtime/address.runtime.test.tsx` reads the help, author id and ref back off the
runtime's own accessibility tree and element.

## Limitations

- No `aria-activedescendant` and no native combobox value: the closed trigger
  announces its choice through `aria-valuetext`, and an empty select announces
  nothing — a placeholder is not a choice.
- The list is not associated with the trigger by an ARIA attribute (0.11.0 has
  no `aria-controls`); the trigger says `expanded` and the rows announce
  themselves.
- Options are data: no rich options or compound escape hatch.
- No search, type-ahead or multi-select.
- A long list caps at 320px and scrolls; the highlighted row reveals itself, and
  a row taller than the list aligns its top rather than its last line.
- Open animation, positioning and dismissal are the runtime's.
