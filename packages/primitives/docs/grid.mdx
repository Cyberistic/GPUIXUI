`Grid` is the runtime's fixed-size grid: a numeric column count and an optional
row count. It is not a CSS grid.

## Usage

```tsx
import { Grid, Text } from "@gpuixui/primitives";

<Grid columns={2} gap="sm">
  <Text role="caption" tone="muted">Width</Text>
  <Text role="code">1280 px</Text>
  <Text role="caption" tone="muted">Height</Text>
  <Text role="code">800 px</Text>
</Grid>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `columns` | `number` | required | equal column tracks; floored, minimum 1 |
| `rows` | `number` | auto | equal fixed rows; floored, minimum 1 |
| `gap` | spacing step | none | both axes, from `spacing` |
| `grow` | `boolean` | `false` | takes leftover space on the parent's axis |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `children` | `ReactNode` | — | cells, in source order |
| `testId` | `string` | — | stable locator |

## Limitations

- Equal tracks only; a narrow label column is a `Stack` row.
- No auto-flow or spanning cells.
- No named areas or template strings.
- Not focusable and no role.
