## Usage

```tsx
import { Progress, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="xs">
  <Text role="caption" tone="muted">Uploading · 42%</Text>
  <Progress value={42} label="Uploading" />
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | — | 0–100 determinate fill; omit for indeterminate, and a stored `null` reads as omitted |
| `buffer` | `number` | none | 0–100 held-ahead point; paints the segment between `value` and itself |
| `tone` | `primary \| success \| destructive \| muted` | `"primary"` | the fill's colour role; a stored name the table does not carry reads as `primary` |
| `size` | `"sm" \| "md"` | `"md"` | track height from `spacing.xs`/`sm`; a stored name the table does not carry reads as `md` |
| `label` | `string` | none | accessible name, and `ProgressLabel`'s default text |
| `formatValue` | `(percent: number) => string` | `` `${percent}%` `` | the announced and painted share; a blank answer keeps the default |
| `loadingText` | `string` | `loading.indeterminate` (`"loading"`) | what an indeterminate bar says instead of a percentage; a blank one keeps the provider's |
| `reducedMotion` | `boolean` | the motion provider | holds the indeterminate segment; no effect with `value`. The prop overrides the provider |
| `children` | `ReactNode` | the track | the parts to draw |
| `style` | `StyleDesc` | — | merged last, on the root frame |
| `className` | `string` | — | Tailwind classes, joined last on the root frame |
| `testId` | `string` | — | stable locator, on the root |

A widget record kept in JSON stores a share it never learned as `null` rather than `undefined`. That reads as **absent**, like an omitted prop: the bar paints the moving segment and says the loading word, while `0` remains the empty share it names.

## Limitations

- No `aria-valuenow`: the value is announced as `aria-valuetext`.
- The indeterminate word is the provider's `messages.loading.indeterminate`; pass `loadingText` to word one bar differently.
- The indeterminate segment is a discrete step, not a smooth sweep.
