`Progress` paints a track and a fill. With `value` it is determinate; without it,
a segment advances as an indeterminate bar.

## Usage

```tsx
import { Progress, Stack, Text } from "@gpuixui/primitives";

<Stack direction="column" gap="xs">
  <Text role="caption" tone="muted">Uploading · 42%</Text>
  <Progress value={42} label="Uploading" />
</Stack>;
```

## Composition

| Part | Responsibility |
| ---- | -------------- |
| `Progress` | role, accessible name, announced value |
| `ProgressTrack` | the bar's background and overflow clip |
| `ProgressIndicator` | the fill, and the buffer segment after it |
| `ProgressLabel` | visible task name, defaulting to the root's `label` |
| `ProgressValue` | the clamped percentage in the caller's words |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | — | 0–100 determinate fill; omit for indeterminate |
| `buffer` | `number` | none | 0–100 held-ahead point; paints the segment between `value` and itself |
| `tone` | `primary \| success \| destructive \| muted` | `"primary"` | the fill's colour role |
| `size` | `"sm" \| "md"` | `"md"` | track height from `spacing.xs`/`sm` |
| `label` | `string` | none | accessible name, and `ProgressLabel`'s default text |
| `formatValue` | `(percent: number) => string` | `` `${percent}%` `` | the announced and painted share |
| `loadingText` | `string` | `"loading"` | what an indeterminate bar says instead of a percentage |
| `reducedMotion` | `boolean` | `false` | holds the indeterminate segment; no effect with `value` |
| `children` | `ReactNode` | the track | the parts to draw |
| `style` | `StyleDesc` | — | merged last, on the root frame |
| `className` | `string` | — | Tailwind classes, joined last on the root frame |
| `testId` | `string` | — | stable locator, on the root |

## Limitations

- No `aria-valuenow`: the value is announced as `aria-valuetext`.
- The indeterminate word defaults to English; pass `loadingText` for another
  locale.
- The indeterminate segment is a discrete step, not a smooth sweep.
- One buffer, no stacked segments and no in-track label.
