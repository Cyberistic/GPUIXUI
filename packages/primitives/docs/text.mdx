## Usage

```tsx
import { Text, Stack } from "@gpuixui/primitives";

<Stack direction="column" gap="2xs">
  <Text role="h2">Version 0.11.0</Text>
  <Text role="body" tone="muted">
    Released 17 October 2026.
  </Text>
  <Text role="code">nub add @gpuixui/primitives</Text>
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `role` | `TextRole` | `"body"` | size, leading, weight and family; a stored name the scale does not carry reads as `body` |
| `tone` | `TextTone` | `"default"` | colour role; a stored name the table does not carry reads as `default` |
| `align` | `"start" \| "center" \| "end"` | runtime default (left) | horizontal alignment; the runtime has no writing direction, so `start` paints left and `end` paints right, and a stored name this release does not carry paints the default |
| `truncate` | `boolean` | `false` | one line, clipped with an ellipsis |
| `clamp` | `number` | none | cut to a box N lines tall |
| `selectable` | `boolean` | `false` | `userSelect: "text"` plus the theme's `selection` wash |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |
| `children` | `ReactNode` | — | the string (or inline nodes) |

## Limitations

- No paragraph or list semantics: only the heading and code roles are published.
- No rich text: one run, one role; compose several `Text` nodes in a `Stack`.
- No responsive type scale or fluid sizing.
