---
title: Text
description: One run of type, named by a theme role and a semantic tone.
---

`Text` names a role from the theme's type scale and a tone that decides its
colour. It adds no behaviour: the runtime has one `text` host element, so every
typographic role is the same element with a different resolved `StyleDesc`. It is
not a heading element in the accessibility tree — see Limitations.

## Usage

```tsx
import { Text, Stack } from "@gpuixui/primitives";

<Stack direction="column" gap="2xs">
  <Text role="h2">Version 0.10.0</Text>
  <Text role="body" tone="muted">
    Released 17 October 2026.
  </Text>
  <Text role="code">nub add @gpuixui/primitives</Text>
</Stack>;
```

## Roles

| `role` | Family | Typical use |
| ------ | ------ | ----------- |
| `display` | sans | a landing or empty-state headline |
| `h1`, `h2`, `h3` | sans | page, section and subsection titles |
| `body` | sans | running text |
| `bodyStrong` | sans | the lead sentence of a section |
| `label` | sans | a control's visible name |
| `caption` | sans | metadata and helper text |
| `code` | mono | an inline identifier or command |
| `codeBlock` | mono | a block of code |

Sizes, line heights and weights come from `theme.typography`. No component picks
a font size.

## Tones

| `tone` | Colour role | Use for |
| ------ | ----------- | ------- |
| `default` | `foreground` | body and headings |
| `muted` | `mutedForeground` | metadata, help, disabled-adjacent copy |
| `primary` | `primary` | a link-like non-interactive emphasis |
| `destructive` | `destructive` | an error or a breaking change |
| `inherit` | none | text on a coloured surface, taking its parent's colour |

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `role` | `TextRole` | `"body"` | size, leading, weight and family |
| `tone` | `TextTone` | `"default"` | colour role |
| `align` | `"start" \| "center" \| "end"` | runtime default | horizontal alignment |
| `truncate` | `boolean` | `false` | one line, clipped with an ellipsis |
| `clamp` | `number` | none | clip after N lines |
| `selectable` | `boolean` | `false` | `userSelect: "text"`; off for chrome, on for content |
| `style` | `StyleDesc` | — | merged last |
| `testId` | `string` | — | stable locator |
| `children` | `ReactNode` | — | the string (or inline nodes) |

## Keyboard

Not focusable. Selectable text is pointer-selectable when `selectable` is on;
there is no copy command binding in the component.

## Accessibility

`Text` publishes the semantics its typographic role carries. GPUix 0.11.0
exposes `role` and `aria-level` on the host element, so:

- `h1`/`h2`/`h3` set `role="heading"` with `aria-level` 1/2/3, and a plain string
  child becomes the heading's name;
- `code`/`codeBlock` set `role="code"` (AccessKit `Code`);
- `display`, `body`, `bodyStrong`, `label` and `caption` stay plain text.

A mixed or element child gets the role but no derived name. `display` is a
visual size, not a heading; if the document outline matters, use `h1`–`h3`.

## Theming

`textStyle` reads `typography[role]`, the mono/sans family and the tone's colour
role. `userSelect` defaults to `"none"` so chrome does not accept a text
selection by accident; turn it on for content.

## Limitations

- No paragraph or list semantics: only the heading and code roles above are
  published.
- A heading's name is derived from a **plain string** child; compose icon or
  formatted children and give the region its own accessible name elsewhere.
- No rich text: one run, one role. Composition is several `Text` nodes in a
  `Stack`.
- No responsive type scale or fluid sizing.
- `truncate` needs a bounded width to truncate against.

## Verification

- `src/core/variants.test.ts` — every role resolves from the theme.
- `src/components/presentational.test.tsx` — tone, alignment, truncate, clamp,
  selectable, and the heading/code semantics (level and name, with body copy
  left plain).
- `runtime/layout.runtime.test.tsx` — the string is painted, its box height
  equals the role's line height, and the a11y tree reports a heading's level
  (`h1` = 1, `h3` = 3) with body copy carrying no heading role.

```sh
nub run --filter @gpuixui/primitives test
nub run --filter @gpuixui/primitives test:runtime
```
