---
title: Rating
description: A whole number of stars, or none.
---

`Rating` is a radio group shaped input: one tab stop, arrows move the selection
and native focus with it, and `Space` or `Enter` chooses the star holding focus
the way a platform radio does. It differs from `RadioGroup` in two ways a rating
needs — the arrows **clamp** at the ends instead of wrapping, and `Delete`
clears it back to zero. It is not a slider: the value is a small whole number,
not a position.

## Usage

```tsx
import { Rating, Stack, Text } from "@gpuixui/primitives";
import { useState } from "react";

const [score, setScore] = useState(0);

<Stack direction="column" gap="xs">
  <Rating label="Quality" value={score} onValueChange={setScore} />
  <Text role="caption" tone="muted">
    {score === 0 ? "Not rated" : `${score} of 5`}
  </Text>
</Stack>;
```

Omit `value` to let the rating own its state; `defaultValue` sets the start
(`0` is unrated). Clicking the selected star keeps it — clearing is a deliberate
key (`Delete`/`Backspace`) or the app calling `onValueChange(0)`.

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | — | controlled rating, `0..max` |
| `defaultValue` | `number` | `0` | uncontrolled start |
| `onChange` | `(value: number) => void` | — | deprecated alias for `onValueChange`; the new name runs when both are passed |
| `onValueChange` | `(value: number) => void` | — | the new rating; `0` means cleared |
| `max` | `number` | `5` | how many stars to paint |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | star size from `iconSize` |
| `disabled` | `boolean` | `false` | out of the tab order, half opacity, inert |
| `readOnly` | `boolean` | `false` | shows the value, takes no input, no tab stop |
| `label` | `string` | none | the group's name; stars are announced "N of max" |
| `description` | `string` | none | announced help for the group (`aria-description`); a blank one publishes nothing |
| `ref` / `aria-id` / `onLayout` | host address | none | land on the star that holds the tab stop |
| `invalid` | `boolean` | `false` | failed validation: chosen stars paint destructive and the ring turns destructive |
| `style` | `StateStyle<RatingState>` | — | resolved against the live state, merged last |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the rating's own: the press and focus on the star it landed on, keys on the group root |
| `testId` | `string` | — | stable locator on the group |

Values are truncated to whole stars and clamped to `0..max`; a value that is not
a number reads as unrated.

Your host handlers are composed with the rating's, never substituted: the press
and focus arrive from the star they landed on, the keys from the group root. A
disabled or read-only rating installs no `onClick`, and its keys stay observable.

## Keyboard

| Key | Effect |
| --- | ------ |
| `Space` | chooses the focused star, on the **release** (the press is swallowed so it cannot scroll a container) |
| `Enter` | chooses the focused star, on the press |
| `ArrowRight` / `ArrowUp` | + one star, clamped at `max` |
| `ArrowLeft` / `ArrowDown` | − one star, clamped at `1` once rated; an unrated rating stays `0` |
| `Home` / `End` | one star / `max` |
| `Delete` / `Backspace` | clear to `0` |

The group holds **one tab stop** — on the current rating, or on the first star
when unrated — and an arrow moves the selection and native focus together, so
the ring is always on the star the value came from. An activating key chooses
the star that holds focus (falling back to the tab stop if no star reported
focus), so `Space` on an unrated rating selects the first star instead of
nothing.

## Pointer

Hovering a star previews the score a press would choose: the stars up to it
fill, and moving out of the group restores the rating. The preview is
**paint only** — the value, the announced state and the tab stop keep reading
the rating — so a reader who leaves without pressing changes nothing. A press
commits the star it landed on, exactly as before. A `disabled` or `readOnly`
rating ignores the pointer.

## Accessibility

- Roles: `radiogroup` with the group's `label`, and one `radio` per star
  (AccessKit `RadioGroup` / `RadioButton`).
- Each star's name is `"N of max"` and its state is announced through
  **`aria-valuetext`** (`"checked"` / `"unchecked"`), because `@gpuix/native` 0.11.0 has no
  `aria-checked`.
- `readOnly` keeps the group visible to assistive technology but removes it from
  the tab order; `disabled` also paints it muted.
- The group's help is announced on the `radiogroup` node through
  **`aria-description`** — there is no `aria-describedby` — so a visible `Label
  description` reaches assistive technology when it is passed as `description` or
  through `labelledBy(name, help)`.
- The group wrapper is not focusable, so the **address** lands on the star that
  holds the tab stop: `ref` receives that star, `aria-id` is its automation id,
  and `onLayout` reports its box. An unrated rating addresses the first star, and
  the address follows the value (`runtime/address.runtime.test.tsx`).

## Theming

A selected star paints `colors.primary` (`colors.destructive` when `invalid`),
an empty one `colors.mutedForeground`, using two icons of the same geometry:
`star-filled` and `star`. The ring declares the destructive colour too while
invalid. The filled icon is still monochrome — its `#000` fill is what GPUix
retints — so a theme change repaints both states. The star size is
`theme.iconSize[size]`, and the ring is the shared `keyboardRing`
(`focusVisible`, painted after Tab and not after a click).

Each star's press target reserves `targetSize.minimum` (24px, WCAG 2.2
SC 2.5.8) in both axes — the glyph is centred inside it, so `sm` draws a 14px
star in a 24px target rather than an 18px one. The box is the control: it holds
the role, the focus, the ring and the press.

`style` takes a `StateStyle<RatingState>` — a `StyleDesc`, or a callback that
receives `{ disabled, readOnly, focused, invalid }` for the group. It merges
after every role decision, so a callback is the last word on a property the
recipe also sets.

## Limitations

- **Whole stars only.** Half stars would need clipping or a transform, neither of
  which exists in `@gpuix/native` 0.11.0; a caller that needs a finer score can keep it in
  state and paint the label beside the stars.
- **Clearing is explicit** (Delete/Backspace or the app), not "click the selected
  star again" — a rating is not a toggle. An arrow clamps at one star once the
  rating is set, so a nudge at the end never clears it.

## Verification

- `src/core/rating.test.ts` — clamping (not wrapping), Home/End, Delete/Backspace,
  an arrow never clearing a rated value, the tab-stop choice, a zero or
  fractional `max`.
- `src/components/Rating.test.tsx` — group and star labels, checked states, the
  single tab stop, filled vs outline icons, the destructive paint and muted
  empty stars while invalid, keys, click, disabled/readOnly, ring, a `style`
  callback receiving the live state and winning, and the pointer preview
  (filled stars ahead of the value, the value still announced, disabled and
  read-only ignoring it).
- `src/components/activation.test.tsx` — the activation contract every control
  shares: `Enter` on the press, `Space` on the release, a held key ignored and
  exactly one activation. `Rating` failed it (a focused star could not be
  chosen with either key); the matrix names the part that regresses.
- `runtime/rating.runtime.test.tsx` — a real click on "4 of 5" reports `4`; an
  arrow moves the checked star and native focus; Right at five stays at five and
  Left at one keeps the star; Delete clears;
  `Space` chooses the focused star on the release and not on the press; Delete
  clears; filled stars paint `colors.primary` (destructive while invalid, with
  the empty stars still muted); a real pointer hover fills up to the star it is
  over while the announced value stays put, and leaving restores the rating;
  Tab enters on the rating and the next Tab leaves the group; disabled refuses
  input; and every star's painted box is at least the 24px pressable floor
  (measured at `sm`, the smallest glyph).
