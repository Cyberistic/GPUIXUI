## Usage

```tsx
import { Rating, Stack, Text } from "@gpuixui/primitives";
import { useState } from "react";

const [score, setScore] = useState(0);

<Stack direction="column" gap="xs">
  <Rating label="Quality" value={score} onValueChange={setScore} />
  <Text role="caption" tone="muted">
    {score === 0 ? "Not rated" : `${score} of 5`}
  </Text>
</Stack>;
```

## API

| Prop | Type | Default | Consequence |
| ---- | ---- | ------- | ----------- |
| `value` | `number` | — | controlled rating, `0..max` |
| `defaultValue` | `number` | `0` | uncontrolled start |
| `onValueChange` | `(value: number) => void` | — | the new rating; `0` means cleared |
| `onChange` | `(value: number) => void` | — | deprecated alias for `onValueChange` |
| `max` | `number` | `5` | how many stars to paint; a stored `null` is the default five, while a count that is there and cannot be laid out is one star |
| `allowHalf` | `boolean` | `false` | score in halves |
| `size` | `"sm" \| "md" \| "lg"` | `"md"` | star size from `iconSize` |
| `disabled` | `boolean` | `false` | out of the tab order, half opacity, inert |
| `readOnly` | `boolean` | `false` | shows the value, takes no input, no tab stop |
| `label` | `string` | none | the group's name |
| `description` | `string` | none | announced help for the group (`aria-description`) |
| `invalid` | `boolean` | `false` | chosen stars paint destructive |
| `className` | `string` | — | a Tailwind class string, joined after the recipe so it wins conflicts |
| `style` | `StateStyle<RatingState>` | — | resolved against the live state, merged last |
| `onClick` / `onKeyDown` / `onKeyUp` / `onFocus` / `onBlur` | host handlers | none | composed with the rating's own |
| `ref` / `aria-id` / `onLayout` | host props | none | land on the star that holds the tab stop, so they follow the score; measure a wrapper for the whole control |
| `testId` | `string` | — | stable locator on the group |

## Limitations

- A stored `value` is placed on the painted scale: without `allowHalf`, the stars a score has fully earned paint (`4.9` is four stars.
- Halves are the finest score; a quarter star is not expressible. A half star is a **clipped glyph**, not a tint: the filled star is painted whole and cut at the cell's midpoint, so the outline still shows in the right half. The `rating-lifecycle` probe measured it in a window — 47 checks on 0.11.0 — where a star at `0.5` paints 168 primary pixels in its left half and 0 primary / 98 muted in its right, against a whole star's 270 primary and no muted, and the roles reach the glass rather than tinting over it (an unrated star paints no `primary`, a failure `destructive` and no brand).
- The pointer preview is paint-only: a reader hears the value, not the preview. A press also owns the keyboard path — the probe pressed the disabled group before the clear key and `Delete` left the value at `5`, because native focus had moved to a group that refuses input; a composition that drives a rating by key moves focus back to it after pressing another control.
