# tokens-theme — next-unit audit after plan 534 (2026-10-18)

Where the workstream stands after plan 534.

## Queue state

- Plan 534 closed the last numeric group a copied platform style could not own:
  `PlatformStyleStructure.density` was `DensityName` only, and
  `DensityOverrides` merged over the base theme's preset and ignored a `preset`
  key, so `{ preset: "compact", rowHeight: 30 }` silently produced
  comfortable-sized controls with a 30px row. The override now names the preset
  it starts from (`DensityOverrides.preset`), `mergeDensity` resolves it first,
  and the style field is `DensityName | DensityOverrides`.
- The only `[ ]` rows in `TODO.md` are cross-team handoffs to `components`,
  `primitives`, `docs-site`, `playground` and the integration owner. There is no
  token-native row pending.
- Gates: `nub run check`, `nub run lint` and `nub run test` green at 534;
  `packages/tokens` is 124 files / 5551 tests.

## Candidates, re-checked

1. **Marks on row washes (still deferred).** The combobox row highlights with
   `hover` only, so no shipped composition paints a `primary` mark on `active`,
   `accent` or `selected`. `markPairs` already covers the plain surfaces, `input`
   and the combobox check on `hover`. Revisit when a component adopts one.
2. **Elevation over the content fills.** The probe after 533 found only the AAA
   dark `sm` level under 1.05:1 (1.0396–1.0483 on `info`, `success`, `warning`,
   `primary`), and no shipped composition lands a resting card shadow on a solid
   chip or an action. Not a pair yet.
3. **The docs platform table cannot print a density override.** `docs.test.ts`
   and `readme.test.ts` derive a platform row's density as
   `style.structure.density ?? defaultDensity.name`, which is a string for every
   shipped style but would print `[object Object]` if a maintainer changed one to
   `{ preset, … }`. The failure would be loud (the document says `compact`), but
   the guard should resolve `applyPlatformStyle(getTheme(mode), style).density.name`
   instead. Cheap; do it with the next docs-truth unit, not on its own.
4. **Component literals the tokens can already satisfy.** The cross-team rows
   name the exact sites (drawer widths/heights, `overlayWidth`,
   `overlayMaxHeight`, `keycapSize`, field adornment and chat viewport). Tokens
   side ships the values.
