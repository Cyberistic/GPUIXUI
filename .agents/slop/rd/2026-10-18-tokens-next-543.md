Where the workstream stands after plan 543.

## What landed

- **543** gave `ContrastPairClass` an ordered owner. The union was the last
  exported domain union without an index, while every sibling (`colorRoles`,
  `metricRules`, `motionLevels`, `themeChecks`, `translucentRoles`, …) had one.
  The concrete failure it removes: `inventory.test.ts`'s `floorRow` rebuilt the
  ledger's floor table from **eight named fields**, so a ninth class would have
  forced a floor at both levels (`contrastFloors` is a record over the union) and
  a design-system row (`rowFor` is a record over the union) — both compile
  errors — while `COMPONENTS.md` kept publishing an eight-value table and the
  containment assertion stayed green. The reference's floor snippet had the
  mirror-image problem: its required order came from the `contrastFloors` object
  literal through `Object.entries`, a second owner.

  `contrastPairClasses` is the index, `ContrastPairClass` derives from it, and
  the ledger, the reference snippet and the contract now enumerate it. A probe
  with a ninth class made the ledger case, the reference case and the
  design-system row guard fail until each was updated, and made
  `enforces every class through at least one pair` report `["unused"]` — the
  new case that catches a floor with no enforcement. No colour, pair, floor or
  metric moved; 130 files / 5631 tests, and the branch's three gates are green.

## Candidates, re-checked

1. **The catalogue's "every present-tense figure" claim is split across two
   suites.** `docs/tokens.md` attributes the whole current-figures table to
   `figures.test.ts`, but several figures are pinned in `docs.test.ts` (the
   field edge on Linux dark, the `primaryText` row values). The guarantee holds;
   the sentence names one owner. A wording-and-ownership unit, the cheapest real
   guard left in the documents.
2. **Fills on row washes (recorded, not fixed).** A probe over the 24 shipped
   sets shows `secondary` on `hover` at **1.000:1** in the identity light and
   dark sets and `accent` on `hover` at 1.000:1 light, so a neutral filled
   control or an accent toggle inside a hovered row has no shape against the
   wash. The contract measures fills against the four panels, not the row washes
   (plan 309), and the shipped secondary control's own `secondary` → `hover` →
   `active` step is already the plan-357 cross-team row; adding the pair today
   would fail the gate on values the `components` migration is going to change,
   so it waits for that migration or for a documented composition.
3. **A re-applied style names itself twice** (`"Light · Windows · Windows"`),
   because `applyPlatformStyle` appends the label to the palette's name.
   Cosmetic, and the name now carries the palette's level, which is the meaning
   worth keeping. Recorded, not fixed.
4. **`ColorForm` and `FigureClaim` are literal unions without an index.** Neither
   is a table domain: `ColorForm` is the return type of the total `roleForm`,
   and `FigureClaim` lives in an internal documentation helper that the package
   does not export. No action.
5. **The consumer handoffs.** Another workstream's tree.
