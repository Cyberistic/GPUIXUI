## What landed

- **564** closed the last CSS habit the typeface contract accepted. Plan 533
  closed the padded name and the CSS generic keyword and plan 385 the comma
  stack, but a family wrapped in CSS quotes — `'"Helvetica Neue"'`, the canonical
  CSS spelling for a multi-word family — returned `[]` from all seven checks.
  The runtime passes `StyleDesc.fontFamily` to its font collection as
  `QueryFamily::Named(name)` without unquoting it
  (`references/gpui-ce/crates/gpui_ce_parley/src/catalog.rs:85`), so the theme
  painted the system fallback silently while `themeFailures` said it was good.

  A fifth `quoted` rule reports a double-quoted, single-quoted or half-quoted
  name; `D'Nealian` and every shipped family pass. The rule joins
  `typefaceRules`, so `docs.test.ts`, `readme.test.ts` and `inventory.test.ts`
  derive the catalogue, README, design-system and ledger rows from the index —
  the three guards failed until each was updated. `typeface-quoted.test.ts`
  (eight cases) fails on the pre-fix tree in six of them; the example file
  gained `quotedTheme`/`quotedFailures`, which the same suite runs.

  142 files / 5731 tests green; `check`, `lint` and `test` pass. No family,
  colour, pair, floor, metric, platform style or recipe value moves.

## Candidates, re-checked

1. **CSS-wide keywords (`inherit`, `initial`, `unset`, `revert`).** Not generic
   family keywords, so adding them to `cssGenericFamilies` would falsify its CSS
   Fonts 4 claim; a sixth rule for a rarer habit is not worth a public union
   member yet.
2. **A whitespace-separated fallback (`Inter system-ui`).** Indistinguishable
   from a real family name with a space, which the check must keep accepting.
3. **Fills on row washes.** `secondary` on `hover` is 1.000:1 in the identity
   sets, so a filled control inside a hovered row has no shape against the wash.
   The shipped consumer ladder is the plan-357/334 cross-team row; the token
   contract measures fills on the four panels, and this waits for `components`.
4. **The consumer handoffs.** Another workstream's tree.
