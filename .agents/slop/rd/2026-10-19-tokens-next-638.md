# tokens-theme — audit after plan 637 (2026-10-19, fourteenth tick)

## Scope

Every remaining `[ ]` row in `TODO.md` is a cross-team handoff or the
upstream-blocked `registerFont` (052), so this tick re-audited the numeric
contract — `themeMetricFailures` — against the fixed squares the shipped
components paint, the series plans 620–636 worked through. Plan 637 closed the
documentation half; this tick looked at the one direction the fixed-surface
bounds never asked: the glyph a square holds.

  Each spreads `textStyle(theme, "caption")` around a `✕`.

## Finding

**The field's adornment is a fixed square with no line-fit rule.**
`dimensions.fieldAdornmentSize` is documented as the “trailing clear control (or
other adornment) inside a field”, and plan 353 settled the 16/18 literals on it.
The metric contract held it to `positive`, to fitting inside
`density.controlHeight.sm`, and as the trailing term of `fieldMinWidth` — all
“fits inside something else” rules. Nothing held the caption line the control
paints inside it, the direction plan 517 already guards for `keycapSize`.

The probe:

```ts
const clipped = extendTheme(getTheme("light"), {
  typography: { caption: { lineHeight: 20 } },
  dimensions: { keycapSize: 22 }, // keeps plan 517 coherent
});
themeMetricFailures(clipped); // []
themeFailures(clipped);       // []
```

The shipped identity is `fieldAdornmentSize === caption.lineHeight === 16`, so
the defect is invisible today; a copied theme that grows the caption leading
leaves the 16px clear control painting a 20px line and the checker reports
nothing. No platform style or recipe overrides either metric, so every shipped
set passes the corrected rule at equality and no colour, pair, floor or metric
moves.

## Decision

Add one `at-least` rule in the `dimensions` group —
`fieldAdornmentSize ≥ typography.caption.lineHeight` — with no border term,
because the four controls paint no border. Plan 638 carries the exact edits, the
six-case suite (three fail on the pre-fix tree) and the document updates.

## Not changed

- Any colour, pair, floor or shipped metric.
- The `controlHeight.sm` fit and the `fieldMinWidth` query-row bound.
- `keycapSize`'s caption-line-plus-borders rule.
- The components migration to `theme.dimensions` (cross-team row).
