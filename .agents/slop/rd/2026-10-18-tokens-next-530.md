## Candidates, re-checked

1. **Marks on row washes (deferred again).** The combobox row highlights with
   `hover` only — `combobox.tsx:196-214` sets `backgroundColor: hover` for the
   highlighted state and `hover` for the pointer, with no press style — so no
   shipped composition paints a `primary` check on `active`, `accent` or
   `selected`. `markPairs` already covers the plain surfaces, `input` and the
   combobox check on `hover` (plan 341). Revisit when a component adopts one.
2. **Component literals the tokens can already satisfy.** The cross-team rows
   name the broad migration; the remaining exact sites are
   `date-picker.tsx:287` (220 = `overlayWidth`), `navigation-menu.tsx:511`
   (220), `menu/sub.tsx:398` and `command-menu.tsx:343` (320 =
   `overlayMaxHeight`), `keyboard-shortcuts.tsx:169-170` (20 = `keycapSize`),
   and `search-input.tsx:175`, `time-picker.tsx:418` and
   `hotkey-recorder.tsx:231` (18, the adornment split). These are
   `components`-owned; the tokens side already ships the values.
3. **The numeric contract's member completeness (not yet planned).** This is
   the strongest token-native follow-up. `themeMetricFailures` reads a
   hand-maintained list per group, and its JSDoc claims "every numeric member
   of every group must also be finite". Plan 530 had to add nine `Dimensions`
   members by hand to `finiteMembers` and `positive`; another field would ship
   with **no** rule and both checks would return `[]` for it. The colour side
   closed exactly this gap in plan 086 with a declared exemption list. A
   `metricMembers` index (one ordered list per group, like `colorRoles` and
   `metricRules`) plus a guard that every numeric member of every group is
   indexed — and every index entry is read by a rule — would make the claim
   true. It also lets the `Dimensions` completeness case be derived instead of
   remembered.
4. **The ladder/floor cascade on a non-finite bound.** `drawerWidthSm: Infinity`
   reports `finite` and then an `increasing` failure against the next step, and
   `density.rowHeight: Infinity` now reports both the overlay and chat viewport
   floors. `featherLadder` already skips non-finite neighbours to keep one
   diagnostic per bad value; `ladder` and `atLeast` do not. This is a
   diagnostics-quality follow-up, not a correctness defect.
