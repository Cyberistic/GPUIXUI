# tokens-theme — audit before plan 655 (2026-10-19, twenty-third tick)

## Scope

Every remaining `[ ]` row in `TODO.md` is a cross-team handoff or the
upstream-blocked `registerFont` (052). This tick audited the copyability of the
package's own JSDoc examples — the surface plan `356` called closed.

## What was probed

Plan `356` extended `snippets.test.ts` to read every non-test module, but the
import-contract case filters the blocks:

```ts
snippets
  .filter(({ code }) => [...code.matchAll(importPattern)].length > 0)
  .forEach(...)
```

A block with no import is skipped as a contextual continuation. That is correct
for `docs/tokens.md`, where a section may sequence an expression under a setup
block. It is not correct for a source module: each `@example` there stands
alone.

A probe read every fenced block in every non-test module and printed its label
and whether it imports the package. Fourteen of 44 have no import:

| Module | Blocks |
| ------ | ------ |
| `color.ts` | `isHexColor`, `alpha` |
| `contrast.ts` | `relativeLuminance`, `contrastRatio`, `compositeOver` |
| `elevation.ts` | `elevationShadow`, `elevationShadows` |
| `motion.ts` | `motionTransition` |
| `styles.ts` | `textStyle`, `statusTone`, `filledControl`, `focusRing`, `selectionStyle` |
| `theme.ts` | `getTheme` |

Five of them paint with a `theme` that the block never declares, so the copy
fails twice:

```ts
// statusTone's example, as published
const tone = statusTone(theme, "info");
// ReferenceError: theme is not defined (and statusTone is not in scope)
```

The executed `.example.ts` files run in the suite (plan `350`) and the Markdown
snippets import their names (plan `355`); the source JSDoc is the third
copyable surface and the half plan `356` missed.

## Finding

The guard's exemption is right for a docs page and wrong for a source module.
Plan 655 makes every source example a copyable module: it must contain a
`@gpuixui/tokens` (or `/react`) import, and a theme-painting example declares
`getTheme("light")` (or `"dark"`) so it runs on its own. The existing
name-import case then covers these blocks, because the filter no longer drops
them.

## Not changed

- `docs/tokens.md` / the README: their snippets keep the fragment rule and are
  already guarded;
- any public value, colour, pair, metric, floor, role, check kind or example
  file;
- the executed `.example.ts` suite;
- a component or primitive source file.
