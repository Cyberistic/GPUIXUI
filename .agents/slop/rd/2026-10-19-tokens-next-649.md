# tokens-theme — audit before plan 649 (2026-10-19, twentieth tick)

## Scope

Every remaining `[ ]` row in `TODO.md` is a cross-team handoff or the
upstream-blocked `registerFont` (052). This tick audited the find-highlight
check against the surfaces the pinned runtime paints, reading
`references/gpuix/packages/native/src/custom_elements/diff.rs` and
`.../markdown/render.rs` (read-only).

## What was probed

Plan 582 replaced the plain-tone arm of `themeHighlightFailures` with the code
block's 3.5% ink wash. A `<diff>` does not use that ink: it paints its rows on
`theme.bg` (`.bg(theme.bg)`) and tints a changed row with 5.5% of `diffAdd` or
`diffDel` (`nativeSyntaxTints`, plan 591). A find match on a changed diff line
is therefore behind the selection wash **and** the row tint, which no check
measured.

The probe walked every shipped set, both washes, both tints and the four
`nativeTextSurfaces` tones. Match rows passed; the active match failed on Aero
light:

| foreground | tint role | surface | ratio | floor |
| ---------- | --------- | ------- | ----- | ----- |
| `mutedForeground` | `destructiveText` (`diffDel`) | `muted` | **4.437:1** | 4.5 |
| `mutedForeground` | `successText` (`diffAdd`) | `muted` | **4.440:1** | 4.5 |
| `mutedForeground` | `destructiveText` | `background` | **4.454:1** | 4.5 |
| `primaryText` | `destructiveText` | `muted` | **4.481:1** | 4.5 |
| `primaryText` | `successText` | `muted` | **4.484:1** | 4.5 |
| `mutedForeground` | `successText` | `background` | **4.491:1** | 4.5 |
| `primaryText` | `destructiveText` | `background` | **4.498:1** | 4.5 |

`themeHighlightFailures` and `themeFailures` both returned `[]` for that theme.
The plain-tone and code-ink arms passed, which is why the existing suites were
green.

The same probe found the two tints' **step** already passed (1.063:1 at the
tightest, high-contrast dark), so no floor or step value moves.

## Finding

The find highlight must be measured where the runtime paints it. Plan 649 walks
the code ink and both diff row tints in the text and step arms, names the paint
in the failure payload (`ink`, or `tint`/`tintOpacity`), and moves Aero light's
`mutedForeground` and `primaryText` one designed step darker. The two values
were the only shipped failures; every shipped set then clears the secondary
floor (4.586:1 at the tightest tint pair).

## Not changed

  ink is the harder text surface; the step was re-checked on both);
- a component or primitive source file;
- the check kind count, the `contrastPairs` count or the public export list.
