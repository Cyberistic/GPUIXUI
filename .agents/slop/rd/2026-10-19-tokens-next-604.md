# tokens-theme — next-unit audit after plan 604 (2026-10-19)

## What landed

- **604** closed the last fixed surface metric of the timeline: `timeline.tsx`
  painted a 16px marker column and an 8px event dot as literals, so a brand
  could size every other rail-like surface through `theme.dimensions` but not
  this one. `dimensions.timelineMarkerSize` (8) and
  `dimensions.timelineMarkerColumnWidth` (16) now own both, with two rules:
  the dot is at least the `borderWidth.thin` connector it marks, and the column
  at least contains the dot.
- The rules are gated on usable values, so a zero dot or zero column keeps its
  single `positive` diagnostic (the plan-532 rule). `dimensions.example.ts`
  moves the marker to 12px in a 24px column and passes `themeFailures`; the
  catalogue, design system, README and ledger name the two members.
- 157 files / 6,003 tests green; `check`, `lint` and `test` pass. No colour,
  pair, floor or shipped pixel moves.
- Both directions verified by hand: with the two rules removed, the two
  `at-least` cases fail; with the design-system sentence removed its docs case
  fails; with the catalogue sentence removed the `markdownProse` case fails.
  Each restores green.
