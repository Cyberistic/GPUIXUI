# tokens-theme — audit before plan 656 (2026-10-19, twenty-fourth tick)

## Scope

Every remaining `[ ]` row in `TODO.md` is a cross-team handoff or the
upstream-blocked `registerFont` (052). This tick audited the half of plan `655`
that the guard still leaves to prose: whether a **copyable** block brings the
`theme` it paints with.

## What was probed

Plan `655` made every source `@example` import the package and promised that a
theme-painting example declares `getTheme("light")` (or `"dark"`). The new
`imports every public name it calls, renders or types` case sees exported names
only, so a bare `theme` is invisible to it. A probe read every fenced block in
the non-test modules, `docs/tokens.md` and the package README, stripped imports
and comments, and looked for a `theme` identifier with no local binding.

Seven blocks surfaced from a first pass that looked for a `theme.` property
access; a second pass for a bare `theme` passed as an argument found fifteen
more, so twenty-two copyable blocks fail:

| Surface | Blocks |
| ------- | ------ |
| `packages/tokens/src/styles.ts` | `nativeFieldTheme` `@example` |
| `packages/tokens/src/native-text.ts` | `nativeTextTheme` `@example` |
| `docs/tokens.md` | `statusTone`, `textStyle`, `controlHeight`/`controlPaddingX`, `extendTheme`, `elevationShadow`/`elevationShadows`, `motionTransition`, `contrastRing` (two), `selectionStyle` (three), `nativeFieldTheme`, `disabledControl`, `filledControl` |
| `packages/tokens/README.md` | `motionTransition`, `statusTone`, `focusRing`, `selectionStyle`, `nativeTextTheme`, `nativeHighlight`/`nativeTextTheme` |

Each begins with an import, so it presents itself as a module; pasting it into a
file throws `ReferenceError: theme is not defined`.

A legitimate exemption exists and must survive: a docs block **without** a
package import is a contextual continuation (plan 355), a destructured callback
(`shippedThemes.flatMap(({ theme }) => …)`) binds the theme, and
`docs/tokens.md`'s `focusRing` block receives it as a typed parameter
(`(theme: Theme, focused: boolean)`). A JSX `theme={…}` prop is not a variable
reference, and the word "theme" in a JSX label is not one either.

## Finding

The copyability guarantee is only as wide as its guard. Plan 656 adds one case
that a package-importing block must bind `theme` or receive it as a parameter,
and fixes the seven blocks with `const theme = getTheme("light")`. No token
value, role, pair, floor, metric, check, platform style, recipe or shipped theme
moves.

## Not changed

- the contextual-fragment rule for blocks with no import;
- the executed `*.example.ts` suite;
- `children`, the page's ambient slot in a JSX fragment;
- the docs prose, counts, tables and links.
